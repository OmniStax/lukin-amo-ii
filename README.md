# Modern Atomic and Optical Physics II

The OmniStax edition of *Modern Atomic and Optical Physics II*, Mikhail D. Lukin's Harvard lecture notes, typed by Lilian Childress.
Read it at https://omnistax.andrewchen14250.workers.dev/. The app that reads it, the shared tools and the rules for building a book are in [OmniStax/OmniStax](https://github.com/OmniStax/OmniStax); clone this repository into that one's `omnistax-content/` folder (`npm run books` there does it).
