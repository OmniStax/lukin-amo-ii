原子物理学中，陷俘与冷却之间有着密切的联系。要陷俘原子，原子必须足够冷；一旦它们被陷俘，就有可能把它们冷却得更低，因为阱切断了它们与外界的热接触。因此，我们将从讨论原子陷俘背后的一些基本考虑开始。

11.3.1 原子-表面相互作用

实验利用磁阱、电阱或重力阱使原子与其环境隔离。特别是，阱使原子不会与固体表面或液体表面接触。原子损失是与原子-表面碰撞相关的首要问题，因为原子倾向于黏附在固体上。然而，这种倾向会因原子的类型和所考虑的表面的类型而异。

原子在表面上方的有效势通常支持许多能够陷俘原子的束缚态。此外，固体和液体有大量的振动模式和转动模式，所以一旦被陷俘在表面附近，原子会很快弛豫到该势的基态。在$>$ 1 mK的高温下，原子黏附的概率基本上等于 1。不同原子-固体对的典型结合能列于表 11.1。

原子一旦黏附到表面上，就与固体热化，并在表面上保持黏附某个特征共振时间$\ktauR$。为求出这个共振时间，我们考虑平衡条件：附着到表面上的原子数必须等于离开表面的原子数。

若黏附概率为 s，原子密度为$\kndens$，平均原子速度为$\kvbar$，则流向表面的通量$\Phi = (1/4)\kndens\kvbar s$必须与原子离开表面的速率$\sigma/\ktauR$相等，其中$\sigma$是面密度。假设气体与表面处于热平衡，它们的化学势必须相等，因而

$$\frac{\sigma}{\kndens} = \klambdaDB e^{\kEB/(k_B\kT)}, \tag{11.11}$$

其中$\klambdaDB$是原子的德布罗意波长，$\kEB$是原子与表面的结合能，$\kT$是表面的温度。

共振时间对结合能呈指数敏感，所以只有结合能小于或接近温度的那些原子-固体对，才会有相当小的共振时间。随着壁的温度降到结合能之下，$\ktauR$增大。最终，原子开始堆积在表面之上，这会显著地改变表面的性质。若$\mathcal{L}$是原子之间的距离，以原子直径$d$为单位，则在低到使$\mathcal{L} < 1$的温度下就会发生堆积。

在高面密度下，化学活性原子会开始彼此反应，形成分子，这些分子随后便永久地从化学亚稳原子的系综中损失掉。

若原子不具反应性，物质将聚集成多个单层，气相中的原子密度将与固相处于热平衡。于是，气态非反应性原子的密度就是该原子种类在表面温度下的蒸气压。这一观察说明了为什么真空室在烘烤除气之后能达到低得多的压强。烘烤除气产生较低的“有效蒸气压”，因为表面的结合能对撞击腔室壁的其他原子变得可见，所以无论腔室温度下的蒸气压如何，它们都会黏附。

原则上，只要共振时间在所需温度下相当短，就应当可以利用冷的腔室壁来冷却原子。然而实际上，几乎没有哪种原子（He 上的 H 是一例）能被冷却到有用的温度$\sim 1K$，只有少数特殊的原子对能被冷却到$\sim 100K$以下。因此，表面冷却技术迄今只用于氢原子。

11.3.3 初始冷却

可以采用多种方法把原子冷却到阱深以下。从表 11.3可以看出，确实可以利用冷的 He 表面把氢冷却到$\sim$ 1K，并把它直接俘获在磁阱中。然而，这种方法几乎不适用于其他任何原子。因此，大多数陷俘冷原子的实验在开启阱之前先使用一个激光冷却阶段。

激光冷却

我们已经详细考虑了多普勒冷却和亚多普勒冷却背后的机制。实验上，它们通常依次实施：先用多种多普勒冷却技术的组合把原子俘获在磁光阱中，然后关闭磁阱，以便进行偏振梯度冷却。利用这些技术，在典型的碱金属原子中可以达到$\sim 10^{11}\mathrm{cm}^{-3}$的原子密度和$\sim 50\mu$K的温度。然而，要达到玻色凝聚，相空间密度仍须提高许多个数量级。进一步的冷却是通过把原子转移到不含任何共振光场的阱中来完成的，例如磁阱或远非共振的光学偶极力阱。

缓冲气体冷却

激光冷却有其局限，因为它只对具有循环跃迁的原子效果良好（对分子则不起作用），而且至多只能产生含$\sim 10^{10}$个原子的冷云。对其他各种原子和分子，实际上可以使用一种略有不同的表面冷却。我们已经看到，原子通常会在很长的时间内束缚在冷表面上。然而，如果腔室中含有足够的冷缓冲气体，原子在到达腔室壁之前就能被冷却到缓冲气体的温度。实验上，这一温度由所需的蒸气压决定。例如，氦缓冲气体可以把原子从 1000K 冷却到$\sim 1K$，同时保持足够的蒸气压，使原子平均自由程远小于典型的腔室尺寸。原子冷却之后，缓冲气体可以被抽走，并通过磁陷俘使原子与腔室壁热隔离。我们顺带指出，也存在脉冲冷却机制，它们对一系列电极定时，使原子或分子脉冲始终在爬升势梯度，从而使该脉冲减速。

11.3.4 光阱与磁阱

最后的冷却步骤必须在不激发原子跃迁的阱中进行。一种可能的方案是利用原子偶极力把原子约束在红失谐激光束的焦点上。实验上，常用大功率 CO2激光器来完成这一任务，因为它的波长$\sim 10\mu$m与大多数光学跃迁远失谐。

磁阱利用磁偶极相互作用来约束角动量非零的原子。从量子力学上讲，磁量子数为$m_F$的原子态沿磁场$\kBz$的轴的能量为

$$H = g_F\kmuB m_F\kBz. \tag{11.13}$$

由于麦克斯韦方程组禁止静磁场极大值，这种偶极力只能用于弱场趋近态。

为使原子保持被磁阱约束，原子在阱中运动时，其自旋必须绝热地跟随磁场方向。只要磁场的角度$\ktheta$变化得足够缓慢，使得

$$\frac{d\ktheta}{d\kt} \ll \frac{\kmuB\kBz}{\hbar} = \komegaLarmor, \tag{11.14}$$

原子就将保持在弱场趋近态。如果磁场的角度变化过快，就会出现自旋反转（或“马约拉纳反转”），把原子从被陷俘的态中逐出。

人们能想到的最简单的磁阱是四极阱，其中反亥姆霍兹线圈在其中心产生磁场极小值。磁场在各方向$i = x, y, z$上都是线性的：$B_i = \tilde{B}_ix_i$，其中$\sum|\tilde{B}_i| = 0$。然而，这样的阱在其中心处磁场为零，在那里绝热跟随判据无法满足。因此这种阱的作用就好像在中心有一个孔！通过让磁场零点的位置随时间变化，可以堵住四极阱中的孔。时间轨道势（TOP）阱利用时间平均的四极场来模拟对原子的谐振约束。

或者，可以构建磁场极小值非零的磁阱，方法是把二维四极阱与亥姆霍兹线圈结合起来，以提供轴向约束。这种所谓的“约费-普里查德”阱以最早分别用它来约束等离子体和原子的研究者命名。在阱的中心附近，势近似为谐振势，磁场为

$$\kB = B_0\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} + B_1\begin{pmatrix} x \\ -y \\ 0 \end{pmatrix} + \frac{B_2}{2}\begin{pmatrix} -xz \\ -yz \\ z^2 - \frac{1}{2}\left(x^2 + y^2\right) \end{pmatrix}. \tag{11.15}$$

11.3.5 蒸发冷却

一旦原子被约束在阱中，就可以对它们施加进一步的冷却技术。蒸发冷却提供了达到超冷温度的最有效方法，也是制备量子简并气体的唯一技术。蒸发冷却背后的物理机制非常简单：从阱顶“蒸发逸出”的那些原子，其能量必定多于留下的原子。剩下的原子一旦重新热化，它们的温度就应当下降。

历史

蒸发冷却是哈拉尔德·赫斯于 20世纪80年代在汤姆·格雷塔克和丹·克莱普纳的小组中工作时发明的。该方法最初是用原子氢演示和发展的。大约五年后，它被应用于碱金属，并最终成为制备量子简并物质的标准方法。

理想化的蒸发冷却

在一个完美的世界里，如果蒸发是影响被陷俘原子的唯一过程，那么只要等得足够久，就可以用蒸发冷却把原子冷却到任意低的温度。然而，冷却率会随时间降低，所以更有效的冷却机制是缓慢降低原子阱的势垒，使冷却率保持相当大（见图 11.4）。

或者，可以把原子共振激发到一个未陷俘的，从而选出最热的原子将其从阱中移出。通过缓慢改变共振能量，可以先从阱中逐出最热的原子，并依次切除越来越冷的原子，直到达到所需的温度。这一技术通常利用原子超精细能级之间的射频耦合来完成。在磁阱中，只有弱场趋近态会被陷俘，因此对强场趋近态的共振激发可用来有选择地移除某些原子。虽然所有原子无论动能如何都有相同的超精细结构，但磁阱会引起与空间位置有关的塞曼分裂。因此，这种所谓的“射频刀”可用来切除阱边缘的原子，射频频率的缓慢改变可使刀扫向更靠近阱中心的地方，更冷的原子留在那里。

竞争过程

蒸发冷却并不是影响被陷俘原子的唯一过程。三体复合、非弹性散射以及与背景气体的碰撞共同作用，限制了被陷俘原子的寿命。因此，蒸发冷却必须进行得足够快，使原子在整个过程中都留在阱中，但又必须足够慢，使原子在热原子被逐出之后有时间重新热化。

三体复合

陷俘实验中使用的几乎每一个原子都处于亚稳态。给定足够的时间，碱金属原子会形成分子并最终形成金属晶体，而稀有气体通常被陷俘在亚稳的超精细态中。乍一看，这一观察令人非常担忧，因为这意味着我们陷俘的是一个本质上不稳定的对象。然而存在一个漏洞：为了弛豫到它们的（分子）基态，两个原子需要第三个物体带走多余的能量和动量。如果原子密度足够低，三个原子同时相互作用的概率可以相当小。然而，这些考虑把可用的原子密度限制在$\sim 10^{15}\mathrm{cm}^{-3}$。

非弹性碰撞

磁阱只约束某些自旋种类，所以任何使原子自旋反转的碰撞过程都会导致损失。这些所谓的“偶极的”或“非弹性”过程只需要两个原子。幸运的是，对碱金属而言，二体过程在低温下并不构成太大的问题。

背景气体

最后，原子可能因与真空室中背景气体的碰撞而从阱中损失。吸附在腔室壁上的任何物质都可能蒸发并把原子撞出阱外。碱金属原子对这些过程非常敏感，因此要成功地把蒸发冷却进行到量子简并，需要超高真空$\sim 10^{-11} - 10^{-12}$托。

11.3.6 蒸发冷却理论

为了定量地考察蒸发冷却如何起作用，我们将假设一个特定的磁阱模型，并计入二体非弹性过程。如果磁阱由反亥姆霍兹线圈构成，则在中心附近可以把阱近似为球形线性势

$$B(\rho) = \frac{B_0}{\rho_0}\rho, \tag{11.16}$$

其中$\rho$是到阱中心的距离，$\rho_0$是阱的大小，$B_0$是阱的最大场。如果阱中心的原子密度为$\knzero$，则热平衡时的密度分布为

$$\kndens(\rho) = \knzero e^{-\kmumag|B(\rho)|/k_B\kT}, \tag{11.17}$$

其中$\kmumag$是被陷俘原子的磁矩。

我们把积分的上限取为$\infty$而不是$\rho_0$，因为当$\ketaev > 5$时，阱边缘附近的原子密度小到可以忽略。量$\kVgeo$表示阱的几何体积，而$\ketaev^3$是以阱底密度为参照的密度的压缩因子。

计入二体过程

二体损失发生的速率必定与原子密度的平方成正比，

$$\dot{\kndens} = -\kgin\kndens^2, \tag{11.22}$$

其中$\kgin$是非弹性过程的速率常数。原则上$\kgin$可以依赖于磁场、温度等，但为了我们讨论的目的，我们假定它是常量。

注意，这个表达式中出现了一个 1/8 的因子（相对于式 (11.21)），这是因为对密度的非线性依赖。

蒸发本身

蒸发背后的基本思想是：阱边缘的原子离开系统，黏附在腔室壁上。

我们还必须计入其余原子的热化率$\kGammath$，它由原子云内的弹性碰撞速率$\ksigmael$决定

$$\kGammath \propto \knzero^2\kvbar\ksigmael. \tag{11.29}$$

原子从云中蒸发的速率于是由热化能够补充热原子（它们随后蒸发）储备的速率决定。蒸发率近似为

$$\dot{N}_v = -\knzero^2\kvbar\ksigmael e^{-\ketaev}\kVgeo\ketaev^{\sim 1.5}. \tag{11.30}$$

一个重要的无量纲量是蒸发损失与非弹性损失之比，

$$\frac{\dot{N}_v}{\dot{N}_d} \approx e^{-\ketaev}\ketaev^{4.5}\frac{g_{el}}{\kgin}. \tag{11.31}$$

为建立完整的模型，我们现在必须考虑被阱损失的原子的平均能量。初始平均能量为

$$\bar{E} = \bar{K} + \bar{U} = \frac{9}{2}k_B\kT \tag{11.32}$$

蒸发的原子通常具有的能量量级为阱的阈值能量加上热能，即

$$E_v = \bar{K} + \bar{U}_v \sim E_{th} + (3/2)k_B\kT, \tag{11.33}$$

而由于非弹性碰撞损失的原子则具有

$$E_d = \bar{K} + \bar{U}_d \sim 6/2k_B\kT. \tag{11.34}$$

显然，因偶极弛豫而损失的原子起的是加热而不是冷却样品的作用，在定常态下，可以预期偶极的加热率应当与蒸发冷却率相匹配，即$\frac{\dot{N}_v}{\dot{N}_d} \sim 1$。因此，弹性散射率与非弹性散射率之比对蒸发冷却的成功变得至关重要。在许多系统中，最典型的是碱金属，有利的比值$\kgin \ll g_{el}$使得蒸发冷却到量子简并成为可能。

11.3.7 探测原子系综

冷原子系综的空间分布和动量分布可以用近共振激光来探测。通过对原子云在共振激光束中留下的阴影成像，可以测量温度和原子数，而无需收集荧光光子。

原子云通过其复折射率影响入射激光束，

$$\knref = \sqrt{1 + 4\pi\frac{N}{V}\alpha}, \tag{11.35}$$

其中$\alpha$是原子的极化率。通常，人们测量折射率的实部（折射部分）或虚部（吸收部分），后一种测量更为常见。

吸收成像测量原子系综的与空间位置有关的透射系数，

$$t = e^{-\kdOD/2} \tag{11.36}$$

它按光学深度$\kdOD$的指数变化，

$$\kdOD = \frac{n_c\sigma_0}{1 + \delta^2}, \tag{11.37}$$

其中$n_c = \int\frac{N}{V}dz$是沿视线积分的柱密度，$\sigma_0$是截面，$\delta = (\omega - \omega_0)/(\Gamma/2)$是归一化失谐。吸收成像通常在共振处进行，那里没有使图像畸变的折射效应。吸收成像的一个问题是，玻色凝聚体的光学深度极大，量级为$\kdOD \sim 300$，所以被陷俘的凝聚体会完全吸收共振光。取而代之，使用飞行时间成像。原子云从阱中释放，任其膨胀和下落。几毫秒之后，原子云已把其初始速度（或动量）分布映射到粒子的位置上，从而可以对阱内的动量分布进行吸收成像。这一动量分布的形状使人能够把抛物线形的凝聚体与原子云的高斯热成分区分开。

非共振成像可以通过测量相位来完成

$$\kphi = -\delta\frac{\kdOD}{2}, \tag{11.38}$$

是原子云通过使图像与参考光束干涉（或者在实际中，在光路中放置合适的相位板）印刻在激光束上的。由于激光与原子云不共振，这种成像可以在阱内进行；此外，被激光激发的原子很少，所以可以用“相衬成像”对单个凝聚体拍摄多幅图像。

这些成像技术提供了对原子分布的定量测量。最近甚至已经证明，这类图像可以是受散粒噪声限制的，其噪声由对每个相机像素有贡献的原子的有限数目决定。
