我们已经看到如何把陷俘与冷却结合起来，使原子系综达到量子简并，理想气体在此时会出现玻色凝聚。然而，真实的原子并不是理想气体，它们的相互作用对决定原子玻色凝聚体的行为起着重要作用。

原则上，在我们的理论中计入原子间相互作用可能会很棘手。然而，稀薄原子气体提供了一个很有吸引力的机会，可以在极低的密度$\kndens \sim 10^{12} - 10^{15}\ \mathrm{cm}^{-3}$下工作，此时原子之间相距$\kndens^{-1/3} \sim 100\mathrm{nm} - 1\mu\mathrm{m}$。相比之下，液体的密度通常高达$\kndens \sim 10^{21}\ \mathrm{cm}^{-3}$，以致原子间距$\kndens \sim 1nm$几乎不比由范德瓦耳斯相互作用的尾部决定的原子大小$\krzero \sim 1\mathrm{nm}$大。因此，稀薄气体的理论比液体的理论简单得多，因为我们可以确定一个小参数$\kndens^{-1/3}\krzero$，据此作微扰展开。例如，碱金属原子的典型大小为$\krzero \sim 1 - 10\mathrm{nm}$，所以$\kndens^{-1/3}\krzero < 0.1$。

然而，小参数$\kndens^{-1/3}\krzero$并不完全是我们想要的。为了在低密度极限下有效地描述散射过程，最好按另一个小参数$\kkmag\krzero \ll 1$展开。不过，如果气体足够冷，$\kT < \kTc$，其中$\kTc \sim \hbar^2\kndens^{2/3}/\km$对应于玻色子的凝聚温度或费米子的简并温度，那么$\kndens^{-1/3}\krzero \ll 1$就意味着$\kkmag\krzero \ll 1$。这些所谓的稀薄量子气体提供了一个在理论上易于处理的系统，可用来研究原子间相互作用。

11.4.1 范德瓦耳斯势

间隔较远的中性基态原子之间的相互作用以范德瓦耳斯势为主。考虑两个这样的原子，它们的间距远大于原子的玻尔半径，$r \gg a_0$。在这样大的距离上，原子之间的静电相互作用可以写成多极展开

$$\kUr = \frac{c_1}{r} + \frac{c_2}{r^2} + \frac{c_3}{r^3} + \frac{c_4}{r^4} + \frac{c_5}{r^5} + \frac{c_6}{r^6} + \ldots. \tag{11.39}$$

第一项对应库仑势，仅当原子带电时才不为零。第二项代表电荷-偶极相互作用，r 的幂次更高的项代表更高阶的相互作用。对于碱金属原子，所有这些项在一阶微扰论中都为零，因为偶极、四极等算符的对角矩阵元为零。要求出领头阶的势，需要用到二阶微扰论，而主要的贡献（对处于基态的中性原子而言）来自偶极-偶极相互作用

$$\hat{V}_d(r) = \frac{\mathbf{d_1}\cdot\mathbf{d_2}}{r^3} - 3\frac{(\mathbf{d_1}\cdot\mathbf{r})(\mathbf{d_2}\cdot\mathbf{r})}{r^5}. \tag{11.40}$$

如果原子处于态$|n\rangle$时的能量为$E_n$，那么到$1/r$的领头阶，所得的势为

$$\kUr = \frac{6}{r^6}\sum_{n,n'}\frac{|\langle 0|d_z|n\rangle|^2|\langle 0|d_z|n'\rangle|^2}{2E_0 - E_{n'} - E_n} \tag{11.41}$$
$$= -\frac{\hbar^2}{2\kmured}\frac{\krzero^4}{r^6}, \tag{11.42}$$

其中$\kmured = m_1m_2/(m_1 + m_2)$是原子的约化质量。注意$E_0 < E_{n\neq 0}$，所以二阶修正总是负的，因此在大距离上范德瓦耳斯势是吸引的。碱金属的$\krzero$典型值在 1 nm 到 10 nm 之间，远大于它们的实际大小$\sim 0.1$ nm。如果原子间距变得与$\krzero$同量级，多极展开就会失效，势也不再必然是吸引的。此外，对于$r \gg \krzero$，与任何离心势相比，$\kUr$都可以忽略。在短距离上，电子交换主导着原子间的相互作用，产生很强的短程排斥势。

11.4.2 散射理论基础

我们对二体散射理论的分析将只考虑两个原子之间的相对运动。当质心运动与相对运动解耦时，这一假设成立，例如两个原子在均匀的背景势中碰撞，或被限制在抛物线形的外部势中。着眼于相对运动，我们可以把原子间的碰撞重新表述为单个物体在固定势$\kUr$上的散射，其中$r$是原子间距。唯一重要的区别是质量的改变：由原子的裸质量$m_1, m_2$变为单个物体的约化质量$\kmured = m_1m_2/(m_1 + m_2)$。

沿$\hat{z}$方向入射到势上的单个物体的波函数可以写成如下形式

$$\kpsi_k(\mathbf{r}) = e^{i\kkmag z} + \kpsi_{sc}(\mathbf{r}), \tag{11.43}$$

其中$\kpsi_k$满足薛定谔方程

$$-\frac{\hbar^2\nabla^2}{2\kmured}\kpsi_k + U(\mathbf{r})\kpsi_k = \frac{\hbar^2\kkmag^2}{2\kmured}\kpsi_k. \tag{11.44}$$

在$r \to \infty$的极限下，散射波趋于具有某种角度依赖性的出射波

$$\lim_{r\to\infty}\kpsi_k(\mathbf{r}) = e^{i\kkmag z} + \kfk\frac{e^{i\kkmag r}}{r}, \tag{11.45}$$

其中$\theta$是$\mathbf{r}$与$z$轴之间的夹角。

波函数中的入射平面波部分可以借助下面这个有用的公式，用球谐函数表示：

$$e^{i\kkmag z} = \sum_{l=0}^{\infty} i^l(2l+1)P_l(\cos\theta)j_l(\kkmag r), \tag{11.46}$$

其中$j_l(\kkmag r)$是 l 阶球面贝塞尔函数。在$\kkmag r \gg 1$的极限下，即远离散射体处，贝塞尔函数趋于正弦函数，于是

$$e^{i\kkmag z} \approx \sum_{l=0}^{\infty}\frac{2l+1}{2i\kkmag}P_l(\cos\theta)\frac{1}{r}\left((-1)^{l+1}e^{-i\kkmag r} + e^{i\kkmag r}\right). \tag{11.47}$$

整个波函数因此可以写成入射球面波与出射球面波的相干叠加。

散射截面

涉及散射的实验通常测量诸如沿某一方向散射的原子数这样的量。因此，方便的做法是确定分散射截面

$$\frac{d\ksigmasc}{d\Omega} = \frac{\text{单位时间内散射进立体角 d}\Omega}{\text{入射束的强度}}. \tag{11.48}$$

由于分子的单位是 1/时间，分母的单位是 1/(面积·时间)，截面的单位是面积，可以解释为散射势的大小。用式 (11.45)中定义的散射波函数表示，分散射截面为

$$\frac{d\ksigmasc}{d\Omega} = |\kfk|^2\frac{v_\mathrm{final}}{v_\mathrm{initial}}, \tag{11.49}$$

其中$v_\mathrm{final}$和$v_\mathrm{initial}$是原子的末速度和初速度。我们将着重讨论弹性碰撞，此时$v_\mathrm{final} = v_\mathrm{initial}$。

总截面由分散射截面对所有立体角积分得到

$$\ksigmasc = \int d\Omega\frac{d\ksigmasc}{d\Omega} = 2\pi\int_0^{\pi}|\kfk|^2\sin\theta d\theta. \tag{11.50}$$

玻恩近似

为了计算截面这类有用的量，我们需要知道如何用散射势$\kUr$表示$\kfk$。如果我们知道散射波函数$\kpsi_k(\mathbf{r})$，就可以对薛定谔方程积分，得到

$$\kfk = \frac{-\kmured}{2\pi\hbar^2}\int d^3\mathbf{r}'e^{-i\kk'\cdot\mathbf{r}'}U(\mathbf{r}')\kpsi_k(\mathbf{r}'), \tag{11.51}$$

其中$\theta$是入射波$\kk$与散射波$\kk'$之间的夹角。玻恩近似对应于对势的微扰展开。在玻恩近似下，入射波受散射体的影响不大，于是

$$\kpsi_k(\mathbf{r}) \approx e^{i\kkmag z}, \tag{11.52}$$

而分散射截面由势的傅里叶变换给出。

虽然玻恩近似在大多数情形下并不能给出好的解，但它确实为冷碰撞提供了一些有用的直观认识。特别是，当入射粒子能量较低，使得$\kkmag$相对于势的有效大小$\krzero$很小时，可以在一级玻恩近似中展开指数函数，

$$\kfk \approx \frac{-\kmured}{2\pi\hbar^2}\int d^3\mathbf{r}'(1 - i(\kk' - \kk)\cdot\mathbf{r}' + \cdots)U(\mathbf{r}'). \tag{11.54}$$

在低能量下，只有第一项有贡献，因此分散射振幅$\kfk$没有角度依赖性。换句话说，在低温下出射的散射波是各向同性的。

分波展开

为了得到低能散射的定量描述，我们将使用分波分析。假设原子间势$\kUr$是球对称的，我们可以用球谐函数展开波函数，

$$\kpsi = \sum_{l=0}^{\infty}A_lP_l(\cos\theta)R_l(r), \tag{11.55}$$

其中$P_l$是第$l$个勒让德多项式。将$\kpsi$代入薛定谔方程

$$-\frac{\hbar^2\nabla^2}{2\kmured}\kpsi_k + U(\mathbf{r})\kpsi_k = \frac{\hbar^2\kkmag^2}{2\kmured}\kpsi_k. \tag{11.56}$$

并利用$U(\mathbf{r}) = \kUr$，我们得到一组互不耦合的方程，每个$R_l(r)$对应一个：

$$\frac{d^2}{dr^2}R_l(r) + \frac{2}{r}\frac{d}{dr}R_l(r) - \frac{l(l+1)}{r^2}R_l(r) - \frac{2\kmured}{\hbar^2}\kUr R_l(r) = -\kkmag^2R_l(r). \tag{11.57}$$

由于$\kUr$的短程性（因为$\kkmag\krzero \ll 1$），我们可以把空间分成两个区域，在其中分别适用不同的近似（见图 11.5）。只要我们处于超冷极限$\kkmag\krzero \ll 1$，两个区域就会重叠，我们就可以匹配两个解，求出散射振幅。

在 A 区，$\kkmag \ll 1/r$，所以我们可以忽略薛定谔方程中的能量项。原则上，我们可以求解这个方程得到$R_l^{(A)}(r < \krzero)$，这个解依赖于短程势的细节，但不依赖于能量$\kkmag$。

在$B$区，$r > \krzero$，势的作用可以忽略，薛定谔方程化为球坐标下的自由空间薛定谔方程。因此该区域的解是球面贝塞尔函数，对于小的距离$1 > \kkmag r > \kkmag\krzero$

$$R_l^{(B)}(r) = c_1r^l + c_2r^{-(l+1)}. \tag{11.58}$$

通过在$R_l^{(B)}(r)$与$R_l^{(A)}(r)$同时适用的区域内将二者匹配，我们可以得到两个系数$c_1$和$c_2$。此外，由于$R_l^{(A)}(r)$和$R_l^{(B)}(r < 1/\kkmag)$与$\kkmag$无关，我们发现两个系数$c_1$和$c_2$也不依赖于$\kkmag$。这两个系数之比可以通过论证当$r \sim \krzero$时两项的量级应当相当来定性地估计，于是

$$\frac{c_2}{c_1} \propto \krzero^{2l+1}. \tag{11.59}$$

比例常量的量级通常为一，但在特殊情形下它可以被显著增强。

球面贝塞尔函数解$R_l^{(B)}(r)$在$\kkmag r \gg 1$时有不同的渐近行为：

$$R_l^{(B)}(r) \propto \frac{\sin\left(\kkmag r - \frac{\pi l}{2} + \kdeltal\right)}{r} \sim \frac{(-1)^{l+1}e^{-i\kkmag r} + e^{i\kkmag r+2i\kdeltal}}{r}, \tag{11.60}$$

其中相移$\kdeltal$由系数$c_1$和$c_2$决定：

$$\tan\kdeltal = \frac{c_2}{c_1}\frac{\kkmag^{2l+1}}{(2l-1)!!(2l+1)!!}. \tag{11.61}$$

双阶乘符号 !! 的定义为$n!! = n(n-2)(n-4)\ldots$，对于$l = 0$有$(-1)!! = 1$。由定义可知，在零能量极限$\kkmag \to 0$下，相移为零。这是一种运动学效应，是短程势的结果。

我们已经看到如何利用短程势计算$c_1$和$c_2$，并由此导出相移$\kdeltal$。如果我们能用相移表示$\kfk$，那么至少在原则上，我们就可以由原子间势能导出散射截面。请考察式 (11.60)和式 (11.45)，注意平面波可以写成式 (11.47)的形式。

在超冷极限$\kkmag\krzero \ll 1$下，相移很小，所以$\tan\kdeltal \approx \kdeltal \approx c(\krzero\kkmag)^{2l+1}$，其中$c$是量级为一的常量。

在低温下，$f_{l\neq 0} \ll f_0$，除非存在使$c$的值增大的共振。由于这种共振极不可能出现，在超冷极限下，我们可以放心地忽略除 s 波散射振幅$f_0$以外的所有振幅。

11.4.3 s 波散射

s 波（$l = 0$）散射在低温下占主导，所以我们将相当详细地讨论它的性质。特别是，它的性质可以完全由单个参数刻画，即s 波散射长度。

$l = 0$的径向波函数在$\krzero < r < 1/\kkmag$时具有特别简单的形式：

$$R_0^{(B)}(r) = c_1 + \frac{c_2}{r} \propto 1 - \frac{\kascat}{r}, \tag{11.64}$$

其中我们确定出s 波散射长度

$$\kascat = -\frac{c_2}{c_1}. \tag{11.65}$$

注意在低能极限下，$f_0 \approx -\kascat$；这给出了散射长度的另一种定义。

不过，重要的是要记住，当$\kkmag\kascat \sim 1$时，散射振幅将不同于散射长度。

物理解释

为了对 s 波散射长度获得一些物理直观，我们将考虑三个例子：硬球、一般的排斥势和一般的吸引势。硬球由势刻画

$$U_H = \left\{\begin{array}{cc} \infty & r < \krzero \\ 0 & r > \krzero \end{array}\right\}. \tag{11.69}$$

显然，径向波函数在边界上必须为零，所以波函数渐近线的截距必定是

$$a_H = \krzero. \tag{11.70}$$

因此在低能量下，任何具有正散射长度的势的作用都像半径为$\kascat$的硬球。例如，一个高度有限的排斥势

$$U_R = \left\{\begin{array}{cc} |\kVzero| & r < \krzero \\ 0 & r > \krzero \end{array}\right\}, \tag{11.71}$$

其散射长度为正，但小于$\krzero$：

$$0 < a_R < \krzero. \tag{11.72}$$

吸引势的行为不那么显而易见。一般的吸引势，例如

$$U_A = \left\{\begin{array}{cc} -|\kVzero| & r < \krzero \\ 0 & r > \krzero \end{array}\right\} \tag{11.73}$$

其散射长度可正可负，取决于能量最高的束缚态的接近程度。对于足够浅、不存在束缚态的势，散射长度将为负

$$a_A^{(0)} < 0. \tag{11.74}$$

随着吸引势变深，最终会有一个束缚态进入，把一个节点从$r = \infty$带入波函数，并改变散射长度的符号。我们将会看到，束缚态共振导致散射长度增强，这可以用来在实验上操控原子间相互作用的强度。

s 波赝势

在超冷极限$\kkmag\krzero \ll 1$下，所有具有相同散射长度$\kascat$的原子间势都等价于赝势$\kUr$，其中

$$\kUr\kpsi(r) = \frac{4\pi\hbar^2\kascat}{2\kmured}\delta^3(\mathbf{r})\frac{\partial}{\partial r}\left(r\cdot\kpsi(r)\right). \tag{11.75}$$

反过来，这个势等价于对波函数设定一个边界条件

$$\lim_{r\to 0}\kpsi(r) \propto \left(1 - \frac{\kascat}{r}\right). \tag{11.76}$$

赝势的薛定谔方程为

$$-\frac{\hbar^2\nabla^2}{2\kmured}\kpsi(r) + \frac{4\pi\hbar^2\kascat}{2\kmured}\delta^3(\mathbf{r})\frac{\partial}{\partial r}\left(r\cdot\kpsi(r)\right) = 0, \tag{11.77}$$

不难验证$\kpsi(r) = 1 - \kascat/r$满足这个方程。

赝势之所以有用，是因为它只作用于波函数的正则部分，忽略$1/r$奇点。对于光滑函数（没有任何奇点），它的作用就像一个简单的δ 函数势

$$\kUr = \frac{4\pi\hbar^2\kascat}{2\kmured}\delta^3(\mathbf{r}). \tag{11.78}$$

这对一阶微扰论很重要。

11.4.4 粒子统计

到目前为止，我们的分析一直假定碰撞的粒子是可分辨的，例如不同种类的原子，或处于不同电子态的同种原子。为了把分析应用于不可分辨粒子，我们必须考虑这样一个事实：全同粒子散射$\theta$角与散射$\pi + \theta$角产生相同的结果。因此我们需要对两种可能性求和：

$$\kpsi_k(r) = \frac{e^{i\kkmag z} + \epsilon e^{-i\kkmag z}}{\sqrt{2}} + \frac{\kfk + \epsilon f_k(\pi + \theta)}{\sqrt{2}}\frac{e^{i\kkmag r}}{r} \tag{11.81}$$

由于两粒子波函数在粒子交换下必须是对称或反对称的，对玻色子$\epsilon = +1$，对费米子为$-1$。

对于偶数$l$的分波，两个振幅对玻色子相加、对费米子相减；对于奇数$l$的分波，振幅对玻色子相消、对费米子相加。特别是，全同玻色子的 s 波相互作用截面会增大到 2 倍，而全同费米子则完全不通过 s 波通道相互作用。

11.4.5 原子系综上的散射

处理两粒子散射事件的形式体系可以与光在单个原子上散射的量子光学问题相比较。在这两种情形下，入射光或物质波都被出射的径向（或偶极）波所修改。同样，这两种情形都可以推广到包含许多相干散射体的效应：每个发射出的波同相叠加，产生一个平面波，它相对入射波因吸收和折射而发生了改变。

为了说明这一类比，我们考虑一个入射到宽度为$L$的平板上的冷粒子（或物质波），板内含有由$N$个冷原子组成的稀薄云，其密度$\kndens$满足$\kndens\kascat^3 << 1$。我们假定入射粒子的波矢量为$\mathbf{K} = K_z$、位置为$\mathbf{r_0}$，并用$\mathbf{r_j}$标记第$j$个散射体的位置。对于这个系综，$\kfk = -\kascat$，所以多体波函数可以写成

$$\begin{aligned} \kpsi_\mathbf{K}(\mathbf{r_0}, \mathbf{r_1}, \mathbf{r_2}, \cdots\mathbf{r_N}) &= e^{iK_zx_0} - \sum_j\frac{\kascat}{|\mathbf{r_0} - \mathbf{r_j}|}e^{i|K||\mathbf{r_0} - \mathbf{r_j}|} \\ &= e^{iKz_0} - \sum_j\frac{\kascat}{|\mathbf{r_0} - \mathbf{r_j}|}e^{iK(r_0-r_j)/2}e^{iK(z_0+z_j)/2}. \end{aligned} \tag{11.83}$$

对散射粒子的位置$\mathbf{r_1}, \mathbf{r_2}, \ldots, \mathbf{r_N}$取迹，我们可以得到透射的物质波

$$\kpsi_K(\mathbf{r_0}) = e^{iKz_0} - \kndens\int d^3\mathbf{r_j}\frac{\kascat}{|\mathbf{r_0} - \mathbf{r_j}|}e^{iK(r_0-r_j)/2}e^{iK(z_0+z_j)/2} \tag{11.84}$$

在远离散射体平板之处，$z_0 \gg L$，波的形式为

$$\kpsi_k(z_0) = Ae^{iKz_0}, \tag{11.85}$$

其中

$$A \approx e^{i4\pi\kascat\kndens L/K}. \tag{11.86}$$

平板产生了一个相移

$$\delta K = \frac{-4\pi\kascat\kndens}{K}, \tag{11.87}$$

它对应于与平板中的原子相互作用所引起的有效势能移位。特别是，粒子在平板中时动能的变化为

$$\delta\left(\frac{\hbar^2K^2}{2\km}\right) = \frac{4\pi\hbar^2\kascat\kndens}{\km}. \tag{11.88}$$

动能的这一变化对应于与平板中平均场势能相关的能量代价。

11.4.6 共振

在量子稀薄气体中，有可能找到这样的情形：散射长度远超过范德瓦耳斯尾部的大小，$\kascat \gg \krzero$。在这一情形下，

$$\kkmag\kascat \sim 1 \tag{11.89}$$
$$\kkmag\krzero \ll 1, \tag{11.90}$$

所以气体既冷又稀薄，但相互作用很强。液体的相互作用很强，但由于它们不稀薄，$\kkmag\krzero \sim 1$，按分波的微扰展开不成立，所以除了 s 波通道外，我们还必须考虑 p 波、d 波等的散射振幅。因此，冷的稀薄强相互作用气体提供了一个研究纯粹的s 波强相互作用的新系统。

稀薄气体的一个特别有趣的特征是，有可能找到$\kascat \gg \krzero$的情形。这一极限对应于s 波共振，此时$\kkmag\kascat \sim 1$，但仍存在小参数$\kkmag\krzero \ll 1$。对于大的正$\kascat$，散射长度的共振与一个奇特的弱束缚态的出现有关。

这对应于吸引性范德瓦耳斯尾部的一个束缚态，其能量非常接近于零。

在这个共振附近会出现许多有趣的现象，并且有可能在这些弱束缚态中形成分子。形成分子有两种方法：

  1. 把具有正散射长度$\kascat > 0$的气体冷却到低于结合能的温度，$k_B\kT < E_0$
  2. 制备一个具有负散射长度$\kascat < 0$的冷气体，并扫过共振$\kascat \to -\infty \to \infty \to \kascat > 0$。

只有当我们能以某种方式可控地操控原子间势$\kUr$以改变散射长度时，第二种方法才能实现。费希巴赫共振提供了一种控制散射长度的技术。

费希巴赫共振

到目前为止，我们考虑的是处于基态的原子的散射，并忽略了与原子内态有关的任何效应。实际上，我们必须考虑其他散射通道，例如两个原子的单重态或三重态。例如，假设有两个通道，各有其自己的有效原子间势$U_o(r)$和$U_c(r)$。能量较高的通道被称为“闭”通道，因为它对准束缚态呈现出更高的势垒。

两个通道都服从薛定谔方程，如果两个通道之间有某种小的相互作用$g$，它们的薛定谔方程就是耦合的：

$$\left(\hat{\xi} + U_o(r) - E\right)\psi_o + g\psi_c = 0 \tag{11.93}$$
$$\left(\hat{\xi} + U_c(r) - E\right)\psi_c + g\psi_o = 0, \tag{11.94}$$

其中$\hat{\xi}$是动能算符。令$\psi_c^m$为

$$\left(\hat{\xi} + U_c(r) - E_m\right)\psi_c^m = 0, \tag{11.95}$$

的一组完备的规范正交本征函数，并用它们展开$\psi_c$：

$$\psi_c = \sum_{m=1}^{\infty}\alpha_m\psi_c^m. \tag{11.96}$$

在共振附近，这些系数中只有一个$\alpha_{res}$会有可观的物理效应。

为了求解这个方程，我们可以利用齐次解

$$\left(\hat{\xi} + U_o(r) - E\right)\chi = 0 \to \chi = 1 - \frac{\kabg}{r}, \tag{11.100}$$

其中$\kabg$是开通道在没有来自闭通道的任何效应时的背景散射长度。对于非齐次方程

$$\left(\hat{\xi} + U_o(r) - E\right)\eta = g(r)\psi_c^{res}(r), \tag{11.101}$$

有许多可能的解，我们将选取其行为如下的那个解

$$\eta = A\left(1 - \frac{b}{r}\right), \tag{11.102}$$

其中常量 A 和 b 由势能曲线和耦合常数决定。完整的解是齐次解与非齐次解的叠加。

分母可以用移位后的共振能量重写。如果不同的通道对应于具有不同磁矩的原子态，则共振能量可以通过调节磁场来移位$\kEres \propto \kmuB(B - B_0^*)$。对于超冷原子气体中所预期的低能碰撞，

$$\kascat = \kabg\left(1 + \frac{\kDeltaFesh}{\kEres - E}\right) \tag{11.106}$$
$$\approx \kabg\left(1 + \frac{\kDeltaFesh}{\kEres}\right), \tag{11.107}$$
$$\quad \tag{11.108}$$

散射长度在临界磁场附近发散，此时闭通道束缚态与开通道的阈值能量共振。

费希巴赫共振通常极窄，典型宽度为几高斯。对于超冷原子，散射长度有明确的定义，$\Delta B \sim 10G \Rightarrow \kDeltaFesh \sim 500\mu\mathrm{K}$，因为共振宽度远大于典型的原子温度$\sim 1\mu\mathrm{K}$。

应当注意，弱束缚能级的结合能并不等于共振能级的能量。

11.4.7 相互作用玻色气体的量子理论

弱相互作用的稀薄原子气体可以很好地用一个包含单粒子项和二体相互作用的哈密顿量来描述，

$$\kH = \sum_{i=1}^{N}\left(\frac{p_i^2}{2\km} + \kVtrap(r_i)\right) + \sum_{i<j}V_\mathrm{int}(r_i - r_j), \tag{11.110}$$

其中$\krzero$是相互作用势的典型力程。在$\kkmag\krzero \ll 1$的冷的稀薄原子气体中，相互作用势可以用s 波赝势代替

$$V_\mathrm{int}(r) \approx \underbrace{\frac{4\pi\hbar^2\kascat}{\km}}_{\kUzero}\delta(r), \tag{11.111}$$

其中原子间势的所有性质都由一个参数表示，即散射长度$\kascat$。原则上，我们现在可以开始计算系综中$N$个原子的基态和动力学。然而，由于原子是不可分辨的，我们必须小心地把波函数对称化（对玻色子）或反对称化（对费米子），这在原子数很多时变得相当不便。因此，我们将改用二次量子化的语言重写这个哈密顿量，它隐含地包含了原子的不可分辨性。

二次量子化

物质波的二次量子化形式体系与量子化电磁场所用的方法非常相似。与光子的情形一样，我们将考虑一组完备的单原子态$\{|\zeta\rangle\}$，并定义产生算符与湮没算符$\hat{b}_\zeta, \hat{b}_\zeta^\dagger$，它们可以在这些态中增加或移去一个原子

$$\hat{b}_\zeta|\zeta\rangle = |\mathrm{vac}\rangle \tag{11.112}$$
$$\hat{b}_\zeta^\dagger|\mathrm{vac}\rangle = |\zeta\rangle. \tag{11.113}$$

原子的统计性质决定这些算符的对易性质。

$$\text{玻色子:} \quad [\hat{b}_\zeta, \hat{b}_{\zeta'}^\dagger] = \delta_{\zeta,\zeta'} \tag{11.114}$$
$$\text{费米子:} \quad \{\hat{b}_\zeta, \hat{b}_{\zeta'}^\dagger\} = \delta_{\zeta,\zeta'}, \tag{11.115}$$

其中$[A, B] = AB - BA$是对易式，$\{A, B\} = AB + BA$是反对易式。由于对易关系保证了所得波函数的对称性或反对称性，这一形式体系为处理不可分辨粒子提供了方便的工具。

多体态很容易用这些作用于真空态的产生算符与湮没算符表示。例如，在单粒子态$|\zeta_i\rangle$中有$n_i$个原子的态$|\phi\rangle$可以表示为

$$|\phi\rangle = |n_1, n_2\ldots\rangle = \prod_i(\hat{b}_i^\dagger)^{n_i}|\mathrm{vac}\rangle. \tag{11.116}$$

例如，对于玻色子，场算符类似于电磁场模的产生算符与湮没算符：

$$\hat{b}_\zeta^\dagger|\phi\rangle = \sqrt{n_\zeta + 1}|n_1, n_2\ldots n_\zeta + 1, \ldots\rangle \tag{11.117}$$
$$\hat{b}_\zeta|\phi\rangle = \sqrt{n_\zeta}|n_1, n_2\ldots n_\zeta - 1, \ldots\rangle. \tag{11.118}$$

虽然我们在这里将集中讨论玻色子，但值得指出的是，升高和降低费米子数的规则与之相似，只是必须留意由反对易产生的负号。

一个特别有用的基是动量基$|\kk\rangle$，以及与之相联系的产生算符与湮没算符$\hat{b}_\mathbf{k}$和$\hat{b}_\mathbf{k}^\dagger$。在这种情形下，玻色原子与光子之间有精确的类比。此外，我们可以对这些算符作傅里叶变换，定义物质场的实空间算符

$$\kpsihat = \frac{1}{\sqrt{\kV}}\sum_\mathbf{k}e^{i\kk\cdot\mathbf{r}}\hat{b}_\mathbf{k}, \tag{11.119}$$

其中允许的 k 矢量由量子化体积$\kV$边缘处的边界条件决定。利用对易关系$[\hat{b}_\mathbf{k}, \hat{b}_{\mathbf{k}'}^\dagger] = \delta_{\mathbf{k},\mathbf{k}'}$和恒等式$\sum_k e^{i\kk\cdot(\mathbf{r}-\mathbf{r}')} = \kV\delta(\mathbf{r} - \mathbf{r}')$，我们可以求出$\hat{\psi}(r)$的对易规则。

在物理上，$\kpsihat$可以解释为在位置$\mathbf{r}$处湮没一个粒子的算符。

二次量子化表象中的算符

每个原子的可观测量都可以用物质场的产生算符与湮没算符表示。例如，粒子数算符是

$$\hat{N} = \sum_\zeta\hat{b}_\zeta^\dagger\hat{b}_\zeta = \int d^3\mathbf{r}\hat{\psi}^\dagger(\mathbf{r})\kpsihat. \tag{11.121}$$

式 (11.110)中的哈密顿量也可以用$\kpsihat$写出：

$$\kH = \int d^3\mathbf{r}\ \hat{\psi}^\dagger(\mathbf{r})\left(\frac{\kp^2}{2\km} + \kVtrap(\mathbf{r})\right)\kpsihat \tag{11.122}$$
$$+ \frac{1}{2}\int d^3\mathbf{r}\int d^3\mathbf{r}'\ \hat{\psi}^\dagger(\mathbf{r})\hat{\psi}^\dagger(\mathbf{r}')V_{int}(\mathrm{r} - \mathrm{r}')\hat{\psi}(\mathbf{r}')\kpsihat. \tag{11.123}$$

当原子间势可以用s 波赝势代替时，第二项可以大大简化。

零温无相互作用 BEC

考虑零温下两类势中的基态是有启发性的：

  1. 均匀势
  2. 谐振子势

这些势的单粒子态是众所周知的，在零温下我们预期所有原子都堆积到基态中。对于无限高势壁的方势阱，

$$\psi_0(r) \sim \sin\pi x/L\sin\pi y/L\sin\pi z/L. \tag{11.125}$$

谐振子的基态波函数是高斯函数

$$\phi_0(r) = \frac{e^{-\left(\frac{x^2}{2a_x^2} + \frac{y^2}{2a_y^2} + \frac{z^2}{2a_z^2}\right)}}{\pi^{3/4}(a_xa_ya_z)^{1/2}}, \tag{11.126}$$

其中$\{a_x, a_y, a_z\}$是与各个维度上的阱频率$\{\omega_x, \omega_y, \omega_z\}$相联系的谐振子长度：$a_j^2 = \frac{\hbar}{\km\omega_j}$。如果原子之间不相互作用，那么多体态可以写成

$$|\Psi\rangle = (\hat{b}_0^\dagger)^N|\mathrm{vac}\rangle, \tag{11.127}$$

其中$\hat{b}_0$湮没相应势的基态中的一个原子。

弱相互作用：格罗斯-皮塔耶夫斯基方程

如果相互作用足够弱，那么我们定性地预期玻色凝聚仍应发生，大多数原子占据同一个量子态。我们现在需要确定哪个态将被宏观占据。

利用式 (11.124)中给出的哈密顿量，我们可以求出物质场算符的海森伯运动方程。

这类非线性算符方程一般很难求解，但我们可以利用物理直觉找到一个合适的近似。特别是，既然我们预期有一个态被宏观占据，场算符就应当接近经典相干场

$$\hat{\psi} = \kpsiGP + \delta\hat{\psi}, \tag{11.129}$$

其中$\langle\delta\hat{\psi}\rangle = 0$。当这些围绕平均值的涨落很小时

$$\langle\delta\hat{\psi}^\dagger\delta\hat{\psi}\rangle \ll \langle\hat{\psi}^\dagger\hat{\psi}\rangle, \tag{11.130}$$

玻色凝聚体就可以用关于$\kpsiGP$的经典非线性方程很好地描述，这个方程称为格罗斯-皮塔耶夫斯基方程。

格罗斯-皮塔耶夫斯基方程类似于带有一个非线性项的薛定谔方程，其中$\kpsiGP$起着玻色凝聚体波函数的作用。

由于$\kpsiGP$起着波函数的作用，我们应当小心它的归一化，它由粒子总数确定

$$N = \int d^3\mathbf{r}|\kpsiGP|^2. \tag{11.132}$$

这一归一化条件促使我们把$|\kpsiGP(\mathbf{r})|^2$解释为凝聚体空间密度。

在继续之前，我们指出，严格说来，只有当原子场处于相干态$\hat{\psi}|\kpsiGP\rangle = \kpsiGP|\kpsiGP\rangle$时，才能用经典数$\kpsiGP$代替算符量$\hat{\psi}$。物质波相干态与电磁相干态的类似之处在于，它具有不为零的经典相干性$\langle\hat{\psi}\rangle = \kpsiGP$、明确的相位$\propto \kpsiGP$，以及以$\langle\int dV\hat{\psi}^\dagger\hat{\psi}\rangle = \int dV|\kpsiGP|^2$为中心的可能原子数分布。我们对格罗斯-皮塔耶夫斯基方程的推导隐含地假定凝聚体处于具有任意相位的相干态（这代表所谓的对称性破缺描述）。这一假设的有效性并不显然，但对于大的原子数，它能很好地描述凝聚体的动力学。

格罗斯-皮塔耶夫斯基方程能够充分描述零温玻色凝聚体的大多数性质，并且它与电磁场在克尔介质中的演化十分相似。然而，物质场所关心的问题与光所关心的问题大不相同。

T=0 时凝聚体的基态

电磁场的基态是真空，但物质的行为大不相同，因为原子总数守恒，这导致有限的化学势。基态是格罗斯-皮塔耶夫斯基方程带有相位演化的定态解

$$\kpsiGP = \tilde{\psi}e^{-i\kmuchem \kt/\hbar}, \tag{11.133}$$

其中$\tilde{\psi}$满足

$$\kmuchem\tilde{\psi} = (\underbrace{-\frac{\hbar^2}{2\km}\nabla^2 + \kVr}_{\sim\hbar\komegat} + \underbrace{\kUzero|\tilde{\psi}|^2}_{\kEmf})\tilde{\psi}. \tag{11.134}$$

解$\tilde{\psi}$的性质由动能项和相互作用项的相对重要性决定。阱频率$\hbar\komegat$与平均场相互作用能$\kEmf \sim \kUzero N/\kV$之比为

$$\frac{\kEmf}{\hbar\komegat} \approx \frac{4\pi N\kascat\kat^2}{\kV} \sim \frac{N\kascat}{\kat}, \tag{11.135}$$

其中$\kascat$是散射长度，$\kat$是谐振子阱的特征尺寸。注意，凝聚的原子数出现在这个表达式的分子中，所以即使气体的相互作用很弱（$\kascat \ll \kat$），相互作用仍然可以对凝聚体的行为产生重要影响。当$\hbar\komegat \gg \kEmf$时，凝聚体的行为基本上就像无相互作用的气体。在相反的极限$\hbar\komegat \ll \kEmf$下（对于$\kUzero > 0$，称为托马斯-费米情形），相互作用占主导。

托马斯-费米近似

当原子之间的相互作用很强且为排斥性的，$\kUzero > 0$时，我们可以忽略动能项。

由于我们处于强相互作用情形，因子$N\kascat/\kat \gg 1$使化学势显著增大。凝聚体的大小$\bar{a}$也因相互作用而增大。

这种膨胀在物理上是合理的，因为它降低了排斥相互作用的能量代价。

恢复长度

托马斯-费米近似在原子密度不足以满足平均场能量压倒动能这一假设的区域效果不佳。特别是，在阱壁附近，动能不能再被忽略。例如，考虑一个处于具有无限高势壁的盒子中的凝聚体。托马斯-费米近似会预言$|\tilde{\psi}|^2 = N/\kV$是常量，在盒子边缘处突然降为零。在物理上，这是没有意义的：波函数即使在壁上也必须是光滑的，因为$\tilde{\psi}(r)$的急剧变化要付出很高的动能代价。我们预期波函数在某个特征长度$\kxiheal$上平滑地衰减。这个所谓的“恢复长度”可以通过令长度$\kxiheal$上的变化所对应的动能等于相互作用能$\sim \kUzero N/\kV$来估计，由此得到

$$\kxiheal^2 = \frac{1}{8\pi\kascat N/\kV} = \frac{1}{8\pi\knzero\kascat}. \tag{11.140}$$

只要气体足够稀薄，$\knzero\kascat^3 \ll 1$，恢复长度就延伸到许多个原子上

$$\kxiheal \gg \frac{1}{\knzero^{1/3}}. \tag{11.141}$$

当这一稀薄气体假设失效时，格罗斯-皮塔耶夫斯基方程就不能再对凝聚体给出充分的描述。我们还指出，上述讨论只对相互排斥的原子有效；我们将会发现，当动能接近平均场能量时，吸引性相互作用会出现问题。
