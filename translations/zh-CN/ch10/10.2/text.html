就我们的目的而言，离子阱的物理可以通过用谐振子势来近似该阱来理解。

离子可以与将耦合内部电子自由度之间跃迁的激光束相互作用。如果内部跃迁是偶极容许的，离子将迅速弛豫，自发发射一个光子。这类跃迁可用于把离子激光冷却到其运动基态，也可用于通过观察它是否发荧光来读出量子比特的态。然而，对于量子态工程，人们希望有一个长寿命的亚稳态，可以在四极跃迁上被驱动。离子具有这样的亚稳态，寿命约为一秒，我们将着重讨论这些偶极禁戒跃迁，其中自发发射可以忽略。这些内部能级如图 10.4所示。

由于离子被阱紧紧束缚，其运动态也具有量子化的能级。离子的希尔伯特空间于是可以理解为一个二能级系统，带有一个由福克态构成的谐振子阶梯，描述其运动。由于我们主要关心量子态工程，我们将忽略声子加热效应，并假定离子可以制备在其运动基态。因此，我们考虑的陷俘离子与构成其环境的辐射热浴和声子热库都是隔离的。

10.2.1 谐振子势

强库仑相互作用使离子能够被约束在谐振子频率$\knu \sim 10$ MHz的阱中。离子的位置和动量可以用振动能量子的产生算符和湮没算符表示：

$$\kxion = \sqrt{\frac{\hbar}{2\km\knu}}\left(\hat{a} + \hat{a}^\dagger\right) \tag{10.2}$$
$$\kp = i\sqrt{\frac{\hbar\km\knu}{2}}\left(\hat{a}^\dagger - \hat{a}\right), \tag{10.3}$$

而离子运动的哈密顿量就是

$$\kHmotion = \hbar\knu\hat{a}^\dagger\hat{a}. \tag{10.4}$$

离子波函数在其运动基态中的特征尺寸为

$$\kazero = \sqrt{\frac{\hbar}{2\km\knu}}, \tag{10.5}$$

而对于被紧密陷俘的离子，这一谐振子长度显著小于光波长。

10.2.2 内部能级

电子能量结构可以简单地用一个二能级系统表示，它具有基态$|g\rangle$和激发态$|e\rangle$。如果我们忽略自发发射过程，哈密顿量就是

$$\kHelectronic = \hbar\komegaeg|e\rangle\langle e|. \tag{10.6}$$

为了忽略来自激发态的衰变，我们要求衰变率$\kgamma$与我们希望在其间操控离子的时标$\ktau$的倒数相比要小。有两种常用的方法可以实现$\kgamma\ktau \ll 1$：

(1) 使用可在四极跃迁上被驱动的亚稳态。

(2) 使用远失谐的拉曼跃迁，将有效谱线宽度减小$(\kOmega/\kDelta)^2 \ll 1$。

10.2.3 离子-激光相互作用

离子吸收一个光子时，与之相伴的动量冲击可以激发阱中更高的振动态。为了定量地理解这一点从何而来，考虑与行波相联系的电场

$$E_\mathrm{running} = \kEenv e^{i(\kkmag x-\komega \kt)} + c.c. \tag{10.7}$$

或驻波

$$E_\mathrm{standing} = \kEenv\sin{(\kkmag x + \kphi)}e^{-i\komega \kt} + c.c. \tag{10.8}$$

这一电场与离子的相互作用发生在离子所在的位置，因此我们将经典量$x$替换为算符量$\kxion$。于是所得的相互作用哈密顿量（在旋转波近似下）为

$$\hat{H}_\mathrm{running} = -\hbar\left(\kOmega|e\rangle\langle g|e^{i(\kkmag\kxion-\komega \kt)} + h.c\right) \tag{10.9}$$
$$\hat{H}_\mathrm{standing} = -\hbar\left(\kOmega|e\rangle\langle g|\sin{(\kkmag\kxion + \kphi)}e^{-i\komega \kt} + h.c\right). \tag{10.10}$$

如果我们在动量基中写出态，传递给原子的动量冲击就可以显式地看出来，在该基中哈密顿量可以诱导跃迁

$$|g\rangle|p\rangle \rightarrow |e\rangle e^{i\kkmag\kxion}|p\rangle = |e\rangle|p + \hbar \kkmag\rangle. \tag{10.11}$$

因此，我们可以通过激光激发来操控离子的质心运动。

兰姆-迪克参数

正如我们先前所暗示的，与激光波长和离子空间范围相联系的长度尺度是不同的。对于紧阱，它们之比提供了一个小参数

$$\ketaLD = \frac{2\pi \kazero}{\klambda} \sim 0.1, \tag{10.12}$$

而通过对这一参数展开，我们可以突出相互作用哈密顿量在所谓的“兰姆-迪克情形”中所容许的物理过程。我们还可以用反冲能$\komegaR = \hbar \kkmag^2/2\km$来解释兰姆-迪克参数$\ketaLD$

$$\ketaLD = \sqrt{\frac{\komegaR}{\knu}}. \tag{10.13}$$

由于$\komegaR \sim$ kHz而$\knu \sim 10$ MHz，可见$\ketaLD$可以相当小。从物理上看，兰姆-迪克情形对应于这样的极限：离子被束缚得如此之紧，以至于一个光子的反冲能不足以激发更高的振动态，因此光子动量被阱而不是离子吸收。

用兰姆-迪克参数表示，总哈密顿量在行波的转动参考系中为

$$\kHr = \hbar\knu\hat{a}^\dagger\hat{a} - \hbar\kDelta|e\rangle\langle e| - \hbar\left(\kOmega|e\rangle\langle g|e^{i\ketaLD(\hat{a}+\hat{a}^\dagger)} + h.c\right) \tag{10.14}$$

而驻波哈密顿量为

$$\kHs = \hbar\knu\hat{a}^\dagger\hat{a} - \hbar\kDelta|e\rangle\langle e| - \hbar\left(\kOmega|e\rangle\langle g|\sin\left(\ketaLD(\hat{a} + \hat{a}^\dagger) + \kphi\right) + h.c\right). \tag{10.15}$$

注意$\ketaLD$出现在指数或正弦函数中，因此对兰姆-迪克参数展开可以使这些哈密顿量得到显著的简化。特别地，我们将看到，所得的动力学与腔量子电动力学中的J-C 哈密顿量惊人地相似，其中腔光子被离子运动态的量子化激发所取代。

裸能谱

在分析激光-离子相互作用的效应之前，我们应当理解作为如下算符的本征态的裸能级的结构

$$\kHzero = \hbar\knu\hat{a}^\dagger\hat{a} - \hbar\omega_{ge}|e\rangle\langle e|. \tag{10.16}$$

由于$\komegaeg \gg \knu$，电子结构的基态和激发态被很好地分开，但又细分为不同的运动态。特别地，裸态的形式为

$$\kHzero|g\rangle|n\rangle = \hbar n\knu|g\rangle|n\rangle \tag{10.17}$$
$$\kHzero|e\rangle|n\rangle = \hbar(n\knu + \komegaeg)|e\rangle|n\rangle. \tag{10.18}$$

激光诱导的耦合：行波

离子-激光相互作用耦合陷俘离子的裸能态。

将指数展开到$\ketaLD$的最低阶，仅有的非零矩阵元把$n$与$m = n, n+1, n-1$耦合起来。

注意，事实上真正的展开参数是$\ketaLD\sqrt{n}$，因为我们展开的是$\ketaLD(\hat{a} + \hat{a}^\dagger)$的指数，而$\hat{a}$按$\sqrt{n}$变化。

这三个矩阵元诱导内态与运动态之间的耦合，如图 10.5所示。通过调谐激光频率，可以逐一对这三种跃迁寻址。

假设激光频率被调谐到与裸原子跃迁频率$\komega = \komegaeg$共振。如果功率足够小，$\kOmega \ll \knu/\ketaLD$，边带跃迁的激发就被强烈抑制，因此内部和外部自由度解耦。在这一极限下，系统可以很好地用二能级哈密顿量描述

$$\kH = \hbar\knu\hat{a}^\dagger\hat{a} - \hbar\kDelta|e\rangle\langle e| - \hbar\kOmega\left(|e\rangle\langle g| + |g\rangle\langle e|\right). \tag{10.23}$$

从物理上看，这一极限对应于一个局域得很好的离子，其动量分布远大于激光激发所传递的反冲动量。离子吸收一个光子时，其能量不足以把离子激发到更高的运动态，其动量被传递给阱。

如果激光被调谐到红边带，有效动力学可以用J-C 模型描述

$$\kH = \hbar\knu\hat{a}^\dagger\hat{a} - \hbar\kDelta|e\rangle\langle e| - i\hbar\ketaLD\kOmega\left(|e\rangle\langle g|\hat{a} + |g\rangle\langle e|\hat{a}^\dagger\right), \tag{10.24}$$

其中内部跃迁伴随着一个声子的产生或湮没。完全相同的哈密顿量出现在腔量子电动力学中，因此我们可以运用来自腔量子电动力学的直觉来理解陷俘离子如何演化。然而，这两个系统之间存在一些重要的物理差异。光学光子的频率尺度$\sim$ THz远大于离子运动的频率尺度$\sim$ MHz。此外，真空拉比耦合被有效拉比频率$\kg \rightarrow \ketaLD\kOmega$所取代。因此，强耦合情形对离子阱而言显著更容易达到，因为只需增大激光功率即可增大耦合强度。此外，耦合参数可以用激光开启和关闭，从而实现对离子内态和运动态的受控操控。

类似的考虑适用于蓝边带跃迁。在这种情形下，系统遵从一个“反 J-C”哈密顿量

$$\kH = \hbar\knu\hat{a}^\dagger\hat{a} - \hbar\kDelta|e\rangle\langle e| - i\hbar\ketaLD\kOmega\left(|e\rangle\langle g|\hat{a}^\dagger + |g\rangle\langle e|\hat{a}\right), \tag{10.25}$$

其中内态的激发伴随着一个声子的发射，反之亦然。

激光诱导的耦合：驻波

当离子被驻波照射时，驻波相对于离子阱极小值的相位提供了另一种操控系统的手段。对哈密顿量进行兰姆-迪克展开得到

$$\kHs = \hbar\knu\hat{a}^\dagger\hat{a} - \hbar\kDelta|e\rangle\langle e| - \hbar\left(\kOmega|e\rangle\langle g|\left(\sin\kphi + \ketaLD(\hat{a} + \hat{a}^\dagger)\cos\kphi + \mathcal{O}(\ketaLD^2)\right) + h.c\right). \tag{10.26}$$

类似的跃迁发生在裸能级之间，但令相位$\kphi = 0$，就可以消除离子的垂直跃迁。

10.2.4 边带冷却

通过光学地对运动态之间的跃迁寻址，就有可能把离子冷却到阱的基态。通常，这是通过施加一束与容许跃迁的红边带共振的激光来实现的。每个激发循环都使运动能量减少，而发射发生在全部三种可能的跃迁上；平均而言，这把离子抽运到阱的基态，该基态对红失谐激光是暗的。

冷却发生的速率由离子激发态的荧光率$\kgamma$决定。最初，人们希望有较大的荧光率以提高冷却速率；然而，要冷却到基态，需要$\kgamma \ll \knu$，这样对直接跃迁和蓝边带跃迁的非共振激发就可以忽略。实际上，衰变率常常通过选择一条名义上禁戒的冷却跃迁来调节。通过施加另一束激光，把（禁戒的）激发态耦合到另一个对基态具有容许跃迁的激发态，就可以控制有效的自发发射率。利用这类技术，实验者已经把离子冷却到阱的基态，效率超过99%。
