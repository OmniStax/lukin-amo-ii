1.2.1 状态

我们简要回顾基本的量子力学以及原子物理学的一些初等结果。

对系统最完整的了解包含在态矢量$|\kpsi\rangle$中，它是希尔伯特空间$\mathcal{H}$的一个元素。我们可以在希尔伯特空间的任意规范正交基$\{|n\rangle\}$中展开态矢量$|\kpsi\rangle$，

$$|\kpsi\rangle = \sum_n |n\rangle\langle n|\kpsi\rangle. \tag{1.1}$$

为方便起见，我们记$\kcn = \langle n|\kpsi\rangle$为态$|\kpsi\rangle$在基矢态$|n\rangle$上的投影，它给出了态$|\kpsi\rangle$在基$\{|n\rangle\}$中的展开系数。于是，在态$|n\rangle$中找到系统的概率为$\kPn = |\kcn|^2$。

1.2.2 叠加——干涉

量子力学允许态的叠加，特别是对于两个态

$$|\kpsi_1\rangle = \sum_n \kcn^{(1)}|n\rangle \text{ 和} \tag{1.2}$$
$$|\kpsi_2\rangle = \sum_n \kcn^{(2)}|n\rangle, \tag{1.3}$$

它们的叠加$\frac{1}{\sqrt{2}}(|\kpsi_1\rangle + |\kpsi_2\rangle)$具有独特的性质：处于态$|n\rangle$的概率一般并不等于各概率之和。相反，它由概率幅之和的绝对值给出

$$\kPn = \frac{1}{2}\left|\kcn^{(1)} + \kcn^{(2)}\right|^2 \neq \frac{1}{2}(\kPn^{(1)} + \kPn^{(2)}) \tag{1.4}$$

这一不等式的出现，是态矢量的两个分量之间干涉项的结果，在此情形下该项为$\kcn^{(1)*}\kcn^{(2)}$。

1.2.3 可观测量

量子力学中的可观测量由作用于希尔伯特空间中态的厄米算符表示。当对希尔伯特空间中任意两个态$|\kpsi_{1,2}\rangle$都有下式成立时，算符$\hat{O}$是厄米的

$$\langle\kpsi_1|\hat{O}|\kpsi_2\rangle = (\langle\kpsi_2|\hat{O}|\kpsi_1\rangle)^*. \tag{1.5}$$

当系统处于态$|\kpsi\rangle$时，可观测量$\hat{O}$的期望值为

$$\langle\hat{O}\rangle = \langle\kpsi|\hat{O}|\kpsi\rangle. \tag{1.6}$$

当算符$\hat{O}$在基$\{|n\rangle\}$中是对角的时，我们有

$$\hat{O}|n\rangle = \mathcal{O}_n|n\rangle \tag{1.7}$$
$$\Rightarrow \langle\hat{O}\rangle = \sum_n \mathcal{O}_n|\kcn|^2 = \sum_n \mathcal{O}_n p_n \tag{1.8}$$

其中$\mathcal{O}_n$表示算符$\hat{O}$的第 n 个本征值。注意，如果系统处于$\hat{O}$的一个本征态，那么对可观测量$\hat{O}$反复测量时，我们总是得到相同的结果。

1.2.4 不确定性原理

一般而言，算符不对易，即

$$[\hat{A}, \hat{B}] = i\hat{C} \tag{1.9}$$

因此对于$\hat{C} \neq 0$，算符$\hat{A}$和$\hat{B}$不具有相同的本征态。

海森伯不确定性原理指出，对任意两个算符$\hat{A}$和$\hat{B}$，我们有

$$\Delta A \cdot \Delta B \geq \frac{1}{2}\langle[\hat{A}, \hat{B}]\rangle \tag{1.10}$$

其中$\Delta A = \sqrt{\langle(\hat{A} - \langle\hat{A}\rangle)^2\rangle}$。

1.2.5 时间演化：薛定谔绘景

在非相对论量子力学中，系统的动力学由薛定谔方程描述：在薛定谔绘景中，描述系统状态的态矢量随时间演化，而描述对系统可能进行的测量所对应的可观测量的算符则是不随时间变化的。

态矢量按下式随时间演化

$$i\hbar\frac{d}{d\kt}|\kpsi\rangle = \kH|\kpsi\rangle \tag{1.11}$$

其中$\kH$是系统的哈密顿量。薛定谔方程的定态解由$|\kEn\rangle$给出，其中$\kH|\kEn\rangle = \kEn|\kEn\rangle$。任意态都可以在$\kH$的本征态所构成的基中展开，在该基中，态矢量的时间演化取特别简单的形式，即

$$|\kpsi(\kt)\rangle = \sum_n e^{-i\kEn\kt/\hbar}\kcn|\kEn\rangle \tag{1.12}$$

它对应于初态$|\kpsi(0)\rangle$，其展开系数为$\kcn = \langle \kEn|\kpsi(0)\rangle$。在其本征态的基中，哈密顿量是对角的，$\kH = \sum_n |\kEn\rangle \kEn\langle \kEn|$。时间演化方程也可以形式地积分，得到时间演化后的态$|\kpsi(\kt)\rangle = \exp[-i\kH\kt/\hbar]|\kpsi(0)\rangle = \hat{U}(\kt)|\kpsi(0)\rangle$，其中$\hat{U}(\kt)$是时间演化算符。

1.2.6 时间演化：海森伯绘景

在海森伯绘景中，描述系统初态的态矢量不随时间演化，而是描述在时刻$\kt$对系统可能进行的测量的可观测量显含时间，并按照海森伯运动方程演化

$$i\hbar\frac{d}{d\kt}\hat{O}(\kt) = [\hat{O}, \kH] + i\hbar\frac{\partial\hat{O}}{\partial \kt}. \tag{1.13}$$
