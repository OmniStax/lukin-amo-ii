原子系统的完备态基不仅包括离散的束缚能态，还包括由能量更高的非束缚态构成的连续谱。频率等于或高于光致电离阈值的光子可以诱导向这一连续谱的跃迁，而即使是阈值以下的相互作用，也会受到能量上邻近的非束缚态的影响。束缚态到连续谱的跃迁的例子包括原子的光致电离和超冷分子的光致离解。理解连续谱态对原子-场动力学的贡献很重要，因为它们的效应在性质上不同于离散态所特有的拉比振荡。

从数学上讲，态的连续谱可能难以处理，所以我们考虑体积为$L^3$的盒子中的一个原子，把非束缚态离散化。当盒子的尺寸趋于无穷大时，离散的能级趋近于连续谱。这里我们只考虑单个束缚态和一个一般的非束缚态连续谱，用$|1\rangle$表示基态，用$|k\rangle$表示激发态，每个态的能量为$\hbar\komegak$。频率为$\knu$的外加场把每个束缚态$|k\rangle$与束缚态$|1\rangle$耦合，拉比频率为$\kOmegak$。因此（在旋转波近似和转动参考系中）哈密顿量为

$$\kH = \sum_k \hbar\left(\komegak - \knu\right)|k\rangle\langle k| - \hbar\sum_k \left(\kOmegak|k\rangle\langle 1| + \kOmegak^*|1\rangle\langle k|\right). \tag{2.42}$$

我们将用试探波函数来研究动力学，这与我们处理二能级原子的方式类似。把波函数按基态和连续谱态展开，

$$|\kpsi\rangle = \kcone|1\rangle + \sum_k \kck|k\rangle \tag{2.43}$$

并代入薛定谔方程，我们得到现在已经很熟悉的运动方程。

这些方程相当棘手，对于任意一组态$|k\rangle$无法求解。我们将先对第二个方程作形式积分，然后做一系列近似，这些近似对于分布在很大能量范围内、间隔密集的态的连续谱是成立的。对于从基态出发的原子系统，$\kcone = 1$且$\kck = 0$。

代入第一个方程，得到一个只涉及基态概率幅的非局域积分方程。

由于要对失谐$\kdeltak$求和，只有当$\kt = \kt'$时，该指数才会明显不为零。取到最低阶（假设概率幅$\kcone(\kt)$变化缓慢），我们可以令$\kcone(\kt') = \kcone(\kt)$并把它提到积分号外。剩下的积分可以通过给$\kdeltak$加上一个无穷小的虚部来计算。

利用复分析中的一个恒等式，该积分变为

$$\mathop{\mathrm{lim}}\limits_{\epsilon\to 0}\frac{i}{\kdeltak + i\epsilon} = \pi\delta(\kdeltak) + i\mathcal{P}\frac{1}{\kdeltak}, \tag{2.49}$$

其中$\mathcal{P}$表示对$\kdeltak$积分时应取主值。

所得基态概率幅的运动方程包含一个速率为$\kgamma$的布居衰变，以及一个能量移位$\kDeltaStark$：

基态的概率幅简单地按$\kcone(\kt) = \kcone(0)e^{-\kgamma \kt/2 + i\kDeltaStark \kt}$演化，因此布居按$\kpone(\kt) = \kpone(0)e^{-\kgamma \kt}$衰变。

请注意$\kgamma$的表达式，

$$\kgamma = 2\pi\sum_k |\kOmegak|^2\delta(\knu - \komegak), \tag{2.51}$$

恰好就是利用费米黄金规则所得到的布居衰变率。尽管有这种表面上的相似，两种推导之间的关系却相当微妙，因为费米黄金规则来自一阶微扰论，而我们的做法明确涉及长时极限。对此的解释在于：在式 (2.47) 中令$\kt = \kt'$，意味着连续谱态对基态的作用在时间上是局域的，所以非束缚态对先前的构型没有“记忆”。特别地，对所有时间而言衰变率必须是常数，因此早期时刻的值（例如由费米黄金规则算得）确定了系统的衰变率。此外，微扰方法在以下意义上是成立的：激发任何一个连续谱态的概率都非常小，尽管基态的布居当然会发生剧烈变化。

能量移位，

$$\kDeltaStark = \sum_k |\kOmegak|^2\mathcal{P}\frac{1}{\knu - \komegak} \tag{2.52}$$

源于与连续谱态相关的交流斯塔克效应。衰变与能量移位的相对重要性取决于所考虑的具体系统。对于低于光致电离阈值的外加场频率，衰变消失，$\kgamma = 0$，但连续谱态仍会通过交流斯塔克偏移产生影响。高于阈值的光子频率导致衰变；此外，交流斯塔克效应的符号随失谐的符号而改变，所以$\kdeltak = 0$上方和下方的贡献在很大程度上会相互抵消。因此我们预期，能量移位对阈值以下的照射最为重要，而衰变项在阈值以上占主导。

对于实际问题，$\kDeltaStark$是连续谱态确切性质的非常敏感的函数，在许多情形下，系统的分析中并不明确包含它。在一些重要的实际情形中，例如下面要考虑的原子与真空场的相互作用，它是一个常数（例如兰姆移位），只是导致原子能级的适当重正化。

在大时间极限下，$\kck$趋近于值$i\kOmegak e^{i\kdeltak \kt}/(\kgamma/2 + i\kdeltak)$。从物理上讲，系统已被激发到连续谱态的叠加$\sum_k \kck|k\rangle$中，这些态形成一个从原子向外传播的出射波包。这种看似不可逆的行为在性质上不同于先前研究的拉比振荡，说明了电子离开原子的一种机制，转变为自由传播的波包。然而，需要注意的是，上面给出的形式体系并不排除使动力学反演。事实上，我们应当能够对动力学做时间反演，因为到目前为止我们的分析只涉及经历幺正演化的波函数。例如，从一个初始波包出发，可以计算被俘获到原子束缚态中的概率。这样的计算用微扰论是做不到的，并说明了这种方法的灵活性（例如见作业题 5）。
