在导论讲义中，我们回顾了类氢原子较为复杂的能级结构。选择定则与能量守恒使我们能够挑出一部分跃迁，从而使相关动力学中只涉及少数几个能级。在本讲中，我们将详细讨论最简单的原子-场系统，即只有两个原子能级与外加激光场相互作用的系统。

2.1.1 二能级原子

当外场较弱且与单一原子跃迁近共振时，把原子近似为二能级系统是成立的。此时只有基态和近共振的激发能级才有可观的占据概率。我们把这两个态分别记为$|1\rangle$和$|2\rangle$，并把它们的能量差记为$\hbar\komega$。

我们考虑该系统在近单色经典电磁场照射下的演化

$$\kEfield(\mathbf{r}, \kt) = \kEenv(\mathbf{r}, \kt)e^{-i(\knu \kt - \kk\cdot\mathbf{r})} + \kEenv(\mathbf{r}, \kt)^* e^{i(\knu \kt - \kk\cdot\mathbf{r})}, \tag{2.1}$$

其中缓变包络$\kEenv(\mathbf{r}, \kt)$变化的时标远慢于光频$\knu \approx \komega$，长度尺度远大于光波长$2\pi/|\kk|$。该电场与原子偶极子相互作用，原子偶极子由算符$\hat{d} = e\kr$给出，它可以方便地用原子本征态和偶极矩阵元$\kmu_{a,b} = \langle a|\hat{d}|b\rangle$来表示：

$$\begin{aligned} \hat{d} &= \sum_{n,n'} |n'\rangle\langle n|\kmu_{n',n} \\ &= |1\rangle\langle 2|\kmu_{1,2} + |2\rangle\langle 1|\kmu_{2,1}. \end{aligned}$$

在后一个表达式中，我们把求和截断为只包含两个相关能级，并假设原子本征态$|1\rangle$和$|2\rangle$不具有相应的永久电偶极子，即$\langle 1|\hat{d}|1\rangle = \langle 2|\hat{d}|2\rangle = 0$。对于保持旋转对称性的孤立原子系统，情况就是如此。

系统的动力学由二能级原子与经典场的完整哈密顿量支配：

$$\kH = \hbar\komega|2\rangle\langle 2| - (|1\rangle\langle 2|\kmu_{1,2} + |2\rangle\langle 1|\kmu_{2,1}) \cdot \left(\kEenv e^{-i\knu \kt} + \kEenv^* e^{i\knu \kt}.\right). \tag{2.2}$$

为得到含时的原子态，我们在自由哈密顿量的本征态基中表示波函数

$$|\kpsi\rangle = \kcone(\kt)|1\rangle + \kctwo(\kt)|2\rangle. \tag{2.3}$$

注意原子本征态与时间无关，因此$|\kpsi\rangle$的全部时间依赖关系都包含在概率幅$\kcone(\kt), \kctwo(\kt)$中。

由薛定谔方程

$$i\hbar\frac{d}{d\kt}|\kpsi\rangle = \kH|\kpsi\rangle, \tag{2.4}$$

我们得到关于概率幅的耦合微分方程。

这些概率幅$\kcone(\kt)$和$\kctwo(\kt)$具有随时间快速演化的含时相对相位。通过变换到适当的转动参考系，我们可以消去运动方程中显含时间的项。具体地，我们将通过定义缓变振幅$\kctildetwo(\kt)$来改写上述方程，

$$\kctwo(\kt) = \kctildetwo(\kt)e^{-i\knu \kt}. \tag{2.5}$$

这里$\kmu = \kmu_{21}$，且$\kdelta = \knu - \komega$。这些方程可以数值求解，但很难解析处理。然而，当我们关心的是时标比光频$\knu$长得多的动力学时，这些方程还可以进一步简化。对于光场来说，这几乎总是成立的，此时$\knu \sim \text{THz}$；在其他情形下则必须更加小心。

我们所关心的动力学发生在与拉比频率成比例的频率上，

$$\kOmega = \kEenv\kmu/\hbar, \tag{2.8}$$

而且直观上不难理解，快速振荡的项平均而言对原子布居几乎没有影响。更定量地说，在下列情形下，我们可以做旋转波近似（RWA），忽略$\propto e^{\pm 2i\knu \kt}$的项：

$$\begin{aligned} &\text{(a) 场接近共振} : \kdelta \ll \knu, \komega \\ &\text{(b) 场很弱} : \kOmega \ll \knu \end{aligned} \tag{2.9}$$

正如我们前面所指出的，这些要求在实际的实验条件下往往可以满足，但肯定并非总是如此。

这些方程可以严格求解，但考察两种特殊情形的解可以获得许多深入的认识：恰好共振的场，以及与共振远失谐的场。

共振场$\kdelta = 0$

运动方程在$\kdelta = 0$时取特别简单的形式，因此概率幅按正弦和余弦演化。对于初始处于$|1\rangle$态的原子，布居在两个能级之间以频率$\kOmega$振荡。

从物理上讲，概率幅的绝对值对应于两个能级的布居$p_{1,2} = |c_{1,2}|^2$，二者反相振荡。这些“拉比振荡”对应于辐射的周期性吸收与受激发射。

并非所有感兴趣的量都像原子布居那样变化缓慢。例如，原子的瞬时极化可由偶极矩算符的期望值得到，

$$\langle\hat{d}\rangle = \kcone(\kt)^* \kctwo(\kt)\kmu^* + \kcone(\kt)\kctwo(\kt)^*\kmu. \tag{2.15}$$

极化既随$\kctwo(\kt)$演化的快时标$\knu$变化，也随布居演化的较慢时标$\kOmega$变化。还要注意，$\kOmega$与$\langle\hat{d}\rangle$之间存在相移；当我们研究光在原子介质中的传播时，这将变得很重要。

即使外加场振幅$|\kOmega(\kt)|$随时间变化，系统也有简单的解。在这种情形下，概率幅取决于外加场下的总面积。这可以通过对时间重新归一化$d\ktau = |\kOmega(\kt)|d\kt$或$\ktau = \int|\kOmega|d\kt$看出。

远失谐场$\knu \gg \kdelta \gg \kOmega$：绝热消除

运动方程对任意失谐都可以严格求解（只要旋转波近似仍然成立，$\knu \gg \kdelta$）。然而，发展近似技术是有益的，当我们考虑越来越复杂的系统时，这些技术将被证明是不可或缺的。在这里我们将介绍一种称为“绝热消除”的技术。

我们的物理直觉告诉我们，远离共振的场几乎不会引起向激发态的跃迁，即$|\kcone(\kt)| \approx 1, |\kctwo(\kt)| \ll 1$。在最低阶，我们可以考虑令$\kcone(\kt) = 1$。

我们将会看到，这并不是在这种情形下所能做出的最佳近似，但它确实让我们对$\kctwo(\kt)$的结构有所了解。具体地说，一项是常数，而另一项随（很大的）失谐$\kdelta$极快地振荡。在$\kt > 1/\kdelta$的时标上，快速振荡项的影响应当平均为零，因此要理解相关的缓慢演化的动力学，我们只需考虑常数项。

上述练习引出了绝热消除的概念，在其中我们忽略概率幅$\kctwo(\kt)$中随时间变化的部分，以求得相关的缓变动力学。更准确地说，我们要求解方程$\dot{\kctildetwo} = i\kdelta\kctildetwo + i\kOmega \kcone$，将$\kctildetwo$用$\kcone$表示。由于$i\kdelta\kctildetwo$非常大，$\kctildetwo$中随时间变化的部分将由平均为零的快速振荡主导，因而我们可以令$\dot{\kctildetwo} \approx 0$。这给出解$\kctildetwo$，它按照$\kctildetwo = -(\kOmega/\kdelta)\kcone$绝热跟随概率幅$\kcone$。把$\kctwo$的表达式代入式 (2.10)之后，我们得到$\dot{\kcone} = -i(|\kOmega|^2/\kdelta)\kcone$。

下态概率幅的演化就好像该态的能量移动了$|\kOmega|^2/\kdelta$，这一效应称为交流斯塔克偏移或“光致频移”。［注意，由于我们假设了$\kctwo(\kt) \approx 0$，所以无法从这一计算得到上态布居的能量移位；要做到这一点，需要从初始条件$\kctwo(0) = 1, \kcone(0) = 0$出发做类似的计算。］

远非共振的场对能量（以及本征态）诱导出一个按$|\kOmega|^2/\kdelta^2$标度的修正。因此我们的微扰处理只有在$\kOmega \ll \kdelta$时才成立。这一观察有助于理解旋转波近似成立的第二个要求，因为被忽略的项就像是相对于原子跃迁频率失谐$\pm 2\knu$的外加场。计入这些项会导致按$|\kOmega|^2/(2\knu)^2$标度的修正，因此要忽略它们，我们要求$|\kOmega| \ll \knu$。

缀饰态

刚才所描述的量子动力学，可以在所谓“缀饰”原子态的基中得到一种优美的诠释。这类态在涉及光与复杂系统相互作用的情形中尤为重要，在那里已经没有简单的解可用。

缓变振幅的运动方程（2.10，2.11）可以看作由有效哈密顿量得出

$$\kHtilde = -\hbar\kdelta|\tilde{2}\rangle\langle\tilde{2}| - \hbar(\kOmega|\tilde{2}\rangle\langle 1| + \kOmega^*|1\rangle\langle\tilde{2}|), \tag{2.23}$$

它不显含时间。这对应于做了旋转波近似之后、写在转动参考系中的原始哈密顿量。这个哈密顿量可以很容易地对角化。本征矢量$|\pm\rangle$是裸原子态$|1, 2\rangle$的混合，称为缀饰态；相应的本征能量为

$$\kepspm = \hbar\left(-\frac{\kdelta}{2} \mp \sqrt{(\frac{\kdelta}{2})^2 + |\kOmega|^2}\right). \tag{2.24}$$

在共振场$\kdelta = 0$中，缀饰态是裸原子态的对称组合和反对称组合，$|\pm\rangle$$= (|\tilde{1}\rangle \pm |\tilde{2}\rangle)/\sqrt{2}$，其中$|\tilde{1}\rangle$$= (|\kOmega|/\kOmega)\,|1\rangle$。它们的能量间隔是拉比频率的两倍，$2|\kOmega|$。共振时的量子动力学可以很容易地借助缀饰态图像来理解。具体地说，态$|1\rangle$是分裂态$|\pm\rangle$的对称叠加。随着系统随时间演化，$|\pm\rangle$的相位向相反的方向转动，经过时间$\kt = \pi/2\kOmega$之后，系统处于态$|\pm\rangle$的反对称叠加，这恰好对应于裸态$|\tilde{2}\rangle$。

远非共振的场$\kdelta \gg \kOmega$所导致的缀饰态，与原来的原子态非常相似，只混入了另一个态的少量成分。能量与本征态

$$\kepsm = \frac{|\kOmega|^2}{\kdelta} \qquad |-\rangle = |1\rangle - \frac{\kOmega}{\kdelta}|\tilde{2}\rangle \tag{2.25}$$
$$\kepsp = -\kdelta - \frac{|\kOmega|^2}{\kdelta} \qquad |+\rangle = |\tilde{2}\rangle + \frac{\kOmega^*}{\kdelta}|1\rangle \tag{2.26}$$

也接近于裸能量和本征态。

布洛赫球绘景

到目前为止，我们一直用两个复数$\kcone$和$\kctwo$来表示二能级原子，它们满足$|\kcone|^2 + |\kctwo|^2 = 1$。或者，二能级系统的态可以表示为单位球面上的一个矢量（见图 2.3）。指向正$\hat{z}$方向的矢量与态$|2\rangle$对应，而指向负$\hat{z}$方向的矢量则表示态$|1\rangle$。$\hat{x} - \hat{y}$平面内的矢量是叠加态$\left(|1\rangle + e^{i\phi}|2\rangle\right)/\sqrt{2}$。在布洛赫球绘景中，转动参考系有一种特别漂亮的诠释：我们从一个绕$\hat{z}$轴以光频$\knu$转动的参考系来看这个矢量。

把这个矢量解释为磁偶极子，系统的动力学可以看作是绕有效磁场的进动所产生的结果。具体地，设$\kOmega = 0$。在裸参考系中，矢量绕$\hat{z}$轴以频率$\komega$进动。把一个“自旋”$\{\kcone, \kctwo\}$与相应的自旋算符等同起来，

$$\hat{S}_z = |2\rangle\langle 2| - |1\rangle\langle 1| \tag{2.27}$$
$$\hat{S}_x = |1\rangle\langle 2| + |2\rangle\langle 1| \tag{2.28}$$
$$\hat{S}_y = -i|2\rangle\langle 1| + i|1\rangle\langle 2|, \tag{2.29}$$

我们可以把哈密顿量改写为一个有效磁场：

$$\kH = \hbar\komega|2\rangle\langle 2| \rightarrow \frac{\hbar\komega}{2}\left(1 + \hat{S}_z\right). \tag{2.30}$$

变换到转动参考系，

$$\kH = -\hbar\kdelta|\tilde{2}\rangle\langle\tilde{2}| \rightarrow -\frac{\hbar\kdelta}{2}\left(\hat{S}_z + 1\right). \tag{2.31}$$

我们也可以把外加场$\kOmega$理解为一个有效磁场。具体地，式 (2.23)的有效哈密顿量变为

$$\kH = -\frac{\hbar\kdelta}{2}\left(\hat{S}_z + 1\right) - \hbar\left(\mathrm{Re}\,\kOmega\right)\hat{\tilde{S}}_x - \hbar\left(\mathrm{Im}\,\kOmega^*\right)\hat{\tilde{S}}_y, \tag{2.32}$$

其中$\hat{\tilde{S}}_{x,y}$是自旋在转动参考系中的$\hat{x}, \hat{y}$分量。式 (2.32)中的常数项可以忽略，因为它只给系统贡献一个整体相位。于是在海森伯绘景中，作为一个有益的练习，可以证明式 (2.32)的哈密顿量导致如下运动方程

$$\frac{d}{d\kt}\kStilde = \kOmegavec(\kt) \times \kStilde, \tag{2.33}$$

其中矢量$\kStilde = \left\{\tilde{S}_x, \tilde{S}_y, \tilde{S}_z\right\}$，$\kOmegavec(\kt) = \{-2\,\mathrm{Re}\,\kOmega(\kt), -2\,\mathrm{Im}\,\kOmega^*(\kt), -\kdelta\}$。式 (2.33)类似于磁偶极子在磁场中的运动方程，并给出了二能级系统动力学的一种漂亮的可视化，如图 2.3所示。即使在二能级动力学中包含自发发射和退相位之类的过程，这种布洛赫绘景仍然方便。

向多态系统的推广

处理二能级原子的技术同样适用于多态系统，其中每个原子跃迁在共振附近至多有一个缓变场。为说明如何把二能级计算推广到多个能级，我们考虑一个具有单一基态$|1\rangle$和许多激发态$|k\rangle$的原子。每个激发态与$|1\rangle$之间由一个振幅为$\kEenv_k$、频率为$\knuk$的场耦合，而第$k$个跃迁的偶极矩阵元为$\hat{d}_{k,1} = \kmu_k|k\rangle\langle 1| + \kmu_k^*|1\rangle\langle k|$。偶极子与场之间的相互作用有四项，应用旋转波近似将其截断为两项，从而得到哈密顿量

$$\kH_{RWA} = \sum_k \hbar\komegak|k\rangle\langle k| - \hbar\sum_k\left(\kOmegak e^{-i\knuk \kt}|k\rangle\langle 1| + \kOmegak^* e^{i\knuk \kt}|1\rangle\langle k|\right) \tag{2.34}$$

其中$\komegak$是第$k$个跃迁的能量，$\kOmegak = \kEenv_k\kmu_k/\hbar$。

尽管每个激发态的快速相位演化各不相同，我们仍然可以通过做一个幺正变换，从哈密顿量中去掉显含的时间依赖，由算符表示

$$\hat{U} = e^{-i\sum_k \knuk \kt|k\rangle\langle k|}. \tag{2.35}$$

态矢量$|\kpsi\rangle$在由$\hat{U}|\tilde{\psi}\rangle = |\kpsi\rangle$定义的新基中表示。由于$\hat{U}(\kt)$依赖于时间，当我们变换到这个新基时，它会在哈密顿量中引入新项。

通过应用旋转波近似并变换到每个原子态以相应光频转动的参考系，我们找到了一个使哈密顿量与时间无关的基。同样的方法适用于具有许多基态和许多激发态的多能级系统，只要没有任何一个原子跃迁与多于一个外加场相联系。在后面的计算中，我们通常会在转动参考系中工作，因此为记号方便起见，可以去掉波浪号。

当两个场都与同一个跃迁近共振时，这些技术就失效了。如果我们变换到以第一个场的频率转动的参考系，哈密顿量仍将保留一个与第二个场相关的时间依赖。例如，假设前面考虑过的二能级系统现在受到两个外加场的作用，其拉比频率为$\kOmega_a$和$\kOmega_b$，光频为$\knu_a$和$\knu_b$。运动方程（在旋转波近似和转动参考系中）现在包含一个以拍频$\kDelta = \knu_a - \knu_b$振荡的项：

$$i\hbar\dot{\kctildetwo}(\kt) = -\hbar\kdelta\kctildetwo(\kt) - \hbar\left(\kOmega_a + \kOmega_b e^{i\kDelta \kt}\right)\kcone(\kt) \tag{2.40}$$
$$i\hbar\dot{\kcone}(\kt) = -\hbar\left(\kOmega_a^* + \kOmega_b^* e^{-i\kDelta \kt}\right)\kctildetwo(\kt). \tag{2.41}$$

求解这些方程需要把概率幅展开为傅里叶级数$c_i = \sum_n c_i^{(n)}e^{in\kDelta \kt}$，这也称为“弗洛凯基”。不同的傅里叶分量彼此全部耦合，因此概率幅随拍频及其所有高次谐波演化。这个简单的例子说明了非线性光学背后的一种机制。
