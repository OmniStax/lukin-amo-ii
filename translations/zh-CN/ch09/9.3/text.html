我们已经看到，相干态的线性变换保持其经典性质，而非线性相互作用则导致辐射场的高度非平庸的量子态。然而，经验告诉我们，现实世界既是非线性的，又是经典的。要理解这是如何发生的以及为何发生，我们就必须考虑耗散对量子场的影响。

分束器为损耗提供了一个直观而简单的模型。信号入射到分束器上，按其振幅透射率$t$衰减；同时，入射到另一端口的真空场引入涨落，使输出场为

$$\hat{a}_\mathrm{out} = t\hat{a}_\mathrm{in} + i\sqrt{1-|t|^2}\hat{b}_\mathrm{vac}. \tag{9.80}$$

如果信号最初处于相干态$|\kalphacoh\rangle$，则透射场也将是相干态$|t\kalphacoh\rangle$。但对任意量子态，这一点并不成立。例如，入射的福克态在与分束器相互作用之后将不再处于福克态。

9.3.1 有耗腔中单模场的动力学

我们现在希望更详细地考虑耗散对量子场的影响。为简单起见，我们在此着重讨论单模场，例如光学腔中的场。不过，我们将处理一个腔并不完美、而是与外部世界耦合的更现实的情景。

分束器模型可用于理解由一面部分透射镜构成的腔中的耗散。起初，我们只考虑经典损耗，而忽略与之相伴的量子噪声。

经典演化

腔内场的经典演化方程可以通过计算$\kEcav$在一次往返中的变化求得。这里$t$和$r$是左侧镜的透射系数和反射系数，$\kDeltat = 2\kLmed/c$是往返时间，$\kEcav_\mathrm{in}(\kt)$是入射到腔上的场。

对于完美的镜子，$r^2 + t^2 = 1$，因此我们可以在$t \ll 1$的极限下写出腔损耗率。

将演化方程变换到傅里叶域，即可求得腔的响应函数。腔线型为洛伦兹线型，其宽度由腔损耗率给出。

若腔内存在任何介质，则所感生的原子极化强度将修改场的演化。将麦克斯韦方程组投影到腔模上（即对于缓变振幅，忽略$\sim d\kEcav/dz$的项），我们发现腔场的演化为

$$\frac{d}{d\kt}\kEcav(\kt) = -\frac{\kkappa}{2}\kEcav(\kt) + \sqrt{\frac{\kkappa c}{2\kLmed}}\kEcav_\mathrm{in}(\kt) + \frac{i\knubar\kPnl}{2\epsilon_0}, \tag{9.87}$$

其中$\knubar$是腔共振的中心频率。

输出场由反射的输入场与透射的腔场之和给出，

$$\kEcav_\mathrm{out} = -r\kEcav_\mathrm{in} + t\kEcav. \tag{9.88}$$

这一方程称为“输入输出关系”，关于腔中电磁场半经典分析的一份好的参考文献见萨金特、斯库利和兰姆的“Laser Physics”。

9.3.2 腔模的量子力学处理

把经典演化方程改造为量子描述，我们只需将腔场$\kEcav$替换为腔光子湮没算符$\hat{a}$，并计入与腔衰变率$\kkappa$相关的噪声。如果输入场为零，则演化方程变为

$$\frac{d}{d\kt}\hat{a} = \frac{-\kkappa}{2}\hat{a} + \kFnoise. \tag{9.89}$$

原则上，我们可以利用量子涨落耗散定理来确定噪声算符$\kFnoise$的性质。但我们转而通过引入噪声的微观模型来突出涨落的物理起源。我们所添加的噪声实际上非常像我们在式 (9.89)中忽略的输入场项，这里我们现在计入外部真空场经部分透射镜泄漏进入腔中。

微观噪声模型

我们的微观噪声模型将计入量子腔场与其连续区模的环境之间的相互作用。不完美的镜子提供了腔与热库之间的耦合，因为腔光子可以漏出，而热库光子可以漏入。在相互作用绘景中，系统-热库相互作用的有效哈密顿量可以写成

$$\hat{V}_{SR} = i\hbar\sum_k t_k \hat{a}\hat{a}_k^\dagger e^{-i(\knu-\knuk)\kt} + h.c., \tag{9.90}$$

其中$\knu$是腔频率，$\hat{a}_k$是频率为$\knuk$的一个连续区模，腔模与$\hat{a}_k$之间的耦合系数$t_k$由构成腔的镜子的透射性质决定。当环境很大且带宽很宽时，这一相互作用哈密顿量在数学上等价于先前考虑的原子自发发射模型。为了与我们的形式化方法建立联系，我们把系统算符和热库算符确定为

$$\hat{S} = \hat{a} \tag{9.91}$$
$$\hat{R}^\dagger = i\hbar\sum_k t_k \hat{a}_k^\dagger. \tag{9.92}$$

利用我们先前建立的一般热库理论，我们可以立即用微观定义的量写出衰变率和噪声算符。简要回顾一下，热库场的演化方程可以形式上积分，在适当的转动参考系中给出

$$a_k(\kt) = e^{i(\knu-\knuk)\kt}a_k(0) + t_k\int_0^{\kt} d\kt'\, e^{i(\knu-\knuk)(\kt-\kt')}a(\kt'), \tag{9.93}$$

而将其代回$a(\kt)$的运动方程则给出

$$\dot{a}(\kt) = -\sum_k t_k e^{i(\knu-\knuk)\kt}a_k(0) - |t_k|^2\int_0^{\kt} d\kt'\, a(\kt')e^{i(\knu-\knuk)(\kt-\kt')}. \tag{9.94}$$

作维格纳-韦斯科普夫近似，我们得到

$$\dot{a}(\kt) \approx -\frac{\kkappa}{2}a(\kt) + \kFnoise(\kt), \tag{9.95}$$

其中

$$\kkappa = 2\pi\sum_k |t_k|^2\delta(\knu-\knuk) = 2\pi|t_k|^2 D(\knu) \tag{9.96}$$
$$\kFnoise = -\sum_k t_k\hat{a}_k(0)e^{i(\knu-\knuk)\kt}. \tag{9.97}$$

有了这些表达式，我们就可以轻松地计算噪声算符的有关关联函数。例如，如果环境处于频率为$\knu$、光子数为$n$的热态，

$$\langle\kFnoise(\kt)\kFnoise^\dagger(\kt')\rangle = (n+1)\kkappa\delta(\kt-\kt') \tag{9.98}$$
$$\langle\kFnoise^\dagger(\kt)\kFnoise(\kt')\rangle = n\kkappa\delta(\kt-\kt'). \tag{9.99}$$

微观噪声模型为涨落和耗散的起源提供了物理图像。部分透射镜允许腔场漏出（导致衰变），但也允许连续区模漏入（导致噪声）。利用关系式$t_k = (\kkappa/2\pi D(\knu))^{1/2}$，噪声算符为

$$\kFnoise(\kt) = -\sqrt{\frac{\kkappa}{D(\knu)}}\kEhat_\mathrm{in}(\kt), \tag{9.100}$$

其中我们定义了输入场

$$\kEhat_\mathrm{in}(\kt) = \sqrt{\frac{1}{2\pi}}\sum_k e^{i(\knu-\knuk)\kt}a_k(0). \tag{9.101}$$

我们曾用海森伯-朗之万方法来描述腔的量子力学演化，但主方程提供了一种等价的替代方法。如果我们再次把系统算符确定为$\hat{S} = \hat{a}$，则系统密度算符服从主方程

$$\frac{d}{d\kt}\krhohat = -\frac{\kkappa}{2}(n+1)\left(\hat{a}^\dagger\hat{a}\rho - \hat{a}\rho\hat{a}^\dagger\right) - \frac{\kkappa}{2}n\left(\rho\hat{a}\hat{a}^\dagger - \hat{a}^\dagger\rho\hat{a}\right) + h.c. \tag{9.102}$$

它可用于描述腔损耗及相伴的涨落。

例子：相干态

设腔场最初处于相干态$|\kalphacoh\rangle$，而辐射热浴最初处于真空态。由于腔的相干态对应于经典场的量子描述，人们可能预期它在腔模衰变时仍保持为经典场。

经典相干性随时间按指数式衰减，遵循电场振幅的衰减。

为了验证我们确实处于相干态，我们应当考察正交分量。

由于相干态最初有$\langle\delta\kxquad^2(0)\rangle = 1/2$，$\langle\delta\kxquad^2(\kt)\rangle$在所有时刻都保持为$1/2$。对动量正交分量作类似的计算得到同样的结果，表明随着系统演化，腔模仍保持在相干态，$\langle\delta\kxquad^2(\kt)\rangle = \langle\delta\kpquad^2(\kt)\rangle = 1/2$，尽管平均光子数（因而相干振幅$\kalphacoh$）随时间衰减。

量子场的演化

我们发现相干态尽管有腔损耗仍保持其经典相干性，而一般的量子态将随着腔场的耗散而改变其性质。我们在式 (9.107)中对正交分量算符的推导并不依赖于初态，因此在长时间下，无论初始的正交分量如何，我们都得到$\langle\delta\kxquad^2(\kt)\rangle = \langle\delta\kpquad^2(\kt)\rangle = 1/2$。因此，最初压缩的量子态会由于腔衰变而失去其非经典相干性质。

一般而言，产生非经典态的过程必须与耗散竞争。例如，我们已经看到，当忽略耗散时，非经典态可以由单模光与非线性介质（如二能级原子）相互作用产生。当我们同时计入原子与不受约束的辐射模的相互作用以及腔模与连续谱的相互作用时，我们将发现由此产生的耗散起着抹去任何非经典关联的作用。

合适的理论方法取决于所考虑系统的一些细节。例如，在强场与许多原子相互作用的极限下，动力学应当近乎经典。因此使用海森伯-朗之万方法是合理的，该方法明确地显示了与经典动力学的对应。与原子的相互作用给出了腔模演化中的一个驱动项，

$$\frac{d}{d\kt}\hat{a} = -\frac{\kkappa}{2}\hat{a} + \kFnoise + i\sum_j \kg_j^*\hat{\sigma}_{\alpha,\beta}, \tag{9.108}$$

它描述了介质极化强度的量子力学类比。这类演化方程通常是非线性的，一般无法求解，只有某些特殊情形除外。作为例子，我们将考虑压缩光的产生。

同时，在只有少数光子或少数原子存在的情形下，随机波函数方法或主方程往往更为方便。例如，这类光子和原子都很少的系统出现在腔量子电动力学或陷俘离子的量子态工程中。

9.3.3 腔量子电动力学

腔量子电动力学（CQED）提供了另一个重要的例子，在这类系统中耗散和量子效应都起着重要作用。与描述宏观场同许多原子相互作用之性质的压缩光产生不同，CQED 通常代表一个光子很少、与单个原子相互作用的小系统。因此，我们对 CQED 的讨论将提供一个处理小系统的精确方法的例子。

所考虑的物理系统由一个二能级原子构成，其能级为$|1\rangle$和$|2\rangle$，以速率$\kg$耦合到一个单模腔。除了我们在前面几讲中考虑过的相干演化之外，我们还将计入两个耗散速率：原子以速率$\kgamma$发射到自由空间模（腔模除外）中，而光子以速率$\kkappa$从腔中漏出。

开腔与闭腔

在实践中，区分两种情形是有用的。开腔情形描述在一个维度上受约束的腔模，腔长远大于波长，$\kLmed \gg \klambda$。这种情形通常出现在光学频率的 CQED 中，其中采用法布里-珀罗型腔来约束光。处于开腔中的原子的自发发射率$\kgamma$接近其自由空间衰变率，因为它可以很容易地与在垂直于腔模的两个方向上不受约束的自由空间模相互作用。

闭腔在全部三个空间维度上约束场，其长度尺度接近波长，$\kLmed \sim \klambda$。这样的腔可以为微波频率构建，其波长为毫米到厘米量级。处于闭腔中的原子只能与少数腔模相互作用，因此其自发发射率相对于自由空间发射率可以被强烈抑制。

理论表述

为了计入两种耗散机制$\kkappa, \kgamma$，我们需要把两类衰变都纳入主方程

$$\begin{aligned} \dot{\krhohat} &= -\tfrac{i}{\hbar}[\kH,\krhohat] - \tfrac{\kkappa}{2}\left(\hat{a}^\dagger\hat{a}\krhohat + \krhohat\hat{a}^\dagger\hat{a} - 2\hat{a}\krhohat\hat{a}^\dagger\right) \\ &\quad - \tfrac{\kgamma}{2}\left(\hat{\sigma}_{21}\hat{\sigma}_{12}\krhohat + \krhohat\hat{\sigma}_{21}\hat{\sigma}_{12} - 2\hat{\sigma}_{12}\krhohat\hat{\sigma}_{21}\right). \end{aligned} \tag{9.109}$$

注意，这里的密度算符同时包含原子和腔模的自由度，因为它代表总系统。

相干演化由把原子算符$\hat{\sigma}_{ij}$与腔模$\hat{a}$耦合起来的J-C 哈密顿量描述

$$\kH = \hbar\kdelta\hat{a}^\dagger\hat{a} + \hbar \kg\hat{a}^\dagger\hat{\sigma}_{12} + \hbar \kg^*\hat{a}\hat{\sigma}_{21}, \tag{9.110}$$

其中我们在以原子跃迁频率$\komega$转动的参考系中工作，$\kdelta$是腔模的失谐，$\kdelta = \knu - \komega$。由于我们想考虑腔中光子很少的量子态，这个问题的自然基矢态是腔模的福克态和裸原子态：

$$\{|1\rangle_a|n\rangle, |2\rangle_a|n\rangle\}. \tag{9.111}$$

每一对态$\{|1\rangle_a|n\rangle, |2\rangle_a|n-1\rangle\}$以强度$\kg\sqrt{n}$耦合。但当我们加入耦合$\{|1\rangle_a|n\rangle \to \{|1\rangle_a|n-1\rangle$和$\{|2\rangle_a|n\rangle \to \{|1\rangle_a|n\rangle$的耗散机制时，在这组基中动力学将显得更为复杂。

缀饰态基中的 CQED

为了获得对耗散的原子-腔系统的直观理解，变换到J-C 哈密顿量的缀饰态基是有启发的。如图 9.8所示，每一组耦合态都可以独立地对角化，而耗散则在各组之间引入耦合。

探测缀饰态流形最简单的实验方法，是测量原子-腔系统的反射率随入射光失谐的变化。外加场将探测基态与低位缀饰态之间的跃迁。即使原子跃迁与腔模精确共振，原子-场耦合$\kg$也会表现为反射率中峰与峰之间的分裂。因此，缀饰态的分裂$\kg$常被称为“真空拉比分裂。”注意，如果腔的波腹处有$N$个原子，分裂将增大到$\kg\sqrt{N}$，这一效应称为集体增强。按经典的观点，这一效应可以理解为通过改变光在腔内循环时获得的相移而使腔的共振频率发生移动的原子色散的表现。

随机波函数分析

设在时刻$\kt = 0$系统从腔的真空态和原子的激发态$|2\rangle_a|0\rangle$出发。随着系统演化，它能够跃迁到的态只有少数几个。具体而言，可能的跃迁是：

  1. 自由空间发射耦合$|2\rangle_a|0\rangle \to |1\rangle_a|0\rangle$
  2. 相干演化耦合$|2\rangle_a|0\rangle \to |1\rangle_a|1\rangle$
  3. 腔衰变耦合$|1\rangle_a|1\rangle \to |1\rangle_a|0\rangle$。

因此我们只需计入三个态，主方程原则上可以精确求解。我们将使用随机波函数方法，它将提供我们理解无跳跃情形中所涉及的物理过程所需的全部基本要素。

在量子跳跃不重要的情形下，我们将考虑一个只包含由哈密顿量演化所耦合的那些态的波函数

$$|\kpsi\rangle = \kconeone|1\rangle_a|1\rangle + \kctwozero|2\rangle_a|0\rangle. \tag{9.112}$$

概率幅的哈密顿量演化方程为

$$\dot{\kconeone} = i\kdelta \kconeone + i\kg\kctwozero \tag{9.113}$$
$$\dot{\kctwozero} = i\kg\kconeone. \tag{9.114}$$

耗散通过非厄米有效哈密顿量进入

$$\kHeff = -i\frac{\kkappa}{2}\hat{a}^\dagger\hat{a} - i\frac{\kgamma}{2}\hat{\sigma}_{21}\hat{\sigma}_{12}, \tag{9.115}$$

于是“无跳跃”演化方程变为

$$\dot{\kconeone} = -(\frac{\kkappa}{2} - i\kdelta)\kconeone + i\kg\kctwozero \tag{9.116}$$
$$\dot{\kctwozero} = i\kg\kconeone - \frac{\kgamma}{2}\kctwozero. \tag{9.117}$$

事实上，由于丢失的光子不可能被重新吸收回系统——即态$|1\rangle_a|0\rangle$是不耦合的——非厄米演化是精确的。考察这些方程，我们可以看到，在强原子-场耦合极限$\kg \gg \kgamma, \kkappa$下，系统表现出弱阻尼的与单光子腔态之间的拉比振荡。然而，当$\kg$小于其中一个耗散速率时，仍可观察到许多有趣的效应。

开腔：珀塞尔效应

当腔衰变率压倒原子-场耦合，$\kg < \kkappa$时，由于场模是过阻尼的，我们可以采用绝热消除$\dot{\kconeone} \approx 0$。强阻尼的腔场影响原子态的演化。

第一项表明原子的衰变率因其与过阻尼腔模的耦合而被修改，而第二项描述一个能量移位，它表示兰姆移位受到腔模的修改。根据所涉及的腔的类型，所得的原子衰变率可以大于或小于自由空间自发发射率。对于开腔，$\kgamma \approx \kgamma_\text{自由空间}$，因此在零失谐时原子衰变率被增强。

自发发射率的这一增大称为“珀塞尔效应。”

支配这一效应的物理参数涉及腔模体积$\kV$和品质因数$\kQfac$：

$$\kg = \kmu\sqrt{\frac{\knu}{\epsilon_0\hbar \kV}} \tag{9.121}$$
$$\kkappa = \frac{\knu}{\kQfac}, \tag{9.122}$$

其中$\knu$是腔模角频率。腔衰变率也可以用腔精细度 F 来表示，精细度是光子在漏出之前平均在腔中循环的次数。光子寿命是精细度乘以腔中的往返时间

$$\frac{1}{\kkappa} = \frac{\kLmed}{\pi c}\cdot \kFfin. \tag{9.123}$$

强耦合的物理

为了使衰变率$\kgammaeff^\mathrm{open}$相对于$\kgamma$发生显著改变，我们需要有足够的原子-场耦合

$$\kg^2 > \kgamma\kkappa. \tag{9.124}$$

当这一条件满足时，称系统处于“强耦合情形”。事实上，强耦合的优值与原子参数无关，因为偶极矩同时出现在$\kg$和$\kgamma$中。

这里$d$是腔模的直径。长度为$\kLmed$的腔的衍射极限给出$d^2 \sim \klambda \kLmed$，因此对于具有高反射率$r^2 = 1 - t^2$的小腔，优值达到最大。

从物理上说，当开腔处于强耦合情形时，置于腔中的激发态原子把能量转移给腔模的速度，远快于它向$4\pi$发射的速度，因为$\kg > \kgamma$。由于$\kg < \kkappa$，腔模随后会在原子来得及重新吸收光子之前衰变。实际上，原子中的激发衰变到从腔中漏出的光子态中。

我们可以看到强耦合情形的另一种物理图像，只要认识到原子的共振截面为$\sim \klambda^2$。原子在光子从腔中衰变之前与光子相互作用的概率为

$$P_\mathrm{interaction} \sim \klambda^2\cdot \kLmed\cdot\frac{1}{\kLmed d^2}\cdot \kFfin, \tag{9.127}$$

其中$1/\kLmed d^2$是原子密度，$\kFfin$是光子遇到原子的次数。在强耦合情形中，这一概率大于一。

闭腔：被抑制的衰变

约束在闭腔中的原子不能自发发射到不受约束的模中，因此$\kgamma = 0$。

当腔相对于原子共振远失谐，$\kdelta \gg \kkappa$时，原子衰变率被强烈抑制，因为在原子跃迁能量处没有态密度。这一效应已在微波实验中观察到，其中腔的尺寸与波长同量级，$\kLmed \sim \klambda$，而且失谐最大，$\kdelta = \komega/2$。

对于闭腔，$\kV \sim \klambda^3$，因此衰变率被腔的品质因数所抑制。

里德伯原子的微波 CQED

与光学 CQED 相比，微波 CQED 有若干优点。首先，可以构建闭腔，而且原子发射率$\kgamma \propto \komega^3$比光学频率下小得多。由于耦合强度$\kg \propto \sqrt{\komega}$，转到较低的频率可以使$\kg/\kgamma$得到可观的改善。最后，可以利用里德伯原子的大偶极矩来设计具有大耦合常数$\kg$的系统。高激发里德伯原子$N \sim 50$的跃迁频率处于微波范围$\sim$ 10-100 GHz，因此合适的腔的尺寸约为一厘米。此外，原子态可以通过测量使原子电离所需的电场来测量，这提供了分析最终原子态的一种方便机制。

较低的频率也带来潜在的问题。典型的里德伯原子可以在光学频率下衰变到低位激发态，这将妨碍微波操控。因此，使用里德伯原子的实验必须把它们抽运到所谓的角动量最大的圆态中，其中选择定则只允许一条微波衰变通道。因此，圆里德伯原子的寿命可以很长，量级为一秒。虽然把原子激发到 N=50 L=50态需要 50 个微波光子，但巴黎和慕尼黑的研究组仍常规地制备圆里德伯原子。

第二个问题出现在微波频率，因为热光子不能忽略。因此，微波腔通常由超导铌构成，并冷却到液体氦温度。还可以采用额外的技巧，通过送入处于基态的原子来吸收多余的能量，从而把热光子从腔中清空。凭借巧妙的技巧和精心的工程设计，微波 CQED 实验在量子态工程领域展示了相干演化与退相干之间最高的比值。

应用：按需单光子

CQED 的一个潜在应用是创造一种可被触发的光源，使其恰好发射一个光子到频率、时间、方向和形状都明确的波包中。这样的器件之于福克态，正如激光之于相干态，但福克态的非经典本性使其构建困难得多。

人们可以设想把一个单独的激发发射体放入一个腔中，并监测从腔中的泄漏。单个发射体通常会向$4\pi$发射一个光子，但腔可以用来改善方向性。在强耦合情形中，被激发的发射体主要与腔模$\hat{a}$相互作用，后者随后通过哈密顿量与自由场模$\hat{a}_k$相互作用

$$\hat{H}_{c-f} = -\hbar\sum_k t_k\hat{a}_k^\dagger\hat{a}e^{i\kdeltak \kt} + h.c. \tag{9.130}$$

包括连续区模在内的系统态可以表示为

$$|\kpsi\rangle = \kctwozero|2\rangle_a|0\rangle|vac\rangle + \kconeone|1\rangle_a|1\rangle|vac\rangle + \sum_k \kck|1\rangle_a|0\rangle|1_k\rangle. \tag{9.131}$$

这一过程的物理恰好就是束缚态到自由态的跃迁，所以我们可以利用维格纳-韦斯科普夫理论的结果，求出在长时极限和强耦合情形下自由空间模的概率幅：

$$\kck \sim \frac{t_k \kg/\kkappa}{\kg^2/\kkappa + i\kdeltak}. \tag{9.132}$$

一个单光子波包将沿腔模所定义的方向发射，其电场包络为$\sim e^{-(\kg^2/\kkappa)\kt}$。这个系统还不是理想的单光子源，因为我们无法控制脉冲的时间和形状。通过使用三能级原子，可以控制所发射的波包形状。

原则上，这一单光子发射过程是相干的，因而是可逆的。例如，如果原子最初处于基态与激发态的叠加，$(a|1\rangle + b|2\rangle)\otimes|\mathrm{vac}\rangle$，则这一相干叠加将被映射到沿远离腔方向传播的光子模上，于是态将变为$|1\rangle\otimes\left(a + b\hat{a}^\dagger\right)|\mathrm{vac}\rangle$。通过对脉冲传播作时间反演，人们可以设想随后把这一量子态（编码在正交光子态的叠加中）存回原子态。虽然这类想法已获得相当多的理论关注，但实验尚未用腔量子电动力学实现相干的光子释放与存储。

单光子场的测量

按需单光子的实验演示需要区分少量光子。存在这样的光电探测器，它们通过产生宏观光电流脉冲的雪崩过程，以高效率测量单个光学光子。然而，由于死时间效应，无法区分含有多个光子$|1\rangle, |2\rangle, |3\rangle\ldots$的短（$<$ 100 ns）波包。

为了研究短脉冲的非经典性质，可以采用汉伯里·布朗-特维斯装置，它在把信号送到两个探测器之前，先用分束器将其分开。如果一个单光子入射到分束器上，两个探测器永远不会同时记录。这种同时探测是联合概率测量的一个例子。对两个被探测信号之间关联的完整测量，可用于得到二阶关联函数

$$G^{(2)} = \langle\kEenv^\dagger(r_1,\kt_1)\kEenv^\dagger(r_2,\kt_2)\kEenv(r_2,\kt_2)\kEenv(r_1,\kt_1\rangle. \tag{9.133}$$

$G^{(2)}$对于相干态可以因式分解，但对于非经典态不能因式分解。因此，定义一个归一化的关联函数是方便的

$$\kgtwo(\kt_1 - \kt_2) = \frac{G^{(2)}}{\langle\kEenv^\dagger(r_1,\kt_1)\kEenv(r_1,\kt_1\rangle\langle\kEenv^\dagger(r_2,\kt_2)\kEenv(r_2,\kt_2)\rangle}. \tag{9.134}$$

例如，$\kgtwo(0)$对于相干态为 1，对于热态为 2（光子“群聚”），对于单光子态为 0（光子“反群聚”）。对二阶关联函数的测量显然对比激光束的经典相干性更高阶的量子相干性敏感。这类测量之所以有用，是因为非经典态可以表现出高阶关联，而不仅仅是经典相干性$\langle\kEenv^\dagger(r_1,\kt_1)\kEenv(r_2,\kt_2)\rangle$。
