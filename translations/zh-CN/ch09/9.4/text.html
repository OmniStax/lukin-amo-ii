线性放大

我们已经看到噪声如何抑制受衰变作用的场模的量子关联。线性放大同样会给场的初态增加噪声，因为它总是涉及自发发射过程。线性放大器的增益及与之相关的噪声，可以用由反转的二能级原子或反转的谐振子构成的气体来建模。对于增益系数$\ksigmagain > 1$，可以导出一个非常一般的结果：

$$\hat{a}_\mathrm{out} = \sqrt{\ksigmagain}\hat{a}_\mathrm{in} + \sqrt{\ksigmagain - 1}\hat{b}^\dagger, \tag{9.135}$$

其中噪声算符$\hat{b}^\dagger$类似于真空噪声，但其作用相当不同，因为它来自自发发射过程。与其他噪声算符一样，它保证场算符的对易关系不随时间增长或衰减。额外的噪声与指出任意的量子态不能被复制的量子不可克隆定理有关。同样，我们在这里发现，量子态不可能在放大时不因附加噪声而丢失一些信息。

9.4.1 非线性放大

我们已经看到，非线性光学现象产生光的非经典态，而损耗则起着破坏非经典关联的作用。这两种相互竞争的机制之间的相互作用，可以用一个具体的例子来说明：压缩光的产生。我们将首先说明如何通过无损耗的下转换过程产生压缩态，然后讨论损耗和噪声的影响。

简并参量下转换

我们对参量下转换的半经典描述，描述了由强抽运场$\kEenv_0$产生一对场$\kEenv_1$和$\kEenv_2$，其中$\knu_1 + \knu_2 = \knu_0$且$\kDeltakmis = 0$。远离原子共振时，驱动$\kEenv_1$和$\kEenv_2$的极化强度既包含线性电极化率，也包含非线性电极化率：

$$\kPnl_1 \sim \frac{\kchiII}{2}\kEenv_0\kEenv_2^* + \frac{\kchi_1}{2}\kEenv_1 \tag{9.136}$$
$$\kPnl_2 \sim \frac{\kchiII}{2}\kEenv_0\kEenv_1^* + \frac{\kchi_2}{2}\kEenv_2. \tag{9.137}$$

产生压缩光的一种方法，是对约束在腔中的场使用参量下转换的简并形式。频率为$\knu_0$的抽运场驱动腔内的非线性介质，腔的频率$\knu_c = \knu_0/2$决定$\kEenv_1$和$\kEenv_2$的频率，$\knu_1 = \knu_2 = \knu_c$。假设偏振相匹配，两个较低频率的场相同，$\kEenv_1 = \kEenv_2$。腔中这种参量下转换的简并形式常被称为“简并光学参量振荡器”（OPO）。

以腔频率振荡的极化强度（它产生场$\kEenv_1 = \kEenv_2$）包含来自两个相干性的效应

$$\kPnl = \kmu_{31}\krhothreeone + \kmu_{23}\rho_{23} \tag{9.138}$$
$$\sim \kchiII\kEenv_0\kEenv_1^* + \frac{\kchi_1 + \kchi_2}{2}\kEenv_1. \tag{9.139}$$

腔内场$\kEenv_1$的演化方程将含有来自这一极化强度的驱动项。在相位匹配条件下，

$$\frac{\partial\kEenv_1}{\partial \kt} = i\kbetagain\kEenv_1^* \tag{9.140}$$
$$\frac{\partial\kEenv_1^*}{\partial \kt} = -i\kbetagain^*\kEenv_1, \tag{9.141}$$

其中$\kbetagain$把抽运功率和非线性电极化率合并为一个常量。这些方程看起来可能类似于场在线性介质中的传播，那里$\dot{\kEenv} \sim \kbetagain\kEenv$。然而在这种情形下，场的演化与其复共轭的演化不同，所以我们需要仔细跟踪相位。

依赖相位的放大

由于$\kbetagain$的相位是任意的（只有$\kEenv_1$与$\kbetagain$的相对相位才起作用），我们可以自由地选取它为纯虚数，$\kbetagain = i\kbetatilde$。为了使演化方程解耦，我们将在简正模式基$\kEpm = \kEenv_1 \pm \kEenv_1^*$中工作。

一个简正模式被放大，而另一个被去放大，且增益显含$\kEenv_1$相对于$\kbetagain \propto$ $\kEenv_0$的初始相位。当$\kEenv_1$为实数时，对于$\kbetatilde > 0$，场被衰减，而如果$\kEenv_1$为虚数，则场被放大。

量子力学方法

我们希望能把对简并参量下转换的经典描述转换成量子力学的版本。最简单的做法是把腔内电场的值换成腔内光子的湮没算符$\kEenv \to \hat{a}$。这样一种朴素的代换，对于由线性运动方程描述的无损耗系统事实上是成立的，所以在这种情形下它恰好行得通。然而，它一般并不成立，我们可以用一种更严格的方法来说明这个简单情形是如何出现的。

我们的量子力学处理将描述宏观场的产生。因此我们将使用海森伯-朗之万方法，它与我们已经导出的经典描述直接对应。支配腔模与原子之间相互作用的哈密顿量为

$$\kH = -\hbar\hat{a}^\dagger\sum_j \left(\kg_j\hat{\sigma}_{32}^{(j)} + \kg_j\hat{\sigma}_{13}^{(j)}\right) + h.c., \tag{9.144}$$

而抽运的驱动项为$\kH_{pump} = -\kOmega_0\hat{\sigma}_{21} + h.c.$。在腔没有损耗的情况下，场模$\hat{a}$的运动朗之万方程为

$$\frac{d\hat{a}}{d\kt} = i\sum_j \left(\kg_j\hat{\sigma}_{32}^{(j)} + \kg_j\hat{\sigma}_{13}^{(j)}\right). \tag{9.145}$$

对于原子极化强度也可以求出相应的方程。例如，原子极化强度$\sigma_{13}^{(j)}$满足

$$\dot{\sigma}_{13}^{(j)} = -(\kgammaonethree + i\kdelta)\hat{\sigma}_{13}^{(j)} - i\kg_j\hat{a}^\dagger\hat{\sigma}_{12}^{(j)} + i\kg_j\hat{a}(\hat{\sigma}_{11} - \hat{\sigma}_{33}) - i\kOmega_0\hat{\sigma}_{23} + \kFnoise_{13}, \tag{9.146}$$

其中$\kdelta$是相对于居间态的失谐。如果失谐足够大，我们可以忽略原子的衰变和与之相关的噪声项$\kgammaonethree \to 0, \kFnoise_{13} \to 0$。此外，如果假定抽运场很强且是经典的，那么算符$\hat{\sigma}_{21}$基本上等于其经典期望值$\hat{\sigma}_{12} = \kOmega_0/\kDelta$（其中$\kDelta$是经典抽运场相对于$|1\rangle$ $\to$ $|2\rangle$跃迁的失谐）。有了$\hat{\sigma}_{21}$的这个值，项$-i\kOmega_0\hat{\sigma}_{23} \approx -i(|\kOmega_0|^2/\kDelta)\hat{\sigma}_{13}$可以通过把它吸收进$\kdelta$的定义而消去。利用绝热消除，我们得到

$$\hat{\sigma}_{13}^{(j)} = -\frac{\kOmega_0}{\kDelta\kdelta}\kg_j\hat{a}^\dagger - \frac{\kg_j\hat{a}}{\kdelta}. \tag{9.147}$$

这个原子算符类似于极化强度的经典表达式，而$\kg_j\hat{a}^\dagger$起着产生场$\kEenv_1$的经典拉比频率的作用。式 9.145中的另一项取决于

$$\hat{\sigma}_{32} \approx \frac{\kOmega_0}{\kDelta}\hat{\sigma}_{31} \approx -\frac{\kOmega_0}{\kDelta\kdelta}\kg_j\hat{a}^\dagger. \tag{9.148}$$

场算符的厄米共轭出现在方程的右边，正如复共轭出现在经典运动方程中一样。注意，我们的系统涉及经典抽运、线性算符方程和大的失谐，所以海森伯-朗之万方法给出的结果，与我们用朴素代换所得到的结果完全相同。如果系统涉及非线性算符项，那么从经典描述过渡到量子描述时，就会出现编序歧义。

这组方程可以由一个有效哈密顿量导出

$$\kHeff = \frac{\hbar}{2}\left(\kbetagain\hat{a}^2 + \kbetagain^*(\hat{a}^\dagger)^2\right). \tag{9.152}$$

从物理上说，该有效哈密顿量描述光子对的吸收或发射，这恰如我们对简并下转换过程所预期的。尽管我们本来可以猜出它的形式，但现在我们已经从微观考虑把它导出了。

非简并参量下转换

通过类似的计算，非简并参量下转换过程满足运动方程

$$\frac{d\hat{a}_2}{d\kt} = -i\kbetagain^*\hat{a}_1^\dagger \tag{9.153}$$
$$\frac{d\hat{a}_1^\dagger}{d\kt} = i\kbetagain\hat{a}_2, \tag{9.154}$$

它们可以由一个有效哈密顿量来描述

$$\kHeff = \hbar\left(\kbetagain\hat{a}_1\hat{a}_2 + \kbetagain^*\hat{a}_1^\dagger\hat{a}_2^\dagger\right). \tag{9.155}$$

这里，$\hat{a}_1$和$\hat{a}_2$是被该过程放大的两个相位匹配的场模。当真空场在这个有效哈密顿量下演化时，它产生出一个态。

区分这一过程中的两种极限是有益的：$\kxipdc < 1$和$\kxipdc \gg 1$。在第一种情形下，光子的发射主要是自发过程，这导致光子对的关联产生。在第二种情形下，受激发射起重要作用，该系统可用作光学参量振荡器来产生光的压缩态。

非简并参量下转换产生的态表现出关联的光子统计学。尽管每个模（即对另一个模求阵迹之后）处于热态，其分布函数为（例如参见沃尔斯和米尔本，5.2.5）

$$p(n) = \frac{\tanh^2\kxipdc}{\cosh^2\kxipdc} \tag{9.158}$$

两个模之间的光子数之差恰好为零：

$$\Delta\hat{n}|\kpsi\rangle = (\hat{n}_1 - \hat{n}_2)|\kpsi\rangle = 0. \tag{9.159}$$

这是非经典光子关联的一个例子：光子数之差被抑制到远低于光子散粒噪声极限$\langle(\hat{n}_1 - \hat{n}_2)^2\rangle = n_1 + n_2$，这正是在分束器上把一束光一分为二所得到的结果。

在参量下转换中产生的关联光子有多种应用。通过只测量两个模之一，它们可用于标示单光子的产生。以第一个模中的一次探测事件为条件，第二个模中应当恰好有一个光子。一种稍微复杂一些的应用，利用模的某种内部性质，例如偏振，来编码一个纠缠态。在这种情形下，所得到的态可能类似于

$$|\kpsi\rangle = |\mathrm{vac}\rangle + \frac{\kxipdc}{\sqrt{2}}\left(|1_H, 1_V\rangle + |1_V, 1_H\rangle\right) + \mathcal{O}(\kxipdc^2). \tag{9.160}$$

只要产生光子的概率$\sim \kxipdc \ll 1$，系统要么处于真空，要么处于纠缠的双光子态。与许多单光子过程的情形一样，这一纠缠态的产生是概率性的。此外，任何实际系统中固有的损耗都会破坏纠缠态。然而，通过把所有后续测量都以两个光子都被探测到为条件（这一过程称为“后选择”），我们就只在产生了两个光子且二者都没有丢失的情形下使用我们的态。以这种方式，人们可以设计出容忍概率性过程且对损耗不敏感的少光子实验。

9.4.2 压缩态

在$\kxipdc \gg 1$的情形下，简并参量下转换可以导致压缩态的产生。回到$\hat{a}_1 = \hat{a}_2 = \hat{a}$的情形，我们现在允许驱动场具有任意的相位$\ktheta$，于是增益系数变为

$$\kbetagain = \kbetatilde e^{i(\ktheta - \pi/2)}. \tag{9.161}$$

利用这一相位对场算符加权，我们定义腔模的正交分量

$$\kxquad = \frac{1}{\sqrt{2}}\left(\hat{a}e^{i\ktheta/2} + \hat{a}^\dagger e^{-i\ktheta/2}\right) \tag{9.162}$$
$$\kpquad = \frac{1}{\sqrt{2}i}\left(\hat{a}e^{i\ktheta/2} - \hat{a}^\dagger e^{-i\ktheta/2}\right), \tag{9.163}$$

它们是算符运动方程的“简正模式”。

对于$\kbetatilde > 0$，$x$正交分量被放大，而$p$分量被衰减。

因此，如果腔模从相干态出发，则正交分量的方差将朝相反的方向变化。

注意，该场仍处于最小不确定态，因为$\langle\Delta\kpquad^2\rangle\langle\Delta\kxquad^2\rangle = 1/4$，但其噪声性质相对于初始相干态被“压缩”了。

在数学上，压缩态可以表示为有效哈密顿量的时间演化算符作用在初始相干态$|\kalphacoh\rangle$上：

$$|\kpsi\rangle_{Sq} = e^{-i(\kbetagain^*(\hat{a}^\dagger)^2 + \kbetagain\hat{a}^2)\kt/2}|\kalphacoh\rangle. \tag{9.170}$$

压缩态的这一形式定义使得它的所有性质都可以被计算。注意，如果我们从真空$\kalphacoh = 0$出发，有效哈密顿量就会成对地增加和减少光子，所以最终的压缩态将只包含偶数个光子的叠加。显然，这样的态与相干态非常不同。

9.4.3 损耗的影响

我们的分析预言，随着时间推移，压缩态的一个正交分量将消失，而另一个将发散。从实际的角度看，我们预期这样的发散会被阻尼掉，所以为了得到对压缩光产生的真实描述，考虑衰变过程是重要的。

阻尼腔中压缩光的产生

我们将只考虑腔的损耗，它是最容易纳入我们分析的噪声类型。场算符的朗之万方程因衰变率$\kkappa$和与之相关的噪声算符$\kFnoise$而被修改，

$$\frac{d\hat{a}}{d\kt} = -i\kbetagain^*\hat{a}^\dagger - \frac{\kkappa}{2}\hat{a} + \kFnoise \tag{9.171}$$
$$\frac{d\hat{a}^\dagger}{d\kt} = i\kbetagain\hat{a} - \frac{\kkappa}{2}\hat{a}^\dagger + \kFnoise^\dagger. \tag{9.172}$$

腔的衰变对应于光子通过半透明反射镜进出腔、泄漏到外部世界。腔外的场模（许多模）现在充当我们所考虑的单个腔模的热库。当腔外的场初始处于真空态$\knbar = 0$时，噪声算符关联函数为

$$\langle\kFnoise(\kt)\kFnoise^\dagger(\kt')\rangle = \kkappa\delta(\kt - \kt'). \tag{9.173}$$

利用式 (9.162)和式 (9.163)中定义的简正模式，我们可以改写朗之万方程。

这里厄米噪声算符$\kFnoise_{x,p}$是$\kFnoise$和$\kFnoise^\dagger$的线性组合，类似于正交分量算符：

$$\kFnoise_x = \frac{1}{\sqrt{2}}\left(\kFnoise e^{i\ktheta/2} + \kFnoise^\dagger e^{-i\ktheta/2}\right) \tag{9.176}$$
$$\kFnoise_p = \frac{1}{\sqrt{2}i}\left(\kFnoise e^{i\ktheta/2} - \kFnoise^\dagger e^{-i\ktheta/2}\right), \tag{9.177}$$

它们的关联函数可直接由$\kFnoise$的关联函数得出。

在大时间极限下，$\kpquad$的不确定度趋近于一个渐近的非零值，这表明损耗降低了压缩态的量子关联。

定常态压缩

当腔阻尼率远大于压缩系数$\kkappa \gg \kbetagain$时，两个方差都趋近于经典值$1/2$。如此强的损耗使压缩态坍缩成经典的相干态。一般来说，量子关联产生于非线性相干相互作用与耗散之间的平衡。我们希望确定这种竞争的定常态结果。

然而，在强抽运情形$\kbetagain > \kkappa/2$下，我们遇到了非物理的结果，因为预言的腔光子数无限增长，$\langle\hat{a}^\dagger\hat{a}\rangle \to \infty$。我们的分析不足以描述这一情形下的定常态行为，因为我们作了未耗尽抽运近似。对于有限的相互作用时间，这一近似也许足够，但定常态解需要一种完整的处理，用非线性算符方程来考虑这些修正。

我们的解在中间情形$\kbetagain < \kkappa/2$下表现良好，其中

$$\langle\Delta\kxquad^2\rangle \to \frac{\kkappa}{2(\kkappa - 2\kbetatilde)} \tag{9.184}$$
$$\langle\Delta\kpquad^2\rangle \to \frac{\kkappa}{2(\kkappa + 2\kbetatilde)}. \tag{9.185}$$

特别要注意，在阈值抽运率$\kbetagain = \kkappa/2$处，最大压缩只有50%。这一极限来自以速率$\kkappa$泄漏进腔内的外部真空场，它污染了非经典态。

输出场中的压缩

从我们迄今的结果看，似乎在定常态中只能期望看到50%的压缩。然而，这一限制并不是故事的结尾。在实验中，人们观察的不是腔内的场，而是泄漏到连续谱中的那一部分。输出场可以用输入输出关系的量子力学版本求得

$$\text{经典}: \kEcav_\mathrm{out} = -r\kEcav_\mathrm{in} + t\kEcav_\mathrm{cavity} \tag{9.186}$$
$$\text{量子}: \kEhat_\mathrm{out} = -\frac{\kFnoise}{\sqrt{\kkappa}} + \sqrt{\kkappa}\hat{a}. \tag{9.187}$$

这里我们清楚地看到，噪声算符是由光子进出腔的泄漏造成的。由于输出场是输入场被反射的部分与透射的腔场之和，我们需要考虑这两个分量之间的干涉项。我们感兴趣的是连续波情形，所以在傅里叶域中工作是方便的，在其中输入输出关系给出

$$\kEhat_\mathrm{out}(\komega) = -\frac{\kFnoise(\komega)}{\sqrt{\kkappa}} + \sqrt{\kkappa}\hat{a}(\komega). \tag{9.188}$$

动量正交分量满足类似的方程

$$\kPquad_\mathrm{out}(\komega) = -\frac{\kFnoise_p(\komega)}{\sqrt{\kkappa}} + \sqrt{\kkappa}\kPquad(\komega). \tag{9.189}$$

由式 (9.175)，我们知道腔内的正交分量，因此可以求解外部场。

特别是，当$\kbetagain \to \kkappa/2$且$\komega \to 0$时，两个分量发生相消干涉，$\kPquad_\mathrm{out}(0) \to 0$。因此输出场可以被完美地压缩！

对于输出场的某个傅里叶分量与腔频率之间的有限失谐，输出只是部分被压缩。压缩具有宽度$\sim \kkappa$的洛伦兹线型（见图 9.11）。在实际实验中，人们会观察中间的频率，在那里经典噪声可以被抑制，而又存在有限的压缩。

零拍探测

只有存在某种测量压缩的手段，压缩态的产生才能得到评估。由于正交分量以光频振荡，对压缩的直接探测是一项极其困难的任务。取而代之，人们使用一种称为“零拍探测”的技术，把信号变换到较低的频率，在那里可以使用标准电子学。

零拍探测采用处于相干态$\bar{\beta}e^{i\kphi}$的强经典场$\hat{b}_{LO}$，中心频率与信号相同。当这个所谓的“本地振荡器”场与信号在50/50 分束器上混合时，两个输出场为

$$\hat{a}_\mathrm{out}^{(1)} = \frac{1}{\sqrt{2}}\left(\hat{a} + i\hat{b}_{LO}\right) \tag{9.192}$$
$$\hat{a}_\mathrm{out}^{(2)} = \frac{1}{\sqrt{2}}\left(i\hat{a} + \hat{b}_{LO}\right). \tag{9.193}$$

光电探测器测量两个场的光强，它与分束器每一臂中的光子数成正比。

通过测量差电流（它与光子数之差成正比），人们可以消去平均光子数，只探测信号与本地振荡器之间的拍频。

对于信号与本地振荡器的初态$|\kpsi\rangle = |\kpsi\rangle_a|\beta\rangle$，只要$\bar{\beta} \gg 1$很大，这个差电流就提供了信号的正交分量的一种度量。

在精密测量中的应用

精密测量在量子力学上可能受到经典激光中涨落的限制。用压缩光取代激光束可以改进某些测量，而精度上的潜在增益正是研究压缩最初的动机。

假设一次干涉测量需要求出两个场之间的相位差（见图 9.13和图 9.14）。如果这些场具有压缩参数$\krsq$，则信号

$$\Delta P = \langle x\rangle\delta\kphi \tag{9.200}$$

只能在噪声范围内进行测量

$$\langle\Delta P^2\rangle = \frac{1}{2}e^{-2\krsq}. \tag{9.201}$$

显然，非零的压缩参数使这一测量的灵敏度得到改进。

例如，考虑图 9.14所示的干涉仪。初态$\hat{b}_i$和$\hat{a}_i$分别是相干态$|\beta\rangle$和压缩真空态$e^{\krsq/2(\hat{a}^2 - (\hat{a}^\dagger)^2)}|0\rangle$。把这些场在分束器上混合之后，在重新合并于第二个分束器之前，一条臂中被引入相移$\kphi = \pi/2 + \delta\kphi$。光电探测器测量第二个分束器的两束输出光中光子数之差，

$$\hat{n}_- = \hat{b}_f^\dagger\hat{b}_f - \hat{a}_f^\dagger\hat{a}_f \tag{9.203}$$
$$= \cos\kphi\left(\hat{b}_i^\dagger\hat{b}_i - \hat{a}_i^\dagger\hat{a}_i\right) - i\sin\kphi\left(\hat{a}_i^\dagger\hat{b}_i - \hat{b}_i^\dagger\hat{a}_i\right). \tag{9.204}$$

这个量的平均值和方差给出相位差$\delta\kphi$和测量的精度

$$\langle\hat{n}_-\rangle \sim \bar{\beta}\delta\kphi\langle\hat{b}_i^\dagger\hat{b}_i\rangle \tag{9.205}$$
$$\langle\Delta\hat{n}_-^2\rangle_{(\delta\kphi \approx 0)} \sim \bar{\beta}^2\langle\Delta P^2\rangle_a \to 0. \tag{9.206}$$

20世纪80年代末的实验证明了用压缩光可以提高干涉测量的灵敏度。然而，这些想法从未找到实际应用，因为（粗略地说）只需增大相干输入场的强度就可以做出类似的改进（见图 9.13c）。提高激光功率比产生压缩光容易得多，所以产生压缩光的最初动机在实践中并未被证明是有用的。不过要注意，高度压缩态仍可能找到应用，例如在量子信息领域，或用于引力波探测，在这些场合增加光子数行不通。

原子中的压缩

我们在光子激发的背景下考虑过的许多概念，将直接应用于原子物理学。特别是，可以考虑原子系综中的自旋压缩，其中总自旋或“集体”自旋被定义为$N$个单个自旋的矢量和

$$\kScoll = \sum_i^N S_i. \tag{9.207}$$

如果我们考虑由$S_i = 1/2$的原子构成的自旋极化样品，则我们得到集体自旋投影$\kScoll_z = N/2$。尽管正交投影的期望值为零，$\langle\kScoll_x\rangle = \langle\kScoll_y\rangle = 0$，它们的涨落不为零，因为

$$\langle\kScoll_x^2\rangle = \langle\kScoll_y^2\rangle = \frac{N}{2}. \tag{9.208}$$

正交投影中的这一不确定度称为“原子散粒噪声。”然而，与压缩光类似，可以利用原子间的有效相互作用，把一个自旋投影压缩到这个散粒噪声极限以下，代价是另一个投影中的涨落增大：

$$\langle\kScoll_x^2\rangle < \frac{N}{2} \tag{9.209}$$
$$\langle\kScoll_y^2\rangle > \frac{N}{2}. \tag{9.210}$$

原子-光子关联

概率性纠缠产生与后选择的想法（我们最初是在参量下转换中遇到它们的）也可以应用于原子-光子纠缠。作为一个具体的例子，考虑$N$原子拉曼散射的情形，其中

$$\kH = \kg\hat{a}^\dagger\sum_i^N S_i^\dagger + \kg^*\hat{a}\sum_i^N S_i \tag{9.211}$$
$$= \kg\hat{a}^\dagger\kScoll^\dagger + \kg^*\hat{a}\kScoll. \tag{9.212}$$

这个哈密顿量与非简并参量下转换的有效哈密顿量惊人地相似，并且它导致完全同一类的概率性纠缠态。通过以探测到纠缠光子为条件，人们可以投影掉真空态和光子损失。这一技术有可能实现不同原子系综的纠缠，这与量子信息科学中的许多应用有关。
