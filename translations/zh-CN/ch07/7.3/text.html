在前面几讲中，我们已经看到绝热过程如何在三能级系统中导致有趣的现象，特别是导致EIT的暗态的绝热跟随。如果我们集中讨论双光子失谐为零这一最有趣的情形，$\kdelta = 0$，并假定拉比频率为实数，那么由两个外加场耦合的三能级系统的哈密顿量可以写成（在裸态基中）

$$\kH = -\kDelta|3\rangle\langle 3| - \kOmegaone\left(|3\rangle\langle 1| + |1\rangle\langle 3|\right) - \kOmegatwo\left(|3\rangle\langle 2| + |2\rangle\langle 3|\right). \tag{7.24}$$

这个哈密顿量由缀饰态的本征基对角化。

态$|\Phi_0\rangle$对应于系统的暗态$|D\rangle$，因为它与激发态$|3\rangle$的内积为零。通过操控系统使其绝热跟随这个暗态，我们就能对$|1\rangle$和$|2\rangle$中的布居概率幅实现稳健的控制，同时避免与来自$|3\rangle$的自发发射相关的损失。

7.3.1 受激拉曼绝热通道（STIRAP）

瞬时本征态$|\Phi_0\rangle$是下态$|1\rangle$和$|2\rangle$的叠加，其概率幅由混合角$\tan\ktheta = \kOmegaone/\kOmegatwo$控制。正如我们先前所指出的，当其中一个外加场消失时，暗态趋近于这两个裸态，

$$\ktheta = 0 \quad \Rightarrow \quad |\Phi_0\rangle = |1\rangle \tag{7.33}$$
$$\ktheta = \frac{\pi}{2} \quad \Rightarrow \quad |\Phi_0\rangle = -|2\rangle. \tag{7.34}$$

如果我们改变这两个场，使混合角从 0 缓慢变化到$\pi/2$，就可以把布居从$|1\rangle$转移到$|2\rangle$，而始终不使激发态$|3\rangle$有布居。合适的脉冲序列以作用于未占据跃迁的脉冲开始，因此被称为“反直觉”脉冲序列。更重要的是，脉冲的精确形状和定时并不十分重要；要紧的只是混合角被缓慢扫过$\pi/2$。实验已经证实，STIRAP是一种高效而稳健的态转移方法，前提是双光子失谐能保持较小。这类绝热转移技术在分子系统中尤其有用，那里丰富的电子、振动和转动衰变通道使动力学控制不可能实现。

7.3.2 四能级系统

三能级的分析可以推广到具有类似结构的更高维希尔伯特空间。例如，考虑由三个亚稳态$\{$$|1\rangle$, $|3\rangle$, $|4\rangle$$\}$组成的系统，通过外加场$\{\kOmegaone, \kOmegathree, \kOmegafour\}$共振耦合到激发态$|2\rangle$。这样一个系统的哈密顿量可以被对角化，并且有两个简并的暗态。

两个暗态的出现可以通过先考虑$\kOmegaone = 0$来定性地理解。剩下的三能级系统可以被对角化，得到一个暗态$|D_{13}\rangle$，它不与激发态耦合。

开启$\kOmegafour$不影响$|D_{34}\rangle$，并且它构成另一个三能级系统（由$|1\rangle$和第一个三能级系统中的两个亮态组成），该系统同样有一个暗态$|D_1\rangle$。对于共振激发，这两个暗态将是简并的，因为哈密顿量不含失谐参数，且暗态不依赖于外加场。

由于这两个暗态是简并的，我们不能忽略它们之间的非绝热耦合。事实上，我们可以利用这种简并来控制$|\Phi_1\rangle$与$|\Phi_2\rangle$之间的混合，在此过程中制备这两个态的任意叠加。假设最初$\ktheta = 0$，系统从$|1\rangle$ $= |\Phi_1\rangle$出发。当$\ktheta \to \pi/2$时，系统演化为由第三个场$\kOmegafour$所决定的$|3\rangle$与$|4\rangle$的叠加。通过控制$\kOmegafour$的相位和振幅（从而控制混合角$\kphi$），就可以控制最终的量子态$c_3|3\rangle + c_4|4\rangle$。

四能级系统的绝热操控已被用于在实验上构造原子分束器。当原子穿过三束空间上分开的光束（因此在随原子运动的参考系中这些光束是脉冲式的）时，它们被绝热地转移，从初态$|1\rangle$转入$|3\rangle$与$|4\rangle$的可控混合。施加给原子的动量冲击由它最终所处的态决定，因此原子的内态被映射到它的位置上。通过改变第三个场，可以控制并探测原子沿哪条空间路径运动，从而验证绝热转移。
