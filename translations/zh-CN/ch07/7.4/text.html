我们已经定性地论证了，随着反直觉脉冲序列的施加，系统绝热跟随暗态，并且已经找到了相干演化下绝热定理成立的条件。我们还没有定量地说明，在存在退相位和衰变的系统中，探测脉冲必须变化得多慢，这幅简单的图像才能继续成立。

绝热条件的分析

为了定量地分析非绝热损耗，我们假设一个发生在特征时标$\ktau$上的具体脉冲形状。例如，设照射原子云的两个脉冲的时间依赖关系为

$$\kOmegaone(\kt) = \kOmega\sin\frac{\kt}{\ktau} \tag{7.39}$$
$$\kOmegatwo(\kt) = \kOmega\cos\frac{\kt}{\ktau}. \tag{7.40}$$

如果系统在$\kt = 0$时从$|1\rangle$出发，并且在脉冲改变振幅时绝热跟随暗态，那么在$\kt = (\pi/2)\ktau$时，系统将处于$-|2\rangle$。我们想要找出最短的时间$\ktau$，在该时间下原子态能够跟随场的演化而不离开暗态。

为了把退相位和衰变纳入我们的描述，我们将采用随机波函数表述。为使问题简单，我们忽略$|2\rangle$的任何衰变，也忽略$|3\rangle$衰变造成的任何下态重新布居。一般态$|\kpsi(\kt))\rangle = \kcone(\kt)|1\rangle + \kctwo(\kt)|2\rangle + \kcthree(\kt)|3\rangle$的非厄米薛定谔方程给出概率幅的如下运动方程：

$$\dot{\kcone} = i\kOmegaone^*(\kt)\kcthree \tag{7.41}$$
$$\dot{\kctwo} = i\kOmegatwo^*(\kt)\kcthree \tag{7.42}$$
$$\dot{\kcthree} = -\kgammaonethree\kcthree + i\left(\kOmegaone(\kt)\kcone + \kOmegatwo(\kt)\kctwo\right). \tag{7.43}$$

我们将寻找这些波动方程的解，其形式为

$$\kcinst_i = \kcinst_i^{(0)} + \kcinst_i^{(1)} + \ldots \tag{7.44}$$

其中和式中的每一项都代表按小参数$\propto 1/\ktau$的幂展开的更高阶修正。最低阶解$\kcinst_i^{(0)}$是定态解，可以通过忽略运动方程中的所有时间导数求得。前两个方程意味着$\kcthree^{(0)} = 0$，同时求解第三个方程和归一化条件$\langle\kpsi|\kpsi\rangle = 1$，我们就可以求得零阶概率幅。

注意，忽略时间导数恰好给出了我们先前找到的暗态。

然而严格地说，$\kcone^{(0)}$和$\kctwo^{(0)}$并不给出这些波动方程的精确解，因为它们的时间导数不为零。到$1/\ktau$的第一个非零阶，我们必须计入$\kcone^{(0)}$和$\kctwo^{(0)}$中时间变化的效应，从而得到关于一阶修正的一组方程。

这个方程对$\kcone^{(1)}$和$\kctwo^{(2)}$无法求解；不过，我们立刻可以看出，这些一阶修正$\kcone^{(1)}$和$\kctwo^{(1)}$都正比于$\kgammaonethree/\kOmega^2\ktau$。当这些修正很小时，原子态的演化近似是绝热的，于是绝热条件变为

$$\frac{\kgammaonethree}{\kOmega^2\ktau} \ll 1. \tag{7.53}$$

这一结果说明了衰变在绝热过程中的重要性，因为这一结果与我们对相干演化系统的绝热跟随所得的结果大不相同。

量子跳跃引起的误差

在计算暗态形成的非绝热修正时，我们忽略了另一个误差来源：量子跳跃。在特征时标$\ktau$内，系统发生量子跳跃的概率为

$$\kPjump = \kgammaonethree\int_0^{\ktau} |\kcthree|^2 = \frac{\kgammaonethree}{\kOmega^2\ktau}. \tag{7.56}$$

随机波函数方法成立的条件因此是

$$\kPjump \ll 1 \Rightarrow \frac{\kgammaonethree}{\kOmega^2\ktau} \ll 1, \tag{7.57}$$

所以绝热近似和推导它所用的非厄米演化在相同的情形下成立。

注意，对非厄米波函数的非绝热修正和量子跳跃都限制了从$|1\rangle$到$-|2\rangle$的绝热通道的保真度。特别地，最终处于正确末态的概率（$\kOmega\ktau = \pi/2$）可以明确地算出。

与上面讨论的朗道-齐纳问题不同，这个精确解允许按小参数$\kgammaonethree/\kOmega^2\ktau$展开。虽然对于相干的绝热过程我们无法求得微扰解，但在存在衰变时，这样的展开可以成为可能。

7.4.1 评注

部分对角化基：一种直观的方法

我们的分析是用裸态基$|1\rangle$、$|2\rangle$和$|3\rangle$进行的。通过完全对角化哈密顿量，可以定义一个含时的缀饰态基。然而在实践中，这个问题最容易在由暗态$|D\rangle$、亮态$|B\rangle$和激发态$|E\rangle$组成的部分对角化基中求解和理解：

$$|B\rangle = \frac{\kOmegaone|1\rangle + \kOmegatwo|2\rangle}{\sqrt{|\kOmegaone|^2 + |\kOmegatwo|^2}} \tag{7.59}$$
$$|D\rangle = \frac{\kOmegatwo|1\rangle - \kOmegaone|2\rangle}{\sqrt{|\kOmegaone|^2 + |\kOmegatwo|^2}} \tag{7.60}$$
$$|E\rangle = |3\rangle. \tag{7.61}$$

通过选择这种混杂基，我们使相互作用哈密顿量得到了相当大的简化，

$$\kH_\mathrm{int} = -\sqrt{|\kOmegaone|^2 + |\kOmegatwo|^2}\left(|B\rangle\langle E| + |E\rangle\langle B|\right). \tag{7.62}$$

暗态不参与动力学，因为激发态只与$|1\rangle$和$|2\rangle$的亮态叠加耦合。

在这个新基中工作，使我们对非绝热修正有了直观的认识。态$|B\rangle$和$|E\rangle$由$\kOmega = \sqrt{|\kOmegaone|^2 + |\kOmegatwo|^2}$耦合，而有限的脉冲时间在暗态和亮态之间诱导出一个弱耦合。$|D\rangle$ $\to$ $|B\rangle$跃迁的强度为

$$i\hbar\langle B|\frac{d}{d\kt}|D\rangle = -i\hbar\frac{1}{\ktau}. \tag{7.63}$$

非绝热耦合的作用如同一个拉比频率为$\kOmegaNA = 1/\ktau$的弱场，驱动$|D\rangle$到$|B\rangle$的跃迁。

这正是在双共振实验中，原子被光辐射和微波辐射激发时所遇到的那类情形。$\kOmega$和$\kgammaonethree$的净效果是引入$|B\rangle$的有限寿命，因为$|B\rangle$可以被激发到$|E\rangle$，随后会衰变。离开$|B\rangle$的逃逸率与光激发率同量级，

$$\kgammaB = \frac{\kOmega^2}{\kgammaonethree}. \tag{7.64}$$

原子将保持在暗态中，前提是$|D\rangle$与$|B\rangle$之间的混合率$\kOmegaNA$弱于$|B\rangle$寿命的倒数，

$$\frac{1}{\ktau} \ll \frac{\kOmega^2}{\kgammaonethree}. \tag{7.65}$$

在这里，来自亮态的衰变有助于迫使原子进入暗态。通过物理推理，我们得到了与数学推导所得的完全相同的绝热条件。

绝热通道与 EIT

绝热跟随的条件与脉冲在 EIT 介质内传播的条件之间，存在一种有趣的关系。电磁感生透明的光谱窗口允许探测脉冲无损耗地传播，仅当其所有谱分量都落在暗共振谱线宽度$\kDeltaomega$之内，即仅当探测脉冲的持续时间足够长，$\ktau \gg 1/\kDeltaomega$。由于$\kDeltaomega = \kOmega^2/\kgammaonethree$，EIT 脉冲透射的条件恰好对应于绝热跟随条件。

这种对应关系突出了 EIT 与绝热过程之间的联系。如果脉冲进入得足够缓慢，原子系统就绝热跟随暗态，进入无损耗地在介质中传播的$|1\rangle$和$|2\rangle$的叠加。当脉冲离开时，原子态绝热跟随暗态回到$|1\rangle$，把原子相干性转移给透射光。

非绝热暗态制备

暗态也可以不借助绝热过程来制备。例如，设系统从各态的非相干混合态出发，$\krhooneone = \krhotwotwo = 1/2$。由于所需的末态是纯态，任何哈密顿量演化（无论是否绝热）都不可能把这种混合态变成暗态。

然而，暗态的实验发现 [阿尔泽塔 等 Novvo Cirr. 36B, 5/76]是通过监测被两个连续波场照射的热钠蒸气室的荧光完成的。由于塞曼效应，沿蒸气室的磁场梯度产生了失谐的空间梯度。在沿蒸气室的、经塞曼移位的双光子失谐消失的精确位置，荧光信号中出现了一条暗条纹。这被解释为形成了暗态——然而热蒸气一开始处于统计混合。

这个难题很容易通过在亮态和暗态的部分对角化基中分析该实验来解决。原来的混合态是亮态和暗态的统计混合。考虑施加连续波场$\kOmegaone$和$\kOmegatwo$，使得与$|B\rangle$和$|D\rangle$的非绝热耦合消失的情形。同时，这一对场起到光抽运光束的作用，把处于$|B\rangle$的原子激发到$|E\rangle$，原子在那里或者衰变到$|D\rangle$（此后它停留在那里），或者衰变到$|B\rangle$（它从那里又被抽运回$|E\rangle$）。因此，部分对角化基中的光抽运通过纯粹的非相干过程把系统制备在暗态。

布居与相干性：基的重要性

从暗态形成的例子中我们看到，原子相干性的制备与光抽运有某种联系。这并不太令人意外，因为一个基中的相干性（例如$\{|1\rangle, |2\rangle\}$）恰是另一个基中的布居差（例如$\{|B\rangle, |D\rangle\}$）。

布居与相干性之间的关系，可以通过原子在$J = 1$到$J' = 1$跃迁上与线偏振光相互作用这一简单例子来阐明。在没有外加磁场时，我们可以自由地选择量子化轴平行或垂直于光的偏振。

假设我们选择使$m_J$子能级沿平行于光偏振的方向量子化。由于对称性考虑禁止$\Delta J = 0, \Delta m_J = 0$的跃迁，光将只耦合$m_J = \pm 1 \to m_J' = \pm 1$，任何混合态都将被光抽运到较低的$m_J = 0$态。

现在假设我们选择在光的偏振垂直于量子化轴的情形下分析同一个问题。任何线偏振都可以分解为两个圆偏振，它们耦合四个$\Delta m_J = \pm 1$的跃迁。在这一堆能级和跃迁中，我们可以辨认出一个$\Lambda$构型：$m_J = 1$态和$m_J = -1$态现在都耦合到同一个$m_J' = 0$激发态。因此，系统有一个暗态，原子将被光抽运到$m_J = -1$和$m_J = 1$的暗叠加中，它恰好对应于沿偏振轴量子化的$m_J = 0$态。

这一讨论的要点是，一个基中的相干性就是另一个基中的布居分布。通常，后一个基将为复杂的问题提供最多的物理洞察。

暗态的应用

暗态是一种重要的工具，既被用来制备和操控原子态，也被用来控制光脉冲。此外，动量传递与暗态的形成相关联。因此，暗态技术也可以用来产生动量态或空间态的叠加。例如，如上一讲所述，绝热通道已被用来制造可控的原子分束器。
