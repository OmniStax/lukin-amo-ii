我们将用密度算符作为工具，帮助推导一种有效描述，用于与其环境相互作用的开放系统。为了理解约化密度算符如何随时间演化，先考虑它在只作用于系统的哈密顿量$\kHS$下的演化。

现在假设系统与环境之间存在某种耦合，由相互作用哈密顿量$\kHSR$描述。动力学将变得复杂得多，因为即使系统与环境一开始彼此独立，初始直积态$|\kpsi_S\rangle \otimes |\kpsi_R\rangle$也会在$\kHSR$的影响下演化成一个一般无法因子化为独立的系统态与环境态的态。此时称系统与环境是纠缠的。

作为说明，我们回到原子向真空自发发射一个光子的例子。如果原子一开始处于叠加态$|\kpsi_0\rangle = (\kcone|1\rangle + \kctwo|2\rangle) \otimes |0\rangle$，则在时刻${\kt}$它将处于态$|\kpsi({\kt})\rangle = \kcone|1\rangle \otimes |0\rangle + \kctwo({\kt})|2\rangle \otimes |0\rangle + \sum_k \kck({\kt})|1\rangle \otimes |1_k\rangle$，这个态不能再写成原子态与电磁场态的直乘。于是原子约化密度矩阵的各元素可以用衰变率$\kgamma$算出。

注意，非对角元的衰变率是激发态布居的一半。这是能量守恒的相互作用的特征。

3.3.1 一般形式体系

总哈密顿量可以表示为三项之和，

$$\kH = \kHS + \kHR + \kHSR. \tag{3.27}$$

第一项只影响系统自由度，第二项只影响热库，而第三项含有系统算符与热库算符的乘积。

三项各自的贡献不同。系统哈密顿量的作用与没有热库时相同。热库哈密顿量对$\krhoS$没有净效应，因为阵迹在热库算符的轮换下不变，所以对易式必须为零。然而，相互作用哈密顿量同时涉及系统算符和热库算符，需要特殊处理。虽然我们已经得到了作为一般结果的运动方程，但如果不至少给定相互作用哈密顿量和热库本身的某些性质，就无法取得进一步的进展。

3.3.2 环境的性质

不同的环境可以对与之相互作用的系统产生性质上不同的影响。为了说明典型的热库性质，我们考虑涨落磁场中的自旋的例子，其中相互作用哈密顿量为

$$\kHSR = \hbar \kft({\kt})\hat{S}_z. \tag{3.32}$$

这个哈密顿量对应于自旋态$|1\rangle, |2\rangle$之间的能量分裂$\hbar \kft({\kt})$，其中$\hat{S}_z = (|2\rangle\langle 2| - |1\rangle\langle 1|)/2$。我们将考虑$\kft({\kt})$代表无规场的情形。这个模型适用于多种物理系统，例如核自旋（无规涨落的）热浴中的电子自旋。从哈密顿量出发，我们可以形式上推出自旋的描述幺正演化的算符

$$\hat{U} = e^{i\int_0^{\kt} \kft({\kt}')d{\kt}'\hat{S}_z}, \tag{3.33}$$

由此可以算出任何期望值的时间依赖。特别地，我们关心$\langle\hat{S}_+\rangle$，它对应于自旋密度矩阵的非对角元（$\hat{S}_+ = |2\rangle\langle 1|$）。这个算符从哈密顿量中的能量分裂获得一个相位，所以它的时间依赖为

$$\langle\hat{S}_+\rangle = \langle e^{i\int_0^{\kt} \kft({\kt}')d{\kt}'}\hat{S}_+(0)\rangle, \tag{3.34}$$

它依赖于随机变量$\kft({\kt})$的矩。

随机变量

涨落的能量分裂$\hbar \kft({\kt})$代表一个含时的无规过程，也称为随机变量。在每个时刻，$\kft({\kt})$由某个概率分布刻画，我们需要对这个概率分布有所了解，才能预测$\kft({\kt})$对我们所计算的算符的平均效应。特别地，我们会想知道这个概率分布的以下性质：

(1) 一阶矩是期望值$\langle \kft({\kt})\rangle$。通常，我们关心所谓的“平稳过程”，对于它，$\langle \kft({\kt})\rangle = \langle\kft\rangle$是常数。于是我们可以定义

$$\kft({\kt}) = \langle\kft\rangle + \delta \kft({\kt}), \tag{3.35}$$

其中$\langle\delta \kft({\kt})\rangle = 0$。

(2) 无规过程的方差$\langle\delta \kft({\kt})\delta \kft({\kt}')\rangle \neq 0$描述$\kft({\kt})$偏离其平均值的典型程度。

(3) 关联时间$\ktauc$代表$\kft({\kt})$变化所在的时标。它与方差的时间依赖有关；特别地，当$|{\kt} - {\kt}'| < \ktauc$时，方差$\langle\delta \kft({\kt})\delta \kft({\kt}')\rangle$近似为常数。

对于任意的概率分布，原则上我们需要给定无穷多个高阶矩。然而，在下文中我们通常处理“高斯”概率分布。对于高斯概率分布，知道平均值和方差就足以确定所有高阶矩，因为它们两两因子化：

$$\langle\delta \kft({\kt}_1)\delta \kft({\kt}_2)\ldots\delta \kft({\kt}_n)\rangle = \sum\langle\delta \kft({\kt}_1)\delta \kft({\kt}_2)\rangle\langle\delta \kft({\kt}_3)\ldots\rangle, \tag{3.36}$$

其中求和遍及分成成对的与单个的期望值的所有不同分组。特别地，我们应当注意，当$\langle\delta\kft\rangle = 0$时，所有奇数阶矩都为零。

关联时间

对于我们正在考虑的例子（涨落场$\kft({\kt})$中的自旋），我们将区分两个重要的极限：

(1) ${\kt} < \ktauc$

在这种情形下，我们是在远短于环境变化时标的时标上考察系统。每次考察系统（例如对它做一次实验），我们都会发现自旋绕$\hat{z}$轴以速率$\kft({\kt} < \ktauc)$进动，其数值是随机的，但在演化期间是固定的。每个实现的$\kft({\kt})$取值都不同，所以平均而言我们会发现$\langle\bar{\hat{S}}_+\rangle = 0$。然而，这种退相位在某种意义上是可逆的。如果你知道每次实验中$\kft({\kt})$是多少，就可以对它进行补偿。例如，你可以做一个自旋回波实验，在自旋演化到一半时把自旋的取向反转，使净进动消失。因此我们把这第一种情形称为“可逆演化”。

(2) ${\kt} \gg \ktauc$。

对于远长于关联时间的时间，自旋回波技术失效。根本没有办法恢复演化的历史，并消除涨落的环境所造成的破坏。系综平均$\langle\bar{\hat{S}}_+\rangle = 0$再次为零，但这是以一种本质上不可逆的方式。这种情形对应于记忆时间很短的热库。这样的热库称为“马尔可夫环境”，因为它可以用马尔可夫过程（关联时间无限短的无规过程）来描述。在原子物理和量子光学中，大多数环境近似是马尔可夫的，所以我们将着重于理解马尔可夫热库效应的技术。

3.3.3 马尔可夫热库的密度算符方法

通过把系统和热库限制在与原子物理和量子光学相关的某几类相互作用上，我们可以建立一个分析开放系统的框架。特别地，我们将考虑关联时间很短的环境，使得系统只受热库瞬时状态的影响。

我们再次假设$\kH = \kHS + \kHR + \kHSR$。相互作用项$\kHS R$是最相关的部分。为了聚焦于它，我们在相互作用绘景中工作，该绘景是按照幺正算符进行变换而得到的

$$\hat{U} = e^{i(\kHR + \kHS){\kt}/\hbar}. \tag{3.37}$$

在相互作用绘景（用波浪号表示）中，相关的算符为

$$\krhotilde = e^{i(\kHR + \kHS){\kt}/\hbar}\krhohat e^{-i(\kHR + \kHS){\kt}/\hbar} \tag{3.38}$$
$$\kHtilde_{SR} = e^{i(\kHR + \kHS){\kt}/\hbar}\kHSR e^{-i(\kHR + \kHS){\kt}/\hbar}. \tag{3.39}$$

这个幺正变换自动计入了系统和热库的自由演化，因此剩下的动力学只来自相互作用，即

$$\frac{d}{d{\kt}}\krhotilde = \frac{1}{i\hbar}[\kHtilde_{SR}, \krhotilde]. \tag{3.40}$$

我们的分析要求相互作用是系统算符与热库算符的双线性乘积，

$$\kHSR = \kShat\hat{R}^\dagger + \hat{R}\kShat^\dagger, \tag{3.41}$$

其中$\kShat$（$\hat{R}$）是一般的系统（热库）算符。在实际中，相互作用哈密顿量可能含有对这类项的求和：分析的进行方式完全相同，其效应可以通过分别考虑求和中的每一项、最后再求和来计入。在相互作用绘景中，我们把哈密顿量表示为

$$\kHtilde_{SR} = \kShat\kFR({\kt})^\dagger + \kFR({\kt})\kShat^\dagger, \tag{3.42}$$

其中全部时间依赖都明确地包含在热库算符$\kFR({\kt})$中。

例如，在薛定谔绘景中考虑单个原子与辐射场相互作用的哈密顿量，

$$\kHSR = \underbrace{-\sum_j\hbar \kg_j\hat{a}_j}_{\hat{R}}\underbrace{|2\rangle\langle 1|}_{\kShat^\dagger} - \sum_j\hbar \kg_j^*\hat{a}_j^\dagger|1\rangle\langle 2|, \tag{3.43}$$

其中我们可以辨认出适合于我们更一般的相互作用形式的系统算符和热库算符。同样，在相互作用绘景中，哈密顿量包含与系统和热库自由演化相关的相位因子：

$$\kHtilde_{SR} = \underbrace{-\sum_j\hbar \kg_j\hat{a}_j e^{-i(\knu_j - \komega){\kt}}}_{\kFR({\kt})}\underbrace{|2\rangle\langle 1|}_{\kShat^\dagger} - \sum_j\hbar \kg_j^*\hat{a}_j^\dagger e^{i(\knu_j - \komega){\kt}}|1\rangle\langle 2|, \tag{3.44}$$

我们把这些相位因子并入新的热库算符$\kFR({\kt})$中。

除了式 (3.42)给出的相互作用的指定形式之外，我们的分析还需要关于热库本身性质的两个假设，即

(1) 热库很大（因此不受系统影响）

(2) 热库的带宽很宽（因此它的关联时间很短）。

第一个假设表明，热库的状态不会因与系统的相互作用而受到显著影响。因此，在我们的分析中可以取热库处于定态（不含时），例如某一温度T下的统计混合。第二个假设意味着热库的关联时间$\ktauc \sim (1/\text{带宽})$很短；特别地，我们要求$\ktauc$远小于系统演化的典型时标$\ktauS$。这两个假设合起来构成“玻恩-马尔可夫近似”，满足它们的热库称为马尔可夫的。

热库对系统的效应可以通过在介于关联时间与系统演化的特征时间之间的时标$\kDeltat$上取平均来简化，$\ktauc \ll \kDeltat \ll \ktauS$。这种方法类似于对$\ktauc/\ktauS$的微扰论，并将给出对大于$\kDeltat$的时间有效的系统约化密度算符的运动方程。

要继续推进，我们现在必须再做一个假设：初态是可因子化的，

$$\krhotilde({\kt}) = \krhotilde_S({\kt}) \otimes \krhotilde_R({\kt}). \tag{3.49}$$

在此后不久的时间，${\kt} < {\kt}' < {\kt} + \kDeltat$，总密度算符近似可因子化，带有某个小的修正，

$$\krhotilde({\kt}') \approx \krhotilde_S({\kt}) \otimes \krhotilde_R({\kt}) + \krhotilde_{corr}({\kt}, {\kt}'). \tag{3.50}$$

只要$\kDeltat \ll \ktauS$，我们就可以在式 (3.48)的右端到领头阶忽略$\krhotilde_{corr}$，把总密度算符换成系统与热库密度算符的乘积。

利用$\kHtilde_{SR}({\kt})$和$\krhotilde({\kt})$的显式形式，我们现在来考察式 (3.48)中的两项。第一项$\Delta\krhotilde_S^{(1)}$对系统有直接的效应。

由于热库很大，在系统的影响下变化不大，$\langle\kFR({\kt}')^\dagger\rangle$本质上是一个常数。因此，第一项的效应可以解释为对系统哈密顿量的一个附加，$\kHS + \kHS'$。在包括原子-场相互作用在内的许多情形下，$\langle\kFR({\kt}')^\dagger\rangle = 0$，第一项完全消失。

第二项$\Delta\krhotilde_S^{(2)}$负责热库的非平庸效应。

我们将用热库算符的双时关联函数来计算它，其定义为

$$g^{--}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')\kFR({\kt}'')\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')\krhotilde_R\kFR({\kt}')] \tag{3.58}$$
$$g^{+-}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')^\dagger\kFR({\kt}'')\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')\krhotilde_R\kFR({\kt}')^\dagger] \tag{3.59}$$
$$g^{-+}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')\kFR({\kt}'')^\dagger\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')^\dagger\krhotilde_R\kFR({\kt}')] \tag{3.60}$$
$$g^{++}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')^\dagger\kFR({\kt}'')^\dagger\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')^\dagger\krhotilde_R\kFR({\kt}')^\dagger], \tag{3.61}$$

其中第二行当我们对热库算符进行轮换时。

作为例子，我们可以对由辐射场构成的环境显式地算出这些关联函数之一。

双时关联函数现在只依赖于时间之差${\kt}'' - {\kt}' = \tau$，它是$\tau$的一个尖峰函数，其宽度对应于热库关联时间$\ktauc$。在辐射场体积$\kV \to \infty$，$\ktauc \to 0$的极限下，我们恢复出维格纳-韦斯科普夫近似，此时关联函数在时间上是一个 δ 函数。注意，对于辐射场，$g^{--} = g^{++} = 0$，而$g^{-+}$与$g^{+-}$相同，只是把$\langle\hat{a}_j^\dagger\hat{a}_j\rangle$换成$\langle\hat{a}_j\hat{a}_j^\dagger\rangle = \langle\hat{a}_j^\dagger\hat{a}_j\rangle + 1$。

这个结果称为“主方程”，它为研究耦合到马尔可夫热库的开放系统的演化提供了一个必不可少的工具。这套形式体系提供了一种恰当处理所关心系统中非幺正行为的方法。例如可以看出，式 (3.78)保持密度矩阵的阵迹（$\mathrm{Tr}\ \dot{\rho} = 0$）。虽然式 (3.78)描述的是与电磁场的热态相互作用的二能级原子，但我们指出，也可以为其他类型的相互作用导出主方程，例如，与由其他谐振子构成的环境相互作用的谐振子。
