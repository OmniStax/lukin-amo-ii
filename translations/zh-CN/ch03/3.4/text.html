3.4.1 关于广义主方程的说明

在上一讲中，我们推导了支配开放系统演化的方程，该系统与马尔可夫热库耦合。在薛定谔绘景中，这个所谓的主方程具有如下形式

$$\begin{aligned} \frac{\Delta\krhoS}{\kDeltat} = &-\sum_p\frac{\kgammap}{2}\knbar\left(\kShat_p\kShat_p^\dagger\krhoS - \kShat_p^\dagger\krhoS\kShat_p\right) + h.c. \\ &-\sum_p\frac{\kgammap}{2}(\knbar + 1)\left(\kShat_p^\dagger\kShat_p\krhoS - \kShat_p\krhoS\kShat_p^\dagger\right) + h.c. \\ &+\frac{1}{i\hbar}[\kHS, \krhoS]. \end{aligned} \tag{3.79}$$

系统的时间依赖已内含于最后一项中，并且我们加入了对与热库的各种不同相互作用的求和。具体地说，系统-热库相互作用的形式为$\kHSR = \sum_p\kShat_p\hat{R}_p^\dagger + h.c.$，每一项都有各自对应的速率$\kgammap$。为了纳入多个系统-热库相互作用项，我们隐含地做了一个假定：不同的项是非相干的，因此它们之间的干涉消失。虽然这一要求在大多数时候是满足的，但应当记住，存在这种干涉很重要的情形。

虽然式 (3.79)使我们能够有效地计入热库的效应，但这些增加的信息要付出计算代价。假设我们有兴趣研究一个孤立的$n$能级系统。在波函数方法中，该系统的演化由$n$个关于态的概率幅$\{c_i(\kt)\}$的微分方程支配。当计入环境的效应时，系统必须用构成式 (3.79)的$\mathcal{O}(n^2)$个微分方程来描述。方程数目之多会使数学变得复杂，我们将经常需要更精巧的工具来求出解。

还有一点告诫值得注意：在我们先前的推导中，我们假定宇宙的状态是可因子化的，即

$$\krhotilde(\kt') \approx \krhotilde_S(\kt) \otimes \krhotilde_R(\kt), \tag{3.80}$$

其中$\kt' - \kt \leq \kDeltat$。我们在几乎没有论证的情况下做出了这一陈述，但现在我们将证明，对于无记忆的热库，$\ktauc = 0$，我们的假定是成立的。

假设系统和热库在时刻$\kt = \kt_i$之前没有相互作用，于是在$\kt_i$之前的所有时刻，宇宙的密度算符都是可因子化的。在某个时刻$\kt > \kt_i$，我们当然可以写出

$$\krhotilde(\kt) = \krhotilde_S(\kt_i) \otimes \krhotilde_R(\kt_i) + \krhotilde_{corr}(\kt_i, \kt) \tag{3.81}$$

其中$\krhotilde_{corr}(\kt_i, \kt)$取决于系统与热库之间在我们计算关联的时间间隔$\kt \to \kt + \kDeltat$之前建立起的关联。我们将用微扰论来估计对$\Delta\krhoS = \krhotilde_S(\kt + \kDeltat) - \krhotilde_S(\kt)$的那些贡献，它们在我们令$\krhotilde_{corr}(\kt_i, \kt) = 0$时被忽略了。

回忆一下，无记忆热库的时间关联函数是一个 δ 函数；由于积分的时间间隔不重叠，δ 函数在积分区域内处处为零。因此，对$\Delta\krhoS$的、由$\krhotilde_{corr}(\kt_i, \kt)$引起的贡献，在$\ktauc = 0$时于领头阶（以及所有更高阶）消失。事实上，更严格的分析表明，修正按$\ktauc^2$标度。

我们现在已经证明，无记忆的热库与系统的相互作用是局域的；也就是说，它立即忘掉所有先前的关联，只依赖于当前的状态。这种失忆意味着不可逆性，因为信息丢失了（所以熵必然增加）。出于实际目的，不可逆动力学与可逆动力学将给出我们划分系统与环境的界线。环境中任何表现出时间可逆性的部分，即使我们对其演化并不明确感兴趣，我们也将把它纳入系统之中。

我们已经强调了主方程可能不够用的两种情形：(1) 不同的相互作用项之间存在干涉；(2) 热库相互作用是可逆的。关于主方程中隐含的假设和近似的更透彻的讨论，可见于例如科恩-塔诺季等的“Atom-Photon Interactions”。

3.4.2 例：二能级原子

主方程常用于描述耦合到耗散环境的受驱二能级系统的演化。与驱动场的相干相互作用具有如下形式

$$\kHS = -\hbar\kdelta|2\rangle\langle 2| + \hbar\kOmega^*|1\rangle\langle 2| + \hbar\kOmega|2\rangle\langle 1|, \tag{3.84}$$

而热库的效应则进入密度矩阵方程。

这些方程被称为“光学布洛赫方程”。注意，这些方程中只有两个是独立的，因为演化方程必须保持概率，$\krhooneone + \krhotwotwo = \mathrm{Tr}[\krhoS] = 1$，并保持厄米性，$\krhoonetwo = \krhotwoone^*$。

有三类过程对式 (3.89)所描述的系统演化有贡献：

(1) 相干驱动$\propto \kOmega$，

(2) 热光子$\propto \kgamma\knbar$，以及

(3) 自发发射$\propto \kgamma$。

相干相互作用是先前各讲中介绍的理想二能级系统的特征，它们来自系统哈密顿量项。

热光子导致两个方向上的非相干跃迁，而自发发射只允许$\krhotwotwo$中的布居泄漏到$\krhooneone$中：

$$\dot{\krhotwotwo} = \kgamma\knbar(\krhooneone - \krhotwotwo) - \kgamma\krhotwotwo + \ldots \tag{3.90}$$
$$\dot{\krhooneone} = \kgamma\knbar(\krhotwotwo - \krhooneone) + \kgamma\krhotwotwo + \ldots \tag{3.91}$$

虽然非相干过程既能增加也能减少布居$\krhooneone$和$\krhotwotwo$，但它们只会减小非对角项。相干性的衰变率$\kgammaonetwo$（通过$\dot{\krhoonetwo} = -\kgammaonetwo\krhoonetwo + \cdots$定义）与布居衰变出态$|1\rangle$的速率$\kgammaone = \kgamma\knbar$以及$|2\rangle$的速率$\kgammatwo = \kgamma(\knbar + 1)$之间的关系为

$$\kgammaonetwo = \frac{\kgammaone + \kgammatwo}{2} = \frac{2\knbar + 1}{2}\kgamma = \kgammatwoone. \tag{3.92}$$

对于多能级原子，这一关系对任意两个态及其相应的相干性成立，并且只依赖于离开这些态的速率，而不依赖于进入这些态的速率。

虽然我们看到存在与布居衰变相关联的相干性衰变率，但一般说来还存在一些过程，它们减小相干性而不影响布居。这些过程通常以唯象方式纳入主方程，通过令

$$\kgammaonetwo = \kgammatwoone = \frac{\kgammaone + \kgammatwo}{2} + \kgammad, \tag{3.93}$$

其中$\kgammad$是所谓的退相干率或退相位率。这种退相干可由多种来源引起，例如，外加激光场的有限谱线宽度或原子间相互作用。

3.4.3 原子对共振场的响应

我们将考虑两种特殊情形，以获得对原子在同时受到相干抽运和非相干抽运时动力学的物理洞察。

弱外加场

对于足够小的外加场$\kOmega$，主方程可以按微扰处理。由于布居按$\propto \kOmega^2$的项变化，到最低阶我们可以令$\krhooneone \approx \krhooneone^{(0)} + O(\kOmega^2)$，$\krhotwotwo \approx \krhotwotwo^{(0)} + O(\kOmega^2)$，而只考虑相干性的演化。

由于这个方程现在对$\kOmega$是线性的，我们可以通过对$\krhotwoone$和$\kOmega$作傅里叶变换来求解，

$$\krhotwoone(\kt) = \int d(\kdeltanu)e^{-i\kdeltanu \kt}\krhoonetwo(\kdeltanu) \tag{3.95}$$
$$\kOmega(\kt) = \int d(\kdeltanu)e^{-i\kdeltanu \kt}\kOmega(\kdeltanu). \tag{3.96}$$

作了这一代换后，我们发现在弱场极限下，频率为$\kdeltanu$的相干性是一个洛伦兹线型，其有效失谐为$\kdelta + \kdeltanu$：

这一方法可以推广到多能级原子，从而

$$\rho_{ij}(\kdeltanu) = \kOmega_{ij}(\kdeltanu)\frac{i(\rho_{ii}^{(0)} - \rho_{jj}^{(0)})}{\gamma_{ij} - i(\kdelta_{ij} + \kdeltanu)}, \tag{3.98}$$

只要布居$\rho_{ii}$和$\rho_{jj}$在时间上基本被冻结。对于近似处于基态（$\krhooneone^{(0)}\approx 1, \krhotwotwo^{(0)}\approx 0$）的原子，原子响应类似于经典偶极子，因为原子获得的偶极矩与场强成线性关系。另一方面，对于足够大的$\kOmega$，原子的量子化本性变得重要。此时上态中的布居不能忽略，并导致诸如原子响应的非线性和饱和之类的效应。

任意强度的连续波场

当外加场不随时间变化时，我们预期系统将经历被热库相互作用阻尼的拉比振荡。衰变项在经过$\propto 1/\kgammatwoone$的时间后把系统驱动到平衡态，令其密度矩阵元的时间导数为零，就很容易求得系统的定常态描述。

$\kRopt$的作用类似于与外加（相干）场相关联的非相干抽运率。

抽运率$\kRopt$决定了两个重要的极限：

$$\kRopt \ll \kgamma \quad \Rightarrow \quad \krhotwotwo \to 0 \tag{3.102}$$
$$\kRopt \gg \kgamma \quad \Rightarrow \quad \krhotwotwo \to \frac{1}{2}. \tag{3.103}$$

在第一种情形中，相干场很弱，因此原子最终以几乎为一的概率处于基态。更具体地说，可以看出在这一极限下激发态中的布居正比于场的光强（$\krhotwotwo \propto |\kOmega|^2$），并且微扰的弱场方法是成立的。在第二种情形中，外加场使原子处于基态和激发态等权重的统计混合，此时称原子响应是饱和的。

注意，弱场极限对于忽略相干性的演化（即，令$\dot{\krhotwoone} \approx 0$）是充分的但不是必要的；只需要$|\kOmega|^2 \ll \kgammatwoone^2 + \kdelta^2$。式 (3.99)给出的$\krhotwoone$的解类似于作一个绝热近似，即相干性绝热跟随布居差。另一种说法是，在极限$|\kOmega|^2 \ll \kgammatwoone^2 + \kdelta^2$下，布居变化的时标比相干性的固有衰变/振荡时间慢得多。所得的布居方程，

$$\dot{\krhotwotwo} = -\kgamma\krhotwotwo + \kRopt(\krhooneone - \krhotwotwo) \ \text{ 且 } \ \dot{\krhooneone} = -\dot{\krhotwotwo}, \tag{3.104}$$

被称为“速率方程”。它们适用于存在相干性$\krhotwoone$、但其动力学并不重要的情形。例如，速率方程可用于描述与非相干辐射相互作用的原子，因为在这种情形下，由于退相位，$\kgammatwoone$非常大。
