虽然量子力学系统的态用$|\kpsi\rangle$即希尔伯特空间中的一个矢量表示，但这种描述在许多实际情形下并不能给出有用的图像，当然也无法处理宏观物体。任何量子力学态也都可以表示为密度算符；此外，密度算符还可以描述经典系综。

设我们的系统可以处于若干量子态$|\kpsi_\alpha\rangle$之一，并以某个概率$p_\alpha$占据每个态。该系统的密度算符为

$$\krhohat = \sum_\alpha p_\alpha|\kpsi_\alpha\rangle\langle\kpsi_\alpha|. \tag{3.1}$$

如果存在一个基，使得对某个态$|\phi\rangle$有$\krhohat = |\phi\rangle\langle\phi|$，就称系统处于“纯态”。如果找不到这样的基，系统就处于“混合态”，并且失去了一部分纯粹的量子力学特性。最后，如果密度算符的非对角元为零，系统就可以用基矢态的经典系综来描述，称为“统计混合”。

由这一定义，可以立即导出任何密度算符都必须满足的几条重要性质：

(1) $\krhohat = \krhohat^\dagger$

(2) $\mathrm{Tr}[\krhohat] = \sum_n\langle n|\krhohat|n\rangle = 1$ 其中$\{|n\rangle\}$构成一组规范正交基

(3) $\langle n|\krhohat^2|m\rangle \leq \langle n|\krhohat|m\rangle$ 其中$|m\rangle$和$|n\rangle$是任意纯态

第一条是不言自明的，第二条来自概率守恒，第三条只有在密度算符描述纯态时才取等号。

在这里，阵迹的数学含义可能不够清楚。不过，给定一个基$\{|n\rangle\}$，我们可以把算符$\kShat$和$\krhohat$写成矩阵，它们的阵迹就是对角元通常的求和。所谓密度矩阵的元为$\rho_{n,n'}$，使得

$$\krhohat = \sum_{n,n'}|n\rangle\underbrace{\langle n|\krhohat|n'\rangle}_{\rho_{n,n'}}\langle n'|. \tag{3.6}$$

这些矩阵元有物理意义，有两种情形值得区分：

(1) 对角元$\krhonn = \langle(|n\rangle\langle n|)\rangle$对应于处于态$|n\rangle$的概率。

(2) 非对角元$\krhonm = \langle n|\rho|m\rangle = \langle(|m\rangle\langle n|)\rangle$对应于能级$|n\rangle$和$|m\rangle$之间相干性的期望值，例如原子偶极算符。

例如，二能级原子的密度算符可以写成2x2矩阵，

$$\krhohat = \krhooneone|1\rangle\langle 1| + \krhoonetwo|1\rangle\langle 2| + \krhotwoone|2\rangle\langle 1| + \krhotwotwo|2\rangle\langle 2|. \tag{3.7}$$

于是纯态$|\kpsi\rangle = \kcone|1\rangle + \kctwo|2\rangle$的密度矩阵有$\rho_{ij} = c_i c_j^*$。因此纯态满足

$$|\rho_{ij}|^2 = \rho_{ii}\rho_{jj}. \tag{3.8}$$

考虑到要求$\rho^2 \leq \rho$，可见任意混合态只满足不等式

$$|\rho_{ij}|^2 \leq \rho_{ii}\rho_{jj}. \tag{3.9}$$

因此，对于纯态，非对角分量取到所允许的最大值，即“最大相干性”。

例1：热平衡中的二能级原子

混合态的一个例子是处于热平衡的跃迁频率为$\komega$的二能级原子。在基$\{$$|1\rangle$，$|2\rangle$$\}$中，它的密度算符取如下形式

$$\krhohat = \frac{e^{-\kH/k_B \kT}}{\mathrm{Tr}[e^{-\kH/k_B \kT}]} \tag{3.10}$$
$$= \frac{1}{1 + e^{-\hbar\komega/k_B \kT}}\begin{pmatrix} 1 & 0 \\ 0 & e^{-\hbar\komega/k_B \kT} \end{pmatrix} \tag{3.11}$$
$$= \frac{1}{2\cosh\hbar\komega/2k_B \kT}\begin{pmatrix} e^{\hbar\komega/2k_B \kT} & 0 \\ 0 & e^{-\hbar\komega/2k_B \kT} \end{pmatrix}. \tag{3.12}$$

显然，平衡布居取决于原子跃迁频率与温度的相对大小。例如，在室温$\kT = 300K$时，$k_B \kT/(2\pi\hbar) \approx 6 \cdot 10^{12}$ Hz，对应于介于微波和近红外之间的频率。如果原子跃迁频率远高于这一尺度，原子在平衡时将处于基态；否则，它将处于基态和激发态的统计混合。

例2：热平衡中的辐射场

热辐射场的密度矩阵说明了密度算符形式体系如何与统计力学联系起来。频率为$\knu_j$的单个模有密度算符

$$\krhohat^{(j)} = \frac{e^{-\hbar\knu_j\hat{a}_j^\dagger\hat{a}_j/k_B \kT}}{\mathrm{Tr}[e^{-\hbar\knu_j\hat{a}_j^\dagger\hat{a}_j/k_B \kT}]} \tag{3.13}$$

其在福克态$|n\rangle, |m\rangle$之间的矩阵元为

$$\hat{\rho}^{(j)}_{nm} = \delta_{nm}e^{-\hbar\knu_j n/k_B \kT}\left(1 - e^{-\hbar\knu_j/k_B \kT}\right). \tag{3.14}$$

注意，只有对角元不为零，因为该场是光子数态的统计混合。因此，湮没算符的期望值为零，

$$\langle\hat{a}_j\rangle = \sum_n\langle n|\hat{a}_j\krhohat|n\rangle = \sum_n\rho_{n+1,n}\sqrt{n+1} = 0, \tag{3.15}$$

但平均光子数服从玻色-爱因斯坦分布，

$$\knbar_j = \langle\hat{a}_j^\dagger\hat{a}_j\rangle = \sum_n\krhonn = \frac{1}{e^{(\hbar\knu_j/k_B \kT)} - 1}. \tag{3.16}$$
