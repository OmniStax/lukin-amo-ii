原子与平面波的相互作用说明了原子在相干吸收光子的过程中如何改变其动量和能量。非相干过程也会对运动态产生影响，因为自发发射将产生动量冲击的无规分布。要真正描述这类过程，就需要对电磁场和原子动量态作量子处理。然而，要描述经典情形下的质心运动，并不需要这样的细节。因此我们将采用半经典方法来理解光对原子施加的力。

经典动力学与量子动力学之间的对应关系在海森伯绘景中最容易看出，其中动量与哈密顿量的对易式给出有效力：

$$\frac{d}{d\kt}\kp = \frac{1}{i\hbar}[\kp, \kH] = \kF. \tag{8.9}$$

我们现在引入这样的想法：我们的原子非常接近于一个经典运动的球，所受的是平均力。

由于$\krhotwoone/\kOmega \propto \kchi$与$\kOmega$的相位无关，用这个比值来表示力是方便的。

把电极化率的实部和虚部分开，我们发现原子响应的反应分量和耗散分量分别给出贡献。

当我们可以用密度矩阵方程的定常态解来求解$\krhotwoone$时，这个力特别容易计算和理解。定常态解在时标$\kt$远大于退相位时间$1/\kgammaonetwo$或失谐的倒数$1/\kdelta$时成立。为使我们对力的描述成立，原子波包的宽度必须远小于光波长，$\Delta r(0) \ll \klambda$，这样原子才能分辨场的相位。在稍后的某一时刻，质心运动近似地由$r(\kt) \sim r(0) + p(0)\kt/\km$给出，其不确定度为$\Delta r(\kt) \sim \Delta r(0) + \Delta p(0)\kt/\km$。为使力的方程在时刻$\kt$仍然成立，必须有$\Delta p(0)\kt/\km \ll \klambda$，即$\kkmag\Delta p(0)\kt/\km \ll 1$。利用不确定度关系$\Delta r(0)\Delta p(0) \sim \hbar$和$\Delta r(0) \ll \klambda$，对时间的限制可以写成$\kt \ll (1/\komegaR)$，其中反冲能$\hbar\komegaR = (\hbar \kkmag)^2/2\km$。于是，这种半经典的力的描述成立的情形为

$$\komegaR \ll 1/\kt \ll \max(\kgammaonetwo, \kdelta). \tag{8.19}$$

当这个条件满足、且光强较小时，我们可以用$\krhotwoone/\kOmega = i/(\kgammaonetwo - i(\kdelta - \kkmag\kvmag))$求出光致力，并分析其背后的物理。

大失谐：偶极力

当入射光远失谐于原子共振时，电极化率的实部占主导，响应几乎纯粹是反应性的。在此极限下，$\krhotwoone/\kOmega = -1/\kdelta$，且

$$\kFmag = -\hbar\nabla\left(\frac{|\kOmega|^2}{\kdelta}\right). \tag{8.20}$$

这类力称为“偶极力”，它是保守的，因为它可以写成势的梯度。注意，势$\kVeff = \hbar|\kOmega|^2/\kdelta$对应于外加场所感生的交流斯塔克偏移。实际上，我们可以通过在缀饰态图像中考察原子能级来解释偶极力的起源。对于远离共振的光束，原子保持在基态，但它们可以通过移动到交流斯塔克偏移使基态能量降低的区域来减小其势能。因此，偶极力表示处于缀饰态势中的原子所受的吸引或排斥。

失谐的符号决定偶极力的符号。特别地，

$$\begin{aligned} &\kdelta < 0 \Rightarrow \text{原子被吸引到场极大处} \\ &\kdelta > 0 \Rightarrow \text{原子被吸引到场极小处。} \end{aligned}$$

因此，偶极力可以按需要调节成吸引或排斥原子。对失谐的符号依赖关系也可以从经典论证中得到。如果我们把原子看作可极化的经典偶极子$d$，置于极化电场$E$中，则它的能量为$-E\cdot d$。频率低于共振的外加场将感生一个与场同相振荡的偶极子，使能量降低。高于共振的激发感生一个与外加场异相$\pi$的偶极子，使能量升高。因此，处于红失谐场中的原子将趋向场极大处，而处于蓝失谐场中的原子将趋向场极小处。

偶极力只有在大失谐时才占主导，需要同样大的功率$|\kOmega|^2$才能产生强约束的阱。在此极限下，偶极力提供了一种有效的方法来约束原子，而不引入大量自发发射。

偶极力的两个重要例子已在原子物理学中得到广泛应用。偶极阱是通过将红失谐光束紧紧聚焦而形成的，该光束把原子吸引到光强最大的区域。这种简单的设计已被用于操控和研究冷原子和玻色-爱因斯坦凝聚体。偶极力的第二个重要应用称为“光学格子”。被驻波照射的原子被吸引到波节或波腹，间隔为$\sim \klambda/2$。单个驻波将产生一维格子，而加上正交的光束就可以产生更高维的格子。这些光学格子近似等价于“原子晶体”，并且可以通过用原子和激光搭建一个模型晶体，来研究与固体物理学中类似的现象。

偶极力常常可以推广到许多态$\{|i\rangle\}$，每个态都有一个与之相关联的有效势，

$$\kVeff = \hbar\sum_i \frac{|\kOmega_i|^2}{\kdelta_i}|i\rangle\langle i|. \tag{8.21}$$

这个有效势只包含多能级原子所经历的交流斯塔克偏移；一般来说，考虑近简并原子能级之间的双光子过程所引起的贡献（量级也是$1/\kdelta$）可能是重要的。在这种情况下，内态$\{|i\rangle\}$不再是良好的本征态，我们需要对哈密顿量重新对角化，才能得到真正的缀饰态势。

平面波：耗散力

被平面波照射的原子不受偶极力，因为$\nabla|\kOmega^2| = 0$。耗散力取决于$\mathrm{Im}(\krhotwoone/\kOmega)$。

$\kkmag\kvmag$项反映了以速度$\kvmag$运动的原子看到经多普勒频移的激光频率这一事实。

这里$\kRopt$是光抽运率。上面的表达式只在弱场极限下成立，即当$\kRopt \ll \kgamma$时。

耗散力背后的物理直觉很直截了当。每吸收一个光子，光就向原子施加一个动量冲击$\hbar\kk$。当原子非相干地弛豫到基态时，它向$4\pi$发射一个光子，不会导致动量的净变化。因此，每当一个光子被吸收然后自发发射时，运动态平均改变$\hbar\kk$。吸收/再发射以光抽运率发生，所以动量的变化率必定是$\kFforce = \hbar\kk\kRopt$。更一般地，沿着这一思路，耗散力$\kFforce$也可以看作每次散射事件的动量变化$\hbar\kk$乘以散射率$\kgamma\krhotwotwo$。

把$\krhotwoone/\kOmega$用激发态布居重新表示，用一点代数就可以直接证实这个结果。

耗散力能有多大？我们在前面的讲义中已经看到，随着施加的功率越来越大，跃迁会饱和。对于大功率，

$$\mathrm{Im}\left(\frac{\krhotwoone}{\kOmega}\right) = \frac{\kgammaonetwo}{\kgammaonetwo^2 + (\kdelta - \kkmag\kvmag)^2}\frac{\kgamma}{\kgamma + 2\kRopt}, \tag{8.25}$$

在大功率极限下，$\kOmega \gg \kgamma$，$\kRopt \to \infty$，可达到的最大耗散力由原子的自发发射率决定。

考虑到式 (8.24)，这个极限在直觉上是说得通的，因为原子处于激发态的时间不能超过一半，因而达到的最大散射率为$\kgamma/2$。

考察耗散力的典型数量级是有益的。单个动量冲击$\hbar \kkmag$通常会使原子速度改变每秒几厘米。与室温速度$\sim 100 - 1000$ m/s相比，这个反冲速度微乎其微。要把室温原子减速到反冲速度，需要数量巨大的事件，$\sim 10^4$次。对于碱金属原子，$\kgamma \sim 10^6$ Hz，所以减速过程将需要几毫秒，在此期间原子将飞行约一米。这类考虑决定了激光冷却实验的物理尺度。

对于实际的实验，考虑原子随空间和时间变化的速度是很重要的。特别是，当原子被耗散力减速时，它会因多普勒频移而偏离与外加激光束的共振。为了使原子束减速，必须改变共振条件，使典型的原子在整个减速过程中始终与外加的光共振。实际上，这通过两种方式实现：要么外加的激光被啁啾（其频率被扫描），要么空间变化的磁场给原子加上塞曼移位，使它们在减速时保持共振。
