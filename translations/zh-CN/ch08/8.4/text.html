无规过程的量子描述与经典统计力学中的无规涨落理论密切相关。为引出后面量子力学理论的发展，我们简要回顾布朗运动这一经典问题。

8.4.1 布朗运动

考虑一个重粒子，周围是由较轻粒子构成的热浴。较重的粒子在粒子云中运动时，它与较轻粒子的相互作用产生黏滞阻力，使它减速。然而，重粒子永远不会完全静止，因为它不断受到较轻粒子施加的无规动量冲击。在长时间下，重粒子将与它的热浴达到热平衡。

朗之万方程

布朗运动这一经典问题在数学上由朗之万方程描述，它把重粒子所受的力建模为黏滞阻力加上一个涨落的“朗之万力”，

$$\frac{d}{d\kt}\kpcm = -\keta \kpcm + \kft(\kt), \tag{8.34}$$

其中$\keta$是摩擦系数，$\kft(\kt)$是重粒子与轻粒子碰撞产生的无规力。平均而言，朗之万力为零，

$$\langle \kft(\kt)\rangle = 0 \tag{8.35}$$

并且我们定义它的双时期望值

$$\langle \kft(\kt)\kft(\kt')\rangle = 2\kDdiff g(\kt-\kt') \tag{8.36}$$

用扩散系数$\kDdiff$和二阶关联函数$g(\kt-\kt')$表示，满足

$$\int_{-\infty}^{\infty} g(\kt-\kt')d\kt = 1. \tag{8.37}$$

注意$g(\kt-\kt')$的时间依赖由碰撞频率决定。我们特别感兴趣的情形是：较轻的粒子频繁地与重粒子碰撞，但每次碰撞的效果很小。这样，重粒子将缓慢地损失动量，而无规力$\kft(\kt)$将涨落得非常快。在这一快速碰撞极限下，我们可以把两个时标分开，关联函数趋于一个 δ 函数

$$g(\kt-\kt') \rightarrow \delta(\kt-\kt'). \tag{8.38}$$

对于任意的$\kft(\kt)$，我们都可以求得朗之万方程的通解。

所以平均动量不受朗之万力的影响。然而，它的方差将有来自随机动量冲击的贡献。在快速碰撞极限下，我们可以计算方均动量。

注意，$\langle \kft(\kt)\rangle$的线性项为零，因为平均朗之万力为零。这一计算表明，与平均速度不同，方均动量受到扩散项存在的影响。对于很短的时间$\keta \kt \ll 1$，动量平方只是指数式衰减，

$$\overline{\kpcm(\kt)^2} \approx \overline{\kpcm(0)^2}e^{-2\keta \kt}. \tag{8.45}$$

然而，对于长时间$\keta \kt \gg 1$，第一个黏滞项被指数式阻尼，动量由朗之万力决定。

爱因斯坦关系

如果我们可以假定系统在这样的长时间下趋于热平衡，那么对一维系统有$E_\mathrm{kinetic} = (1/2)k_B\kT$。由此得到的用温度和摩擦系数表示扩散常量的方程称为“爱因斯坦关系”。

从物理上说，有限的平衡温度$\kT$由阻尼与扩散的平衡决定。特别要注意，有限温度下的耗散（$\keta$）总会导致涨落（$\kDdiff$）。在我们对激光冷却的应用中，爱因斯坦关系将使我们能够计算原子在平衡时达到的温度。利用微观描述找到涨落力$\kft(\kt)$的量子类比，我们就能预言可以达到的最低温度。

无规行走

如果我们作出摩擦项为零$\keta \rightarrow 0$这一不符合物理的假设，重粒子就只受到来自较轻粒子的无规冲击，没有耗散。它的动量将无限增长，

$$\overline{\kpcm^2} = \kDdiff\kt, \tag{8.49}$$

并且达不到热平衡，所以爱因斯坦关系不成立。这个所谓的“无规行走”问题表明，在没有阻尼时，重粒子将在较轻粒子的云中无规地扩散。关于这一主题，一份很好的参考文献是科恩-塔诺季的“Atom-Photon Interactions”。

8.4.2 海森伯-朗之万方法

要把朗之万方法应用于多普勒冷却的量子力学描述，我们必须确定系统中的涨落。我们的半经典分析对力和原子算符取了平均$\kF \rightarrow \langle\kF\rangle, \hat{\sigma}_{\alpha,\beta} \rightarrow \langle\hat{\sigma}_{\alpha,\beta}\rangle$（其中$\hat{\sigma}_{\alpha,\beta} = |\alpha\rangle\langle\beta|$），这立刻就消去了任何相关的噪声。显然，我们需要做得更好。

原则上，我们只需回到海森伯运动方程，并避免取任何期望值：

$$\frac{d}{d\kt}\hat{\sigma}_{\alpha,\beta} = \frac{i}{\hbar}[\kH, \hat{\sigma}_{\alpha,\beta}]. \tag{8.50}$$

原子的演化有两个主要的贡献：哈密顿量的演化，以及与热库算符的耦合。我们已经计入了哈密顿量的贡献，只需再加上耗散的效应。事实上，这些运动方程看起来与密度矩阵方程非常相似，很容易让人想到引入退相位项$\dot{\hat{\sigma}}_{\alpha,\beta} \sim -\gamma_{\alpha,\beta}\hat{\sigma}_{\alpha,\beta}$来计入耗散。不幸的是，这种朴素的做法会导致不符合物理的结果。特别是，这样的退相干项意味着$[\hat{\sigma}_{\beta,\alpha}, \hat{\sigma}_{\alpha,\beta}]$随时间指数式衰减。

我们更仔细地重新处理这个问题，考虑按照哈密顿量演化的一个一般的系统和热库

$$\kH = \kHS + \kHR + \kHSR \tag{8.53}$$

其中

$$\kHSR = -\hat{R}^\dagger\kShat - \kShat^\dagger\hat{R}. \tag{8.54}$$

在二能级原子与辐射场的模$\hat{a}_i$相互作用、耦合常数为$\kg_i$的情形下，系统算符和热库算符为

$$\hat{R} = \sum_j \hbar \kg_j\hat{a}_j \tag{8.55}$$
$$\kShat = \hat{\sigma}_{12} = |1\rangle\langle 2|, \tag{8.56}$$

但一般而言它们可以取任何形式。

我们可以写出任意系统算符$\hat{A}$演化的运动方程。

第一项描述孤立系统的哈密顿量演化，其余各项描述系统与热浴的相互作用。例如，如果取$\hat{A} = \hat{\sigma}_{12}, \kShat = \hat{\sigma}_{12}$，我们会得到一个看起来与原子相干性的密度矩阵方程非常相似的方程，其中相干场$\kOmega$被算符量$\hat{R}$取代。这并不那么令人惊讶，因为$\hat{R}$起着量子场算符的作用。注意，系统算符和热库算符对易，所以式 (8.57)中最后两项的次序是任意的。尽管如此，我们还是选择了这一次序，因为它突出了$\hat{R}$对真空态的作用，并且当我们把热库算符$\hat{R}$用影响它的系统算符表示时，这将被证明是有用的。

接下来我们考虑热库算符$\hat{R}$本身的演化方程。对于辐射场，$\hat{R} = \sum_j \hbar \kg_j\hat{a}_j$。

第一项表示在适当选取的转动参考系中的自由场演化，而系统与热库的耦合给出量子场的源项，它又反过来驱动系统。

这个表达式与维格纳-韦斯科普夫理论中热库算符所服从的方程非常相似，我们将再次利用马尔可夫近似来简化方程。如果原子算符$\kShat(\kt)$随时间缓慢变化，并且热库带宽很宽，源项就可以近似为一个简单的衰变。

然而，除了预期的衰变项，我们还需要考虑自由场演化项。这个所谓的“量子朗之万力”，

$$\kfhat(\kt) = -i\sum_j \kg_j\hat{a}_j(0)e^{-i(\knu_j-\komega)\kt}, \tag{8.63}$$

在我们先前对热库效应的朴素猜测中是缺失的。与$\kfhat(\kt)$相关的涨落将使对易式$[\hat{\sigma}_{\beta,\alpha}, \hat{\sigma}_{\alpha,\beta}]$免于我们先前发现的不符合物理的指数式衰减。

量子朗之万算符：$\kfhat(\kt)$

自由场演化项的物理意义可以通过考察它的矩来理解。如果热库最初处于热态，那么$\langle\kfhat(\kt)\rangle = 0$，所以$\kfhat(\kt)$的平均效应为零。与经典朗之万力的情形一样，我们发现二阶矩不为零。

$\kfhat$是算符，所以次序是重要的，类似的计算给出相反次序的二阶矩。

既然$\kfhat$是平均为零、二阶矩由 δ 函数给出的算符，我们就把$\kfhat$解释为量子朗之万算符。

海森伯-朗之万方程

代回系统算符$\hat{A}$的运动方程，我们得到一个一般的结果，称为海森伯-朗之万方程。

从物理上说，海森伯-朗之万方程表明，只要系统有某种耗散$(\kgamma/2)\kShat$，就总会伴随着由朗之万噪声算符$\kfhat$描述的涨落。

与主方程的比较

海森伯-朗之万方程是在海森伯绘景中导出的，而密度矩阵方法使用薛定谔绘景。然而，这两种描述是完全等价的。

为说明二者的联系，假设我们从真空态$n(\komega) = 0$出发，于是$\kfhat|vac\rangle = 0$。对$\hat{A}$取期望值得到

$$\frac{d}{d\kt}\langle\hat{A}\rangle = \frac{i}{\hbar}\langle[\kHS, \hat{A}]\rangle + \frac{\kgamma}{2}\left(2\langle\kShat^\dagger\hat{A}\kShat\rangle - \langle\hat{A}\kShat^\dagger\kShat\rangle - \langle\kShat^\dagger\kShat\hat{A}\rangle\right). \tag{8.70}$$

由于$\langle\sigma_{ij}\rangle = \rho_{ji}$，我们可以把这个方程与真空中原子的主方程逐项比较：它们完全吻合。

量子涨落耗散定理

海森伯-朗之万方程可以写成紧凑的形式

$$\frac{d}{d\kt}\hat{A}_\mu = \hat{d}_\mu + \kFnoise_\mu, \tag{8.71}$$

其中$\mu$表示任意算符，$\hat{d}_\mu$表示该算符的相干演化和衰变（如从密度矩阵运动方程所预言的那样），$\kFnoise_\mu$是量子朗之万算符，满足$\langle\kFnoise_\mu\rangle = 0$以及

$$\langle\kFnoise_\mu(\kt)\kFnoise_\nu(\kt')\rangle = 2\kDdiff_{\mu\nu}\delta(\kt-\kt'). \tag{8.72}$$

正如我们在经典朗之万方程中发现的，噪声力与$\hat{d}_\mu$中包含的耗散之间有一种关系。特别是，广义扩散系数$\kDdiff_{\mu\nu}$由$\hat{d}_\mu$的确定性演化唯一决定：

$$2\kDdiff_{\mu\nu} = \frac{d}{d\kt}\langle\hat{A}_\mu\hat{A}_\nu\rangle - \langle\hat{A}_\mu\hat{d}_\nu\rangle - \langle\hat{d}_\mu\hat{A}_\nu\rangle. \tag{8.73}$$

这个“广义爱因斯坦关系”是把扩散系数与温度和摩擦系数联系起来的方程的量子类比，对所有与马尔可夫热库耦合的系统都成立。

为证明式 (8.73)给出的量子涨落耗散定理，考虑量$\langle\hat{A}_\mu(\kt)\kFnoise_\nu(\kt)\rangle$。

广义爱因斯坦关系传达了一个简单的物理信息：只要给定了系统演化的确定性部分，并且热库没有记忆（即量子“白噪声”），就可以立即算出相关的噪声项。因此，涨落耗散定理提供了一种便捷的方法，可以由已知的系统衰变和退相干参数导出扩散系数。
