多普勒冷却的最终温度由自发发射加热与激光冷却力的平衡所决定，长期以来被认为代表了所有激光冷却方案的根本极限。然而，在20世纪90年代初，一批用碱金属（Na、Rb、Cs）进行的实验测得的温度比多普勒冷却极限的预言值低十倍。这一结果令人费解：多普勒冷却极限相当直观合理。而且，它基于原子运动是经典的这一假设，该假设在温度接近$\kTD = \hbar\kgamma$时成立。由于原子在$\kTD \sim 10$ nm时的德布罗意波长远小于辐射的波长，原子确实表现得像经典的点粒子。然而，还有另一个假设不一定成立：我们忽略了真实原子的多能级结构。

8.6.1 实验观测

对亚多普勒温度的解释是由两项实验观测促成的。

偏振梯度

第一，发现原子系综的最终温度敏感地依赖于外加激光束的偏振。冷却对交叉线偏振光束（“lin$\perp$lin”构型）效果尤其好。在这种构型中，电场的圆偏振依赖于位置。

电场是两个交叉圆偏振的驻波之和，二者彼此相移$\pi/2$。穿过这样的场运动的原子会在入射光中经历偏振梯度。由于偏振梯度对二能级原子几乎没有影响，偏振在亚多普勒冷却中的重要性表明，原子的多能级结构可能起着关键作用。

失谐

第二项实验观测涉及外加冷却光束的失谐。发现亚多普勒温度在大失谐$\kdelta \gg \kgamma$的极限下特别容易获得。远失谐激光束的主要效应是原子能级的交流斯塔克偏移，因此这一实验结果表明，交流斯塔克偏移在亚多普勒冷却中也应起重要作用。

8.6.2 西西弗斯冷却

亚多普勒冷却的理论由科恩-塔诺季及其合作者建立。我们将结合一种特定的原子能级构型来考察他们的解释：J = 1/2 $\rightarrow$ J’ = 3/2 跃迁。

当这样的原子受到拉比频率为$\kOmega$、失谐为$|\kdelta| \gg |\kOmega|$的圆偏振$\sigma_+$光作用时，它所经历的主要效应是基态能级的交流斯塔克偏移。由于两个容许跃迁$m = -1/2$ $\rightarrow m = 1/2$、$m = 1/2$ $\rightarrow m = 3/2$的CG 系数不相等，两个基态的交流斯塔克偏移不同：

$$\kDelta^{\sigma_+}_{1/2} = \frac{|\kOmegap|^2}{\kdelta} \tag{8.99}$$
$$\kDelta^{\sigma_+}_{-1/2} = \frac{|\kOmegap|^2}{3\kdelta}. \tag{8.100}$$

另一种偏振$\sigma_-$的效应恰好相反，

$$\kDelta^{\sigma_-}_{1/2} = \frac{|\kOmegam|^2}{3\kdelta} \tag{8.101}$$
$$\kDelta^{\sigma_-}_{-1/2} = \frac{|\kOmegam|^2}{\kdelta}. \tag{8.102}$$

我们之前发现，lin$\perp$lin构型会产生两个交叉圆偏振的驻波，因此我们关心与空间有关的拉比频率

$$\kOmegap = \kOmega\cos \kkmag z \tag{8.103}$$
$$\kOmegam = \kOmega\sin \kkmag z. \tag{8.104}$$

这里$\kdelta < 0$将导致冷却效应。回想一下，在之前的讲义中我们讨论过，这种交流斯塔克偏移的有效势仅适用于双光子跃迁可以忽略的情形。通过仔细选择我们的模型系统和偏振，我们排除了任何可能的$\Lambda$型构型。因此，有效哈密顿量对所考虑的能级构型提供了恰当的描述。

有效的缀饰态势产生一种类似于偶极力的保守力，它不能提供冷却。要理解亚多普勒冷却从何而来，我们必须超越交流斯塔克效应，考察光抽运。由图 (8.4)可见，$\sigma_+$光把原子光抽运到$m = 1/2$态，而$\sigma_-$光把它抽运到$m = -1/2$态。当原子穿过缀饰态势运动时，它还会在缀饰态之间被其所在位置的主导场光抽运。对于红失谐的场，占主导的偏振倾向于把原子光抽运到能量较低的缀饰态，因此在两次光抽运循环之间，原子必须不断爬升势能曲线。爬上山丘使原子在获得势能的同时损失一部分动能；这部分势能随后被倾泻到自发发射的光子中，该光子把原子抽运到较低的态。这一物理机制赢得了形象的名称“西西弗斯”冷却。

8.6.3 亚多普勒冷却的定量分析

虽然我们现在已经理解了西西弗斯冷却背后的物理，但要验证它会导致亚多普勒温度，我们必须推导出更定量的描述。

西西弗斯冷却力

在大失谐的极限下，相关的运动动力学必定来自反应力。

唯一剩下的未知量是布居差$\kDeltarho = \left(|\frac{1}{2}\rangle\langle\frac{1}{2}| - | -\frac{1}{2}\rangle\langle -\frac{1}{2}|\right)$。

求$\kDeltarho$的第一步是计算相关的光抽运率。CG 系数表明，对于$\sigma_+$光，原子以速率$\kRopt^+/3$从$m_g = -1/2$基态被抽运到$m_e = 1/2$激发态，而原子从$m_e = 1/2 \rightarrow$$m_g = 1/2$衰变的概率为$2/3$。因此，从$m_g = -1/2$到$m_g = 1/2$的光抽运率是$(2/9)\kRopt^+ = (2/9)\kRopt\cos^2 \kkmag z$，其中$\kRopt = |\kOmega^2|\kgamma/((\kgamma/2)^2 + \kdelta^2)$。类似的计算对$\sigma_-$光也成立，它以速率$(2/9)\kRopt\sin^2 \kkmag z$把原子从$m_g = 1/2$光抽运到$m_g = -1/2$态。

由于我们选取的能级构型避免了拉曼跃迁，我们可以计算原子布居，而不必同时求出相干性。此外，本着绝热消除的精神，我们可以忽略激发态布居，并写出基态布居的速率方程：

$$\frac{d}{d\kt}\rho_{\frac{1}{2}\frac{1}{2}} = -\frac{2}{9}\kRopt\sin^2(\kkmag z)\rho_{\frac{1}{2}\frac{1}{2}} + \frac{2}{9}\kRopt\cos^2(\kkmag z)\rho_{-\frac{1}{2}-\frac{1}{2}} \tag{8.110}$$
$$\rho_{\frac{1}{2}\frac{1}{2}} + \rho_{-\frac{1}{2}-\frac{1}{2}} = 1. \tag{8.111}$$

由这两个方程可以直接求出布居差的演化，它描述一个以速率$1/\ktauP$趋向定常态值$\kDeltarho_{SS}$的弛豫过程。

人们很想用这个定常态值来计算耗散力。

定常态力在几个波长上平均为零，所以我们显然还没有找到我们所追求的耗散效应。为什么这样行不通？在代入定常态布居差时，我们假设光抽运率远快于原子运动动力学的典型时标。与多普勒冷却中存在明确的时标层次$\kgamma \gg \komegaR$不同，西西弗斯阻尼常数$1/\ktauP$不必比动量变化的速率大。

特别是，我们需要考虑原子位置随时间的变化$z = \kvmag\kt$。修改$\kDeltarho$的速率方程以纳入原子运动，我们得到

$$\frac{d}{d\kt}\kDeltarho = -\frac{1}{\ktauP}\left(\kDeltarho - \cos(2\kkmag\kvmag\kt)\right), \tag{8.117}$$

因此$\kDeltarho_{SS} = \cos(2\kkmag\kvmag\kt)$不再是精确解。对于小速度，我们可以利用绝热展开方法来求解式 (8.117)。

我们立刻看到，布居差落后于瞬时定常态值，这是因为光抽运使布居达到平衡需要一些时间$\sim \ktauP$。此外，这一时间延迟给出的力的贡献不会平均为零，并且与速度成正比。

假设速度在由光抽运$\ktauP$所定义的时标上不变，就可以精确求解式 (8.117)。

看起来这个力依赖于交流斯塔克偏移，而且每个光抽运循环中损失的能量确实是$|\kOmega|^2/\kdelta$量级。然而，光抽运率也通过$\kvc$决定这个力，而由于$\kvc \propto \kRopt{\sim}|\kOmega|^2\kgamma/\kdelta^2$（当$|\kdelta|{\gg}\kgamma, \kOmega$时），在低功率下外加场的强度恰好抵消。

特别是，对于远小于$\kvc$的速度，西西弗斯摩擦系数趋于

$$\ketaS = 3\frac{\hbar \kkmag^2}{\km}\frac{\kdelta}{\kgamma}. \tag{8.127}$$

当$\kdelta < 0$时，摩擦系数起到冷却原子的作用，而蓝失谐的场则引起加热。

多普勒冷却与西西弗斯冷却的比较

很有启发的是比较西西弗斯冷却的摩擦系数$\ketaS$与多普勒冷却的摩擦系数$\keta_D$，在小功率和大失谐的极限下：

$$\keta_D = 8\frac{\hbar \kkmag^2}{\km}\frac{\kgammaonetwo|\kOmega|^2}{\kdelta^3} \tag{8.128}$$
$$\ketaS = 3\frac{\hbar \kkmag^2}{\km\kgamma}\kdelta. \tag{8.129}$$

多普勒摩擦系数随着场变得更弱、失谐更大而趋于零，而西西弗斯冷却机制与功率无关，并且随着外加场的红失谐更大而增大，因此在这一情形下$\ketaS \gg \keta_D$。然而，这种增大的黏性是有代价的：虽然西西弗斯冷却在零速度附近可以强得多，但它的俘获速度也比多普勒俘获速度小得多。

俘获速度

对于相对较弱的场，多普勒俘获速度与功率无关，$\kvc^D \sim \kgamma/\kkmag, \kdelta/\kkmag$。然而，仔细的计算表明，西西弗斯俘获速度与交流斯塔克偏移呈标度关系：由式 (8.124)，俘获速度的大失谐极限为

$$\kvc^S \sim \frac{\klambda}{18\pi}\frac{|\kOmega|^2}{\kdelta^2}\kgamma. \tag{8.130}$$

于是我们发现，当$\kdelta \rightarrow \infty$时，摩擦系数增大，但俘获速度趋于零。

西西弗斯冷却中的非绝热性

从我们对西西弗斯冷却的定量分析中，我们看到，如果原子遵循密度矩阵方程的瞬时定常态解，冷却力就会消失。只有当我们考虑时间滞后时，摩擦力才会出现，因此它对西西弗斯机制必定是关键的。从物理上看，如果原子布居被光抽运的速度远快于原子速度，那么原子穿过缀饰态势运动时就不必损失势能。特别是，如果布居分布绝热跟随原子位置，那么上坡运动的原子布居损失能量的速率与下坡运动的原子布居获得能量的速率恰好相同。反过来，对冷却最理想的情形是，原子爬上势能山丘的速度如此之快，以致它的布居都不能被光抽运到较低的（加速）态。

8.6.4 西西弗斯冷却极限

西西弗斯冷却的极限由我们在多普勒冷却中遇到过的同一动量扩散过程所决定。我们发现，自发发射引起的动量冲击导致扩散率

$$\kDdiff_{sp} = (\hbar \kkmag)^2\frac{|\kOmega|^2\kgamma/2}{(\kgamma/2)^2 + \kdelta^2}. \tag{8.131}$$

此外，原子在$m_s = \pm 1/2$态之间以速率$1/\tau_p$跳跃时，瞬时偶极力的涨落也带来动量扩散。当涨落在一个波长上取平均时，

$$\kDdiff_{dp} = \left\langle 2\hbar^2\kkmag^2\frac{\kdelta^2}{\kgamma}\frac{\kOmega^2/2}{\kdelta^2 + (\kgamma/2)^2}\sin^4(2\kkmag z)\right\rangle = \frac{3(\hbar \kkmag)^2\kdelta^2}{4\kgamma}\frac{\kOmega^2/2}{\kdelta^2 + (\kgamma/2)^2}. \tag{8.132}$$

实际上，这第二个扩散系数在大失谐时占主导。利用爱因斯坦关系和我们得到的西西弗斯摩擦系数的结果，我们可以求出原子在大失谐极限下所达到的最终温度。

这表明最低温度与缀饰态势的深度同量级。一旦原子的动能小到原子无法爬上山丘，西西弗斯冷却机制就不复存在。

看起来$\kTS$可以被降到任意小的值，只要令$|\kOmega|^2/\kdelta \rightarrow 0$。实际上，一旦原子慢到其运动不能再按经典处理，我们的分析就失效了。当原子冷到基本上局域在一个势阱之内时，它的动量具有不确定度

$$\delta \kpcm \approx \frac{2\pi\hbar}{\klambda} \tag{8.134}$$

这为原子能量设定了一个下限，等于反冲能

$$E^\mathrm{kinetic}_\mathrm{min} \sim \hbar\komegaR. \tag{8.135}$$

反冲能的典型值$\kTR \approx 2.4\mu$K（Na）或$\kTR \approx 0.37\mu$K（Rb）远小于多普勒极限。

其他亚多普勒冷却机制

我们只讨论了众多亚多普勒冷却方案中的一种，且应用于一种特定的原子能级构型。具体特征各不相同，但这个模型让人对为达到亚多普勒温度而采用的机制类型有所了解。关于其他冷却技术的好参考资料是梅特卡夫和范德斯特拉滕的“Laser Cooling and Trapping”，或科恩-塔诺季在 Les Houches LXXII（1999）的讲义。

注意，反冲能并不为激光冷却设定最终极限，但要进一步推进，我们就需要用量子力学的方式处理原子运动。超越$\komegaR$的激光冷却方案被称为“亚反冲”机制，它们需要双光子跃迁或诸如暗共振之类的效应。

最后，请注意我们只考虑了自由中性原子的冷却。在许多方面，受约束的原子和离子的冷却可以简单得多，将在后续讲义中讨论。
