两个小组最终趋同的描述，始于主方程的最一般形式，

$$\frac{d\krhoS}{d\kt} = \frac{1}{i\hbar}[\kH_S, \krhoS] + \mathcal{L}(\krhoS), \tag{6.1}$$

其中刘维尔算符可以表示为

$$\mathcal{L}(\krhoS) = -\sum_k \frac{\kgammak}{2}\left(\kchatk^\dagger\kchatk\krhoS + \krhoS\kchatk^\dagger\kchatk - 2\kchatk\krhoS\kchatk^\dagger\right). \tag{6.2}$$

可以证明，式 (6.1)是物理学所允许的主方程的最一般形式，并且它还有一个额外的优点，即记法紧凑。由于它是最一般的形式，它必定包含我们通过假设某种环境而推导出的主方程。为了看出这一点，把（原则上任意的）算符$\kchatk$取为

$$\hat{c}_{2k} = \sqrt{\knbar+1}\,\hat{S}_k \tag{6.3}$$
$$\hat{c}_{2k+1} = \sqrt{\knbar}\,\hat{S}_k^\dagger, \tag{6.4}$$

此时衰变项和吸收项都包含在式 (6.1)中。

将式 (6.1)与$\mathcal{L}(\krhoS)$的定义结合起来，并展开$\krhoS = \sum_\alpha p_\alpha|\kpsi_\alpha\rangle\langle\kpsi_\alpha|$，我们可以把主方程改写成一种富有启发性的形式。

前两项可以用有效哈密顿量改写，

$$\kHeff = \kH_S - i\hbar\sum_k \frac{\kgammak}{2}\kchatk^\dagger\kchatk. \tag{6.7}$$

前两项的这种形式类似于按$\kHeff$演化的纯态的主方程；最后一项我们将解释为一个“量子跳跃”算符，它以某一概率把$|\kpsi_\alpha\rangle$变为另一个态$|\phi_{k,\alpha}\rangle = \kchatk|\kpsi_\alpha\rangle$。

对应于式 (6.8)前两项的薛定谔方程是

$$i\hbar\frac{d}{d\kt}|\kpsi_\alpha\rangle = \kHeff|\kpsi_\alpha\rangle, \tag{6.9}$$

并且由于我们感兴趣的是用式 (6.8)来描述随机演化，我们将把它写成离散时间，

$$|\kpsi_\alpha(\kt+\delta\kt)\rangle = \left(1 + \frac{\kHeff\delta\kt}{i\hbar}\right)|\kpsi_\alpha(\kt)\rangle. \tag{6.10}$$

注意，$|\tilde{\kpsi}_\alpha(\kt+\delta\kt)\rangle$没有归一化，因为有效哈密顿量不是厄米的。

为了简化记号，我们定义

$$\kdeltapk = \delta\kt\,\kgammak\langle\kpsi_\alpha|\kchatk^\dagger\kchatk|\kpsi_\alpha\rangle \tag{6.14}$$
$$\kdeltap = \delta\kt\sum_k \kgammak\langle\kpsi_\alpha|\kchatk^\dagger\kchatk|\kpsi_\alpha\rangle. \tag{6.15}$$

现在我们知道了$\kt+\delta\kt$时刻态的正确归一化：

$$|\tilde{\kpsi}_\alpha(\kt+\delta\kt)\rangle = \frac{1 + \kHeff\delta\kt/i\hbar}{\sqrt{1-\kdeltap}}|\kpsi_\alpha(\kt)\rangle. \tag{6.17}$$

这个归一化的态对应于仅在主方程前两项的影响下演化的系统的态，即从未跳跃到某个$|\phi_{k,\alpha}\rangle$中的系统。

“量子跳跃”态$|\phi_{k,\alpha}\rangle$也没有归一化，因为

$$\langle\phi_{k,\alpha}|\phi_{k,\alpha}\rangle = \langle\kpsi_\alpha|\kchatk^\dagger\kchatk|\kpsi_\alpha\rangle = \frac{\kdeltapk}{\kgammak\delta\kt}. \tag{6.18}$$

同样，我们将定义一个归一化的态

$$|\tilde{\phi}_{k,\alpha}\rangle = \sqrt{\frac{\kgammak\delta\kt}{\kdeltapk}}|\phi_{k,\alpha}\rangle \tag{6.19}$$

以明确地追踪概率守恒。

与薛定谔方程一样，主方程也可以对离散时间$\delta\kt$写出。

把主方程改写成这种形式，我们就可以利用概率解释来获得对所得系统动力学的直观认识——并发展数值方法。式 (6.21)有两项，它们导致经过时间$\delta\kt$之后的两种可能结果：

(1) 以概率$(1-\kdeltap)$，系统按$\kHeff$演化，并保持在态$|\tilde{\kpsi}_\alpha\rangle$。

(2) 以概率$\kdeltap$，系统跳跃到另一个态；具体地说，它跳跃到态$|\tilde{\phi}_{k,\alpha}\rangle$，概率为$\kdeltapk$。

态矢量演化的这种统计图像提供了一个清晰的模拟流程，它只需要计算态矢量（而不是密度矩阵）的各个元素。一个示例算法概括在表 (6.1)中。

Table 6.1蒙特卡罗流程
(1) 选取初态$|\kpsi_\alpha\rangle$
(2) 选取一个随机数r
(3) 对于适当的时间间隔$\delta\kt$，计算$\kdeltap$。若$\kdeltap < r$，将$|\kpsi_\alpha\rangle$替换为$(1 - i\delta\kt\kHeff/\hbar)|\kpsi_\alpha\rangle/\sqrt{1-\kdeltap}$。若$\sum_{k=1}^{K}\kdeltapk \leq r < \sum_{k=1}^{K+1}\kdeltapk$，将$|\kpsi_\alpha\rangle$替换为$|\tilde{\phi}_{k,\alpha}\rangle$
(4) 重复步骤 (2) 和 (3)，持续所需的时间长度。
(5) 将步骤 (1-4) 重复N次，以产生结果的分布。
(6) 如有必要，对所有可能的初态$|\kpsi_\alpha\rangle$重复步骤 (1-5)。
(7) 密度矩阵演化：$\krhoS(\kt) = \sum_\alpha p_\alpha|\kpsi_\alpha(\kt)\rangle\langle\kpsi_\alpha(\kt)|/N$。
