在线性情形下使用的微扰方法不能用来处理强外加场。非线性情形下的一般方法要求得到密度矩阵各分量作为含时外加场$\kOmega(\kt)$的函数的含时解。随着系统复杂性的增加，这样的解即使用数值方法也越来越难以得到。

作为一种特殊情形，我们将只考虑固定频率的连续波场，并寻找系统的定常态行为。首先，考虑一个受到频率相对于原子共振失谐$\kdelta = \knubar - \komega$的光子照射的均匀二能级原子系综。回忆一下，密度矩阵非对角分量的定常态解为

$$\krhotwoone = -i\frac{\kOmega}{\kgammaonetwo - i\kdelta}(\krhooneone - \krhotwotwo). \tag{4.53}$$

对于强场，我们不能再忽略原子布居的变化，因此应当（在定常态下）代入

$$\krhooneone - \krhotwotwo = \frac{\kgamma}{\kgamma + 2\kRopt} \tag{4.54}$$

其中

$$\kRopt = \frac{2|\kOmega|^2\kgammaonetwo}{\kgammaonetwo^2 + \kdelta^2}. \tag{4.55}$$

我们可以利用定常态相干性求出傅里叶域中的非线性电极化率。

注意，线性电极化率给出了所有含时线性传播场的完整解，而我们刚刚导出的非线性电极化率$\kchin(\kdelta)$只适用于连续波的定常态解。对于我们所考虑的这一特殊情形，电极化率决定了外加场的非线性传播方程。由于我们处理的是连续波场，因此可以忽略波动方程中的时间导数。

非线性电极化率本身是通过$\kRopt$进入的外加场强度$\kOmega = \kmu\kEenv/\hbar$的函数。随着外加场增强，$\kchi$减小，这一效应称为饱和吸收。在弱场极限$\kRopt \ll \kgamma$下，这一表达式化为先前得到的线性电极化率。现在我们将在几种特殊情形下考察非线性电极化率。

共振场

对于完全共振的场，$\kdelta = 0$，电极化率的实部为零，虚部变为

$$\mathrm{Im}[\kchin(0)] = \frac{3}{8\pi^2}\frac{N}{\kV}\klambda^3\frac{\kgamma}{\kgammaonetwo}\frac{1}{1 + \kssat} \tag{4.61}$$

其中

$$\kssat = \frac{4|\kOmega|^2}{\kgammaonetwo\kgamma}. \tag{4.62}$$

当这一饱和参量$\kssat$很大，$\kssat \gg 1$时，外加场漂白介质，透射功率随入射光强的增大而非线性增长。在这一饱和情形下，吸收的空间分布发生定性变化，从强场中的线性衰减变为弱场所特有的指数式衰减。

远失谐场

可以把饱和参量定义为失谐的函数，

$$\kssat = \frac{2\kRopt}{\kgamma}. \tag{4.63}$$

由于$\kRopt$随失谐增大而减小，要使非共振跃迁饱和就需要更大的功率。对于非常大的失谐，$\kdelta \gg \kOmega, \kgamma$，电极化率的虚部可以忽略。

介质的折射率由$\mathrm{Re}[\kchi]$决定，因而依赖于光强。依赖光强的折射率（称为克尔效应）的物理可以通过定义一个对光强呈线性的折射率来描述，$\knref = \knref_0 + \knref_2 \kIint$。这类效应有重要的物理后果，包括依赖光强的相移，它们常被称为“自调相”。此外，对于横向范围有限的光束，介质将起透镜的作用，因为折射率是功率的函数，从而是横向位置的函数，由此产生所谓的自聚焦或自散焦。

弱饱和情形

在某些情形下，我们将处理相对较弱的场，只希望计算对线性传播的领头阶修正。在这类情形下，将电极化率展开是有用的

$$\kchin = \kchi + \kchithree|E|^2 + \ldots, \tag{4.65}$$

其中$\kchi$是线性电极化率，$\kchithree$是下一阶修正（至少对于具有反演对称性的系统是如此）。

我们把第一项看作线性电极化率，把第二项看作领头阶非线性修正。

实验上的考虑

出于实际目的，估算使跃迁在共振时饱和所需的光强是有用的。在辐射增宽的系统中，$\kgammaonetwo = \kgamma/2$，$\kRopt = 4|\kOmega|^2/\kgamma$，因此饱和阈值$\kssat = 1$对应于$8|\kOmega|^2 \approx \kgamma^2$，也就是说，对于碱金属原子，光强为几$\text{mW}/\text{cm}^2$。在多普勒谱线增宽的系统中，$\kkmag\kvT \gg \kgammaonetwo$，需要大得多的功率，因为满足$8|\kOmega|^2 \approx \kgamma^2$的外加场只会使一个速度类的原子饱和。然而，在一小部分速度组被饱和的这一中间情形下，可以用亚多普勒分辨率进行抽运-探测或烧孔等非线性光谱学实验。

实际上，真实系统可以比这些计算所预测的饱和得快得多，因为其他原子能级的存在意味着系统不一定衰变回其原来的状态。例如，考虑一个具有两个长寿命超精细能级和第三个激发能级的原子。当施加一个与从其中一个超精细能级到激发态的跃迁共振的场时，大部分原子布居将最终处于另一个超精细能级上，这一效应称为光抽运。此时共振跃迁的饱和只要求$\kRopt$超过超精细能级之间的（缓慢）衰变，这使它容易饱和得多。这个例子说明了二能级模型往往不是很好的近似，尤其是在与原子和光的非线性相互作用有关的情形中。

4.3.1 饱和光谱学

饱和光谱学是非相干非线性多光子相互作用的一个重要例子。它提供了一种探测非均匀谱线增宽介质的固有线宽的简单方法（不同于线性相互作用，后者无法区分均匀谱线增宽与非均匀谱线增宽的共振）。饱和光谱学通常用频率同为$\knu$、接近与原子跃迁能量$\kDelta$共振的两束对传光束来进行。这两束光在热原子云中产生如下电场分布，

$$\kEfield = \kEp e^{-i\knu \kt + ikz} + \kEm e^{-i\knu \kt - ikz} + c.c, \tag{4.66}$$

其中$\kEp$表示前向的强场，$\kEm$表示后向的弱场。

由于热原子中的多普勒频移，这两束光各自与某一速度类相互作用。强场与满足$\knu = \kDelta + \kkmag\kvz$的原子相互作用，使它们的跃迁饱和，而弱场与多普勒频移后满足$\knu = \kDelta - \kkmag\kvz$的原子相互作用。对于一般的失谐，$\knu \neq \kDelta$，这两个场不与同一组原子相互作用。然而，当频率接近裸原子共振时，$\kvz \to 0$，两个速度类开始重叠。在共振时，两个场都与静止的原子相互作用。因此，我们预期弱场$\kEm$的吸收谱将由于被强场饱和的静止原子而在$\knu = \kDelta$附近显示出尖锐的特征。

饱和吸收谱

饱和光谱学的定性图像可以通过计算探测光束的吸收系数$\kalpha_- = \kkmag\mathrm{Im}[\kchi_-] = \kkmag\mathrm{Im}[P_-/\epsilon_0\kEm]$来作定量验证。为了分离出前向和后向传播的场，我们把原子极化分解为沿$\pm\hat{z}$方向的两个行波，

$$P = P_+e^{-i\knu \kt + ikz} + P_-e^{-i\knu \kt - ikz} + c.c. \tag{4.67}$$

为了考虑非均匀的多普勒谱线增宽，这一总极化可以进一步分解为来自不同速度的原子的贡献。某个特定的速度组$\kvz$贡献一个与两束对传光束所感生的原子相干性成正比的极化$P^{(\kvz)}$，

$$\krhotwoone^{(\kvz)} = \underbrace{\krhotwoone^{(\kvz)+}}_{\sim\kEp} + \underbrace{\krhotwoone^{(\kvz)-}}_{\sim\kEm}. \tag{4.68}$$

一旦我们对适当的原子密度$\knv$算出了极化，$P_\pm^{(\kvz)} = \knv\kmu^*\krhotwoone^{(\kvz)\pm}$，就可以对速度类求和并除以$\epsilon_0\kEpm$，得到探测光束的电极化率。

我们可以利用先前对线性相互作用进行分析的结果求出这一相干性$\krhotwoone^{(\kvz)-}$，因为探测光束$\kEm$很弱。具体地说，我们得到

$$\krhotwoone^{(\kvz)-} \approx \frac{i\kOmegam(\krhooneone - \krhotwotwo)^{(\kvz)}}{\kgammaonetwo - i(\kdelta + \kkmag\kvz)}, \tag{4.69}$$

其中$\kOmegapm = \kmu\kEpm/\hbar$。注意，由于原子沿光传播轴线的速度，失谐$\kdelta = \knu - \komega$发生了多普勒频移。对于探测光，向右运动的原子看到频率更高的场（蓝移），因此净失谐为$\kdelta + \kkmag\kvz$。

我们先前的线性分析不需要进一步的计算，因为对于足够弱的场，布居分布$\krhooneone - \krhotwotwo$与$\kOmegam$无关。然而，为了准确地模拟饱和吸收光谱学的非线性方面，我们必须纳入强场$|\kOmegap|^2$对$\krhooneone - \krhotwotwo$的影响。我们先前已经看到，强的非线性相互作用可以通过重新分布原子布居使跃迁饱和：

$$(\krhooneone - \krhotwotwo)^{(\kvz)} = \frac{1}{1 + S(\kdelta - \kkmag\kvz)}, \tag{4.70}$$

其中饱和参量为

$$S(\kdelta - \kkmag\kvz) = \frac{4|\kOmegap|^2(\kgammaonetwo/\kgamma)}{\kgammaonetwo^2 + (\kdelta - \kkmag\kvz)^2}. \tag{4.71}$$

注意，$\kOmegap$的多普勒频移符号是相反的，因为它的传播方向与$\kOmegam$相反。代入式 (4.69)，我们得到由$\kOmegap$和$\kOmegam$在速度为$\kvz$的原子中感生的后向传播的相干性。

现在我们已经可以通过对所有原子速度类对极化的贡献求和，来计算探测光束的吸收系数$\kalpha_- = \kkmag\ \mathrm{Im}[\kchi_-] = \kkmag\ \mathrm{Im}[P_-/\epsilon_0\kEm]$，

$$P_- = \int d\kvz\kmu^*\krhotwoone^{(\kvz)-}\knv, \tag{4.73}$$

其中每个速度类由热分布$\knv$加权。

第一项描述弱探测光通常的多普勒谱线增宽的吸收；第二项描述我们希望计算的饱和效应。通过把热速度分布近似为在对饱和吸收凹陷有贡献的那些速度上为常数，$\knv = n$，我们可以用闭式算出第二项的积分。所得的表达式相当繁复，为了阐明强场的效应，我们将把它展开到$\kOmegap$的最低阶。

饱和吸收特征的表达式，在$\kOmegap$较弱且$\knv$缓变的极限下，表明我们应当看到吸收中有一个尖锐的凹陷，其特征宽度由消多普勒线宽$\kgammaonetwo$给出。
