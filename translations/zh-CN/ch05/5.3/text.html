参量过程是原子与光之间一类重要的相干相互作用。在这样的系统中，我们主要关心外加光场和所产生光场的传播及相互作用；原子的非线性响应之所以重要，只是因为它介导了光场之间的相互作用。光子与原子之间没有能量交换，但原子非线性可以导致外加场之间的混合，甚至产生新频率的场。实际上，非线性介质不必是原子的；在最一般的处理中，光场入射到一个“非线性黑箱”上，它可以产生更高频率的谐波，或和频与差频。

5.3.1 例子：级联系统

我们首先考察参量过程在级联能级构型中如何可用于产生更高频率的场。我们要考虑的情形是，两个场$\kEone$和$\kEtwo$接近于双光子跃迁$\knu_1 + \knu_2 \approx \omega_{12}$的共振。通过驱动这一双光子过程，我们希望使原子发射频率为$\knu_1 + \knu_2$的辐射。

从对称性考虑，人们可能会论证：如果双光子过程是偶极容许的，则$|2\rangle$ $\rightarrow$ $|1\rangle$跃迁是偶极禁戒的。然而，通过破坏相关的对称性（此处为反演对称性），可以使$|1\rangle$与$|2\rangle$之间同时存在单光子和双光子偶极容许跃迁。这种对称性破缺可以通过多种方式实现。氢原子提供了一个特别简单的例子：如果对氢原子施加静电场，线性斯塔克偏移会使$|2s\rangle$和$|2p\rangle$能级混合，于是所得的混杂态没有确定的宇称。选择定则因此被放宽，使得远离共振的双光子跃迁确实可以诱导回到$|1s\rangle$的单光子跃迁。

和频产生有一个直观的半经典解释。假设你用频率满足$\knu_1 + \knu_2 = \omega_{1s\rightarrow 2s}$的两个场驱动受斯塔克偏移的氢原子。由此得到的非对角原子相干性$\krhoonetwo$导致一个以和频$\knu_1 + \knu_2$振荡的极化强度。从半经典的角度看，这个振荡的极化强度将在和频处发射辐射。注意，极化强度正比于两个外加场

$$\kPnl_{\knu_1+\knu_2} \propto \kmu_{12}\kEone\kEtwo, \tag{5.60}$$

并且我们将引入一个非线性电极化率作为比例常数

$$\kchiII = \frac{\kPnl_{\knu_1+\knu_2}}{\epsilon_0\kEone\kEtwo}. \tag{5.61}$$

只要介质有$\kchiII \neq 0$，施加两个场就可以产生和频。

级联能级构型中的非线性极化

我们现在来推导非线性电极化率用原子系统参量表示的表达式。取双光子跃迁相对于居间态远失谐的极限，该系统可以有效地当作二能级系统，被一个场耦合，拉比频率

$$\kOmegaeff = \sum_i \frac{\kOmega_{1i}\kOmega_{2i}}{\kDelta_i} = \sum_i \frac{\kmu_{1i}\kmu_{2i}}{\kDelta_i\hbar^2}\kEone\kEtwo. \tag{5.62}$$

来自外加场$\kEone$和$\kEtwo$的斯塔克偏移可以并入对双光子失谐$\kdeltaeff$的重正化。当$\kDelta_i, \kdeltaeff$很大时，非对角密度矩阵分量为

$$\krhotwoone = -\frac{\kOmegaeff}{\kdeltaeff}. \tag{5.63}$$

5.3.2 和频产生

级联系统说明了介质如何能产生一个以两个外加场的和频振荡的极化强度。现在我们设法理解，这一振荡的极化强度如何产生一个新场。为简化分析，我们将假定：

(1) 两个外加场都是连续波。

(2) 所有场都沿$\hat{z}$方向传播。

于是我们可以把总电场写成三个分量之和，把第三个场与两个外加场同等对待：

$$\kEenv = \kEone e^{i(\knu_1 \kzprop/c - \knu_1 \kt)} + \kEtwo e^{i(\knu_2 \kzprop/c - \knu_2 \kt)} + \kEthree e^{i(\knu_3 \kzprop/c - \knu_3 \kt)} + c.c. \tag{5.66}$$

注意，本着缓变包络近似的精神，我们已把快速振荡项提出来。利用广义 SVEA，我们将求出这三个缓变振幅各自的传播方程。

缓变振幅的演化方程既包含介质通常的线性响应，也包含振荡的极化强度$\kPnl_3$的效应。如果$\kEthree$与两个外加场$\kEone$和$\kEtwo$相比足够弱，那么我们可以预期，在产生$\kEthree$的过程中，这两个外加场不会被大量耗尽。这被称为未耗尽抽运近似，因为$\kEone$和$\kEtwo$起抽运场的作用，驱动$\kEthree$的产生。当我们忽略与$\kEthree$对$\kEenv_{1,2}$的耗尽相联系的非线性项时，$\kEone$和$\kEtwo$的演化方程与线性介质中的相同，

$$\frac{\partial}{\partial \kzprop}\kEenv_{1,2} = \frac{i\knu_{1,2}}{2c}\kchi_{1,2}\kEenv_{1,2}, \tag{5.67}$$

其中$\kchi_i$是介质对频率$\knu_i$的线性响应。

$\kEthree$的演化方程必须同时包含线性响应和非线性响应，因为即使$\kEthree(0) = 0$，和频产生也会发生，而这一产生场随后将与原子近乎线性地相互作用。于是我们得到

$$\frac{\partial}{\partial \kzprop}\kEthree = \frac{i\knu_3}{2c}\kchiII\kEone\kEtwo + \frac{i\knu_3}{2c}\kchi_3\kEthree. \tag{5.68}$$

对于所考虑的远失谐系统，即$\kDelta_i$很大，我们可以确定线性电极化率中的主导项：

$$\kchi_{1,2} \approx \frac{N}{\kV}\frac{1}{\epsilon_0\hbar}\sum_i \frac{|\kmu_{1i,2i}|^2}{\kDelta_i} \tag{5.69}$$
$$\kchi_3 \approx \frac{N}{\kV}\frac{1}{\epsilon_0\hbar}\frac{|\kmu_{12}|^2}{\kdeltaeff} \tag{5.70}$$
$$\quad \tag{5.71}$$

结合初始条件$\kEone(0), \kEtwo(0) \neq 0, \kEthree(0) = 0$，我们现在就有了一个完全确定的问题。

演化方程通过引入吸收线性项的新变量$\tilde{\kEenv}_i$最容易求解，

$$\kEenv_i = \tilde{\kEenv}_i e^{i\knu_i\kchi_i \kzprop/2c} \tag{5.72}$$

由于$\knu_i\kchi_i/2c = \knref_i\knu_i/c = \kkmag_i$恰是场$\kEenv_i$在介质中的波矢量，$\kDeltakmis = \kkmag_1 + \kkmag_2 - \kkmag_3$就是所有三个场的总波矢量之差。

相位匹配

在和频产生中，$\kDeltakmis$是决定$\kEthree$增长的最重要的量。

在$\kDeltakmis = 0$的情形下，称系统满足“相位匹配条件”。这是和频产生最有利的配置，因为场随距离线性增长。

这种场线性增长的物理解释来自对产生场和感生极化强度的相速度的考察。当$\kDeltakmis = 0$时，场$\kEthree$的相速度与极化强度$\kPnl_3$的相速度恰好匹配，因此极化强度总是相长地对新场的产生作出贡献。如果相速度不匹配，$\kDeltakmis \neq 0$，则极化强度的相位在经过$\approx \pi/\kDeltakmis$的距离之后就会错位，产生一个与传播的场$\kEthree$相消干涉的场。

对相位匹配条件的另一种解释援引动量守恒。参量上转换涉及吸收两个光子并发射一个光子，这一过程必须同时守恒能量$\knu_3 = \knu_1 + \knu_2$和动量$\kkmag_3 = \kkmag_1 + \kkmag_2$。对于有限长度$\kLmed$的原子云，动量在$\approx \pi/\kLmed$的范围内是不确定的，因此对于小于相干长度的距离，$\kDeltakmis\kLmed \ll 1$，系统是相位匹配的，场线性增长。一旦场传播得足够远，使得$\kDeltakmis\kLmed \gg 1$，动量守恒就不再满足，相消干涉开始出现。

竞争过程

相位匹配提供了所谓会降低非线性效应的竞争过程的一个例子。介质的线性电极化率与非线性产生相竞争，使得$\kEthree$的结果比其可能达到的值小得多。吸收或光束破碎等其他效应也会减小非线性过程的净输出。这些竞争过程常常压倒非线性效应，并在很大程度上解释了为什么实际系统中的非线性往往如此之小。

级联系统中的和频产生

我们现在把针对一般非线性系统的计算应用于级联能级构型，在其中我们可以用已知的原子量来表示输出场。通过考察$\kDeltakmis \neq 0$时的式 (5.76)，我们看到，在距离$\kzprop = \pi/\kDeltakmis$之后，$\kEthree$达到其最大振幅。

由于$\kDeltakmis$由系统的线性电极化率决定，产生场的强度取决于非线性电极化率与线性电极化率之比。对于远失谐的双光子跃迁（$\kDelta_i$很大），近共振的电极化率 $\kchi_3^{(1)}$主导$\kDeltakmis \approx \frac{\knu_3}{c}(\knref_3 - 1) \approx 2\frac{\knu_3}{c}\kchi_3^{(1)}$。在这一极限下，我们可以很容易地用原子偶极矩表示最大场振幅。

当我们调谐得更接近双光子共振，$\kdeltaeff \rightarrow 0$时，非线性电极化率增大，但这一增大恰好被线性电极化率相应的增大所平衡；确实，双光子失谐从问题中消去了。

当系统不是相位匹配的时，新场的整体大小非常小。如果我们取$\kEone \sim \kEtwo \sim \kEenv$，则和频场的相对振幅为

$$\frac{\kEthree(\pi/\kDeltakmis)}{\kEenv} \sim \sum_i \frac{\kOmega_i}{\kDelta_i} \ll 1. \tag{5.80}$$

相位匹配的实际实现

鉴于这一结果，考虑实现相位匹配的实际方法十分重要。这一目标需要设计线性色散，使极化强度和和频场同相传播。

在原子物理中，相位匹配曾通过混合两种气体来实现。其中一种提供非线性，另一种则是为提供必要的色散以补偿任何相位失配而引入的。通过仔细调节两种原子的比例，即可实现相位匹配。

原子物理中经常使用的另一种方法，是利用强的非微扰场来设计色散。例如，类 EIT 构型可用来消除线性电极化率，从而使$\kDeltakmis = 0$精确成立。一个类似的系统已被用于氢中的二次谐波产生（$\knu_1 = \knu_2$）。强直流场耦合$2s$和$2p$能级，其作用类似于非微扰驱动场，而二次谐波$\kEthree$探测从$1s$到$2p$的跃迁。由$1s, 2s$和$2p$组成的三能级系统因此呈现$\Lambda$构型，允许二次谐波发生EIT 传播。[参见 K.哈库塔、L.马尔梅和 B.P.斯托伊切夫，PRL 66, 596 (1991)]

虽然原子系统几乎是 UV 和 UUV 光谱区相干辐射的唯一来源，但可见光谱区的大多数实用器件并不使用原子：非线性光学晶体通常用于和频产生。类似的相位匹配考虑同样适用，但会采用其他实际方法来实现它。例如，非对称晶体可以表现出双折射，其中不同的偏振可以经历不同的、随温度变化的线性电极化率。相位匹配可以通过仔细选择抽运场的偏振并适当加热晶体来设计。角度调谐也可以采用，利用的事实是$\kDeltakmis$实际上是各波矢量的矢量和。

饱和

当实现相位匹配时，式 (5.76) 表明和频场无限制地线性增长。从物理上看，这一预言不可能正确，因为外加场$\kEone$和$\kEtwo$向系统抽运有限量的功率。事实上，随着$\kEthree$增长，未耗尽抽运近似最终会失效。对于参量过程，原子与光场之间没有能量交换，因此（在无损耗系统中）

$$\frac{\partial}{\partial \kzprop}\left(|\kEone|^2 + |\kEtwo|^2 + |\kEthree|^2\right) = 0. \tag{5.81}$$

因此我们预期，产生场的饱和将在$\kEthree$开始接近外加场$\kEenv_{1,2}$的振幅时出现。

向其他参量过程的推广

我们已经详细讨论了一个具体的过程：参量上转换。同样的物理和数学工具适用于其他非线性参量过程。例如，可以不施加两个红光场去产生和频的蓝光场，而是考虑通过施加一个蓝光场和一个红光场产生差频，来产生频率较低的光场。同样的演化方程适用，而相位匹配方面的考虑将再次起重要作用。

三阶非线性过程

在我们的全部分析中，我们假定所有跃迁上的偶极耦合均不为零，$\kmu_{12}, \kmu_{1i}, \kmu_{2i} \neq 0$，并且我们指出过，这种情形在某些对称性被破坏时出现。事实上，可以证明，在具有反演对称性的系统中，二阶非线性电极化率为零，$\kchiII = 0$，因此最低阶的非线性电极化率是$\kchithree$。三阶电极化率的定义为

$$\kchithree = \frac{\kPnl}{\epsilon_0\kEenv_1\kEenv_2\kEenv_3}, \tag{5.82}$$

其中$\kPnl$是由三个外加场$\kEenv_{1,2,3}$产生的极化强度。例如，克尔效应是三阶非线性过程的一个特例，其中只存在一个场，因此$\kPnl \propto \kEenv|\kEenv|^2$。此外，也可以把氢中的和频产生解释为三阶过程。我们不必援引由直流场造成的对称性破缺，而是可以把这个静场当作第三个外加场，并利用三阶电极化率来分析所得的和频产生。
